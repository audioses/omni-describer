Omni Describer User Guide

Giving a Voice to the Visual World with AI.

Important Notice: Omni Describer has transitioned to a web platform. The desktop app is now in maintenance mode. New features and improvements are focused on the web version at studio.binclusive.io. The web platform requires no installation, no API keys, and works on all devices including Mac and mobile. The desktop app will remain available for those who prefer it.

It all started with my love for movies. When I realized how many details in my favorite scenes were lost without good audio description, an idea sparked: "Well, couldn't AI make this easier for us?" I dreamed of a tool that wouldn't just generate descriptions but would also give full control to the user. After months of intense work, countless trials, and overcoming many technical hurdles, I developed Omni Describer as the product of that dream.

What's in a Name?

The "Omni" in the name comes from Latin, meaning "all" or "everything." I chose this name because I didn't want the tool to serve just one purpose. Yes, Omni Describer primarily aims to make media accessible for blind and visually impaired individuals by creating audio descriptions. However, its purpose is not limited to that.

This is also an exploration tool. A film critic, a student, an artist, or anyone curious about visual details can use features like "Scene Explorer" or "Ask More" to delve into the layers of a video like never before. Omni Describer is a window to see the world through the "eyes" of AI and understand it differently. In short, it is "a describer for everything, for everyone."

System Requirements

To get the best performance from Omni Describer, I recommend meeting the following minimum system requirements:

  • Operating System: Windows 10 or newer (64-bit).
  • Memory (RAM): At least 4 GB of RAM.
  • Storage: At least 500 MB of free disk space for the application and temporary files.
  • Internet Connection: Needed for the online AI services (Google Gemini, an online OpenAI-compatible service), the online voices (OpenAI, Azure, Google) and video downloads. With a local AI (Ollama, or a local OpenAI-compatible server) and Windows or Piper voices, videos can be described without sending anything over the internet.
  • Screen Reader: For full accessibility, a screen reader like JAWS, NVDA, or Windows Narrator is recommended.

Getting Started: Setting Up Your API Keys

By default, Omni Describer uses Google Gemini to analyse videos, so you need your own Gemini API key before you start. Other AI services and voices have their own keys, described in Choosing the AI and Voices.

  1. Open Settings: open the File menu (Alt + F) and choose Settings..., or press Ctrl + ,.
  2. AI Settings tab: press Ctrl + Tab to move from the General tab to the AI Settings tab, then Tab into it.
    • Gemini API Key: needed for video analysis with Gemini. Paste your key into this field. You can get a free key from Google AI Studio. Then press Tab to the Test key button (Alt + T): the app says whether the key works and how many models it can use.
    • OpenAI API Key (for TTS): only needed if you choose the OpenAI voices. You can still use the built-in Windows voices without it. You can get a key from the OpenAI Platform.
  3. Save: press Apply or OK to save your settings. You're now ready to go!
Secure Storage: Your API keys are encrypted and stored securely on your computer in the application's settings file. They are never sent anywhere else except to connect directly to the respective AI services.

At the first start, if no Gemini key is set (and no local AI is chosen), the app offers to open the Google AI Studio page and the Settings. Answer Yes, paste the key, then press Test key. At the very first start you are also asked to accept the license (Agree or Disagree).

Quick Start: Generating Your First Description

Let's get started! Just follow these simple steps:

  1. Select a Prompt (Optional): in the main window, Tab to the list "Optional: Select a prompt preset to enhance generation" and choose a preset with the arrow keys. The read-only box after it shows the full text that will be sent to the AI. For your first try, leaving it at "(No Preset Selected)" is a great starting point.
  2. Choose a Video: press Ctrl + O for a video on your computer, Ctrl + U for a direct link to a video file, or Ctrl + Y for a YouTube link. The same actions are the first three buttons of the main window (Alt + L, Alt + U, Alt + Y).
  3. Wait for the description: the application downloads the video if needed, prepares it and sends it to the AI. You can follow the progress in the "Status Log" (the screen reader also speaks the main steps). This may take a few minutes, depending on the length of the video. Ctrl + Shift + P repeats the last progress message.

When the process is complete, the Described Video Player will open automatically, and you can start enjoying your newly described video! Remember to save the project with Ctrl + S in the player: otherwise the descriptions are lost when you close it (the player asks you before closing).

Cancelling a Description

While a description is being generated, press Escape in the main window, or the Cancel Generation button (Alt + C; the focus moves to it when a generation starts). The cancellation works at every stage: while the video is being prepared, while it is being uploaded (even a long upload), while the app waits to retry after an error, and while the AI is working. The app says "Cancelling..." then "Generation cancelled." Closing the app also stops a running generation. While a generation runs, the File menu and the source buttons are unavailable.

The Main Window and Its Menus

The main window contains, in Tab order:

  1. Local Video File, Direct Video URL and YouTube Video URL buttons, to choose the video to describe.
  2. Open Web Platform: opens the web version of Omni Describer in your browser (no API key needed there).
  3. The prompt preset list and the read-only text of the selected preset (see Managing Prompt Presets).
  4. The Status Log, a read-only text of everything the app did; read it with the arrow keys.
  5. Settings..., Cancel Generation (only available while a description is being generated) and Exit buttons.

The status bar at the bottom shows the current step and, during processing, the percentage.

The File Menu

Open it with Alt + F.

  • Open Local Video... (Ctrl + O): choose a video file on your computer and describe it.
  • Open Video from URL... (Ctrl + U): type the direct address of a video file (ending in .mp4, .webm...). It is downloaded, then described.
  • Open from YouTube... (Ctrl + Y): paste a YouTube address. The quality downloaded is set in Settings, General tab.
  • Open Project... (Ctrl + P): reopen a saved project (.omniad file) in the player, without asking the AI again. If the video has moved, the app asks you to locate it.
  • Recent Projects: a submenu of the last projects you opened or saved; press the number in front of a project to open it.
  • Import Descriptions from SRT or WebVTT...: open an existing description script (.srt or .vtt). The app says how many descriptions it found and then asks for the video they belong to. You can then listen to them, edit them or export them.
  • Describe an Image or PDF... (Ctrl + I), Describe My Screen (Ctrl + Alt + Shift + D) and Live Screen Description (Ctrl + Alt + Shift + L): see Images, PDFs and Your Screen.
  • Reuse Characters from a Project... (Ctrl + G): for a series, choose the project of an earlier episode; the next descriptions start from its characters, so names and descriptions stay the same.
  • Manage Prompt Presets...: see Managing Prompt Presets.
  • Open Web Platform... (Ctrl + W): opens the web version in your browser.
  • Settings... (Ctrl + ,): see A Deep Dive into Settings.
  • Reset Settings and Data...: see Reset Settings and Data.
  • Exit (Alt + F4).

The Help Menu

  • View Help (F1): opens this guide in your web browser, in the interface language when a translation exists.
  • Changelog: what changed in each version.
  • Contributors: the people who helped build and translate the app.
  • View License: the license agreement.
  • About...: version, contact address and a Visit Website button.

Main Features

Before describing, the app finds the moments without speech, even under music (Silero speech detection, downloaded once, about 2 MB, and run on your computer), and the shot changes, then asks the AI to place descriptions there. It announces the approximate number of tokens before sending the video (Escape cancels), and gives news at least every 25 seconds while it works.

The Described Video Player

This is your personal, described movie theater. As the video plays, the descriptions are read at the right moments: by default by your installed screen reader (like JAWS or NVDA), or by the app voice or on your braille display (see "Descriptions in the player" in Audio Output Tab). The focus starts on the Play button. In Tab order the player contains:

  • Play / Pause button (it says Replay at the end of the video) and the video progress slider: arrow keys on the slider move in the video.
  • Rewind 5s (Alt + R) and Forward 5s (Alt + F) buttons, and the Vol slider (the video volume, remembered for next time).
  • Current Audio Description: the text of the description being read; you can review it with your screen reader's reading keys.
  • AI Token Usage: how many AI "tokens" were used, helping you keep track of your API usage.
  • Explore Scene..., Ask More..., Edit Descriptions..., Settings... and Export... buttons, each described below.

Most actions also have a single-key shortcut that works wherever the focus is: see Keyboard Shortcuts (or press F1 or ? in the player to hear them). When you close the player, it asks whether to save the project if something changed; a downloaded video is deleted on closing unless you saved a project (the video is then copied next to the project).

Settings > Audio Output, "Descriptions in the player": your screen reader (speech and braille, the default); the app voice chosen above, prepared in advance so the video is lowered or paused for exactly the right time; or braille only, where the video pauses after each description until you press Enter. "Also show descriptions in large text on the video" displays each description on the picture, with a size and colour of your choice, for low-vision viewers.

Editing Descriptions: The Power to Refine

The AI provides a fantastic starting point, but true quality comes from refinement. The "Edit Descriptions..." button in the player opens a powerful editor that gives you full control over every aspect of your project. The video must be loaded first.

  • Select and Modify: The list at the top (Alt + L) has one row per description: start, end, text, words per second, review status and level. Selecting a row loads it below and moves the video there. Enter on a row moves to its text.
  • Adjust Timestamps: Edit the Start and End fields (HH:MM:SS.mmm), or set them from the player position with the buttons "Start = player position" (Alt + T or Ctrl + [) and "End = player position" (Alt + N or Ctrl + ]). When you change the start time, the end time automatically shifts to preserve the description's duration. All times are validated to ensure they are within the bounds of your video.
  • Rewrite Text: Freely edit the description text to improve clarity, add detail, or correct inaccuracies.
  • Review status and Reviewer notes: mark a description "To review" or "Validated" and add a note; both are saved with the project and appear in the Word production script.
  • Add New... (Alt + A): opens a small dialog where you set the start, end and text of a new description; the start is the current player position.
  • Delete (Alt + D, or Delete in the list): removes the selected description after confirmation.
  • Characters... (Alt + H): opens the character glossary, see Characters and Their Voices.
  • Hear with the export voice (Alt + R or Ctrl + R): plays the text with the voice used in audio exports, pronunciation dictionary included.
  • Save Changes (Alt + S or Ctrl + S) and Close (or Escape).
  • Shortcuts: F8 / Shift+F8: next / previous description to review. Ctrl+P: play or pause the video. Alt+Left / Alt+Right: move the video 1 second. Ctrl+Z / Ctrl+Y in the list: undo / redo. Ctrl+G on a translated dialogue line: change the speaker's voice (unknown, woman, man). Times are typed as HH:MM:SS.mmm (MM:SS or seconds also work); moving to another description keeps your changes, and closing asks if some are not saved.
Save Your Work: When you close the editor, your updated list of descriptions goes back to the player and is used for playback and exports. To keep it after closing the player, save the project in the player with Ctrl + S.

For professional review, each description has a status (to review or validated) and reviewer notes, saved with the project. After generation, an AI check also marks descriptions that are not in the present tense, that interpret feelings instead of describing what is seen, or that leave the fiction (actors' names, camera jargon); they appear with "Review" in the editor, and V in the player counts them. Changing the text clears these marks. Entries that are too long for their pause or that fall over dialogue also start with "Review".

Characters and Their Voices

The AI keeps a glossary of characters so that each person is described the same way throughout the video and named only once their name has been spoken or shown. Open it from the editor with Characters... (Alt + H).

  • The list shows each character's ID, name ("Not named" until revealed), description and voice. Enter edits the selected character, Delete removes it (after confirmation).
  • Add... (Alt + A), Edit... (Alt + E), Delete (Alt + D), then OK to keep your changes or Cancel.
  • In the character form: ID (a unique identifier, required), Name (leave it empty if not revealed yet), Description (how to recognise them, required).
  • Voice for this character's translated lines: when foreign-language dialogue is translated (see audio subtitles), choose which voice reads this character's lines in audio exports and with the app voice:
    • Automatic (default): the speaker's apparent gender on each line.
    • Woman's voice or Man's voice: always that voice for this character.
    • Description voice: the same voice as the descriptions.
    The label ends with "AI saw: woman", "man" or "unknown": the gender the AI perceived, which your choice overrides without erasing it.
  • Giving a character a new name also renames it in every description; the app says how many descriptions were updated.

To reuse the characters of an earlier episode, use File > Reuse Characters from a Project (Ctrl + G) before describing the next one.

Managing Prompt Presets

Prompts are extra instructions that tell the AI what to focus on. By changing the prompt, you can get descriptions in vastly different styles.

  • Selecting a Preset: Before processing a video, choose a preset in the prompt list of the main window.
  • Managing Presets: Go to File > Manage Prompt Presets.... The list shows each preset's name and text. Buttons: Add... (Alt + A), Edit... (Alt + E, or Enter on a preset), Delete (Alt + D), Export... (Alt + X), Import... (Alt + I) and Close. A preset has a name and a prompt text, both required.
  • One list per interface language: the dialog manages the presets of the current interface language (it says which one at the top). Switching the interface to another language shows that language's list.

The presets exist in the ten interface languages. The default presets ship with the app as JSON files in its prompts folder, one file per language (en.json, fr.json...); your own list is saved in your data folder (prompts.json). Export... saves your presets to a JSON file to share them with other describers; Import... adds the presets of such a file (a preset with the same name is replaced). File > Reset Settings and Data can bring back the default presets.

Ask More About the Scene

Ever wonder what a character is holding or what a sign in the background says? This feature lets you ask anything that comes to mind about the scene. It uses Gemini.

  1. Pause the video at the moment you're curious about.
  2. Press Q, or the Ask More... button.
  3. Type your question in the "Your New Question:" field (e.g., "What color is the woman's hat?" or "What does the writing on the wall say?").
  4. Choose in "Video Context Duration (seconds)" how many seconds of video around the current time the AI should analyse (1 to 60, default 5).
  5. Press Submit Question (Alt + S). The AI's answer appears in the "Conversation History" area, and you can ask follow-up questions: the AI remembers the conversation.
  6. Add to Descriptions (Alt + A) adds the last answer as a new description at the current time. Close returns to the player.

The W key in the player asks directly "What is on screen right now?" and shows the answer in this window.

Scene Explorer

Scene Explorer tells you what is in the picture and where. Each object comes with a clock position: 12 o'clock is the top of the picture, 3 o'clock the right edge, 6 o'clock the bottom. It is an ordinary window, read by your screen reader and braille display. It uses Gemini.

  1. Pause the video on a scene you want to explore in detail.
  2. Press S, or the Explore Scene... button.
  3. In the options, choose the "Analysis Duration (seconds)" (1 to 10, default 3) and optionally type what to focus on, then press Analyze Scene (Enter).

The Scene Explorer window has three parts; move between them with Tab:

  • Scene (Alt + S): a summary of the whole scene.
  • Objects (Alt + O): the objects with their clock position. Moving through the list plays a sound placed to the left or right according to where the object is (use stereo headphones).
  • Details (Alt + D): what the selected object looks like and what it is doing.
  • Escape: close the Scene Explorer.

Images, PDFs and Your Screen

File > Describe an Image or PDF (Ctrl+I) describes a photo, a screenshot or a PDF document: main subject first, people, colours and any visible text, read exactly. For a PDF: layout, pictures, charts and tables with their key values, then a summary by section. The result opens in a window you can read line by line, or copy with the Copy button (Alt + C). Supported images: PNG, JPG, WEBP, GIF, BMP and HEIC.

Describe My Screen (Ctrl+Alt+Shift+D) works from any application: a browser, a video call, a game. The screen is captured, described and the answer is read by your screen reader. The capture is deleted afterwards.

Live Screen Description (Ctrl+Alt+Shift+L, on or off) checks the screen every 3 seconds and describes it only when it has changed noticeably, saying just what is new. Each description uses your API quota: turn it off when you no longer need it.

Audio subtitles: in Settings > AI, "Translate dialogue spoken in another language" adds the translation of foreign-language lines (anime in the original version, foreign films), introduced by the speaker. Like on-screen text, they are announced by a short sound and read in the second voice in exports; with "Read translated dialogue with a voice matching the speaker" they are read with a woman's or a man's voice (see Voices).

Private mode: in Settings > AI, "Images and screen described by" can use a local model through Ollama (ollama.com) or an OpenAI-compatible vision service instead of Gemini (see Choosing the AI). With Ollama nothing leaves your computer and no quota is used, but the descriptions are less accurate. PDF documents always need Gemini. Install Ollama, then run ollama pull gemma3 (or choose another vision model in Settings).

With several screens, the screen showing the active window is described. In live mode, the new description waits for a pause in what the computer is playing (up to 8 seconds) before it is spoken.

Command Line and Batch Mode

To describe many files without the interface, use the command line. Folders are processed file by file; images and PDFs get a text description (name_description.txt). The same settings and API key as the app are used.

python -m audio_describer.cli film.mp4 episodes --lang fr --export vtt,srt,txt,project --out out

The installed app has the same command line: OmniDescriber.exe --cli followed by the same options. All options:

  • inputs: one or more videos, images, PDFs or folders.
  • --lang: description language code (fr, en, es...), for this run only; default: the app setting.
  • --export: comma-separated list among vtt, srt, txt, dapt, docx, project, mkv, mp4, mp3 and m4a. Default: vtt,project.
  • --density low|medium|high: keeps only the essential descriptions (low) or all of them (high, default) in the exports; the project keeps everything.
  • --extended: in audio and video exports, pause the picture when a description is longer than its pause.
  • --no-credit: no spoken AI credit at the end of audio and video exports.
  • --watch: keep running and describe every new file copied into the folders (once its copy is finished). Ctrl + C stops.
  • --out: output folder (default: the current folder).
  • --prompt: extra instructions for the AI, like a prompt preset.

Evaluating an Audio Description

Press E in the player to open the questionnaire from the 2020 audio description guide of the French audiovisual regulator (CSA). The video pauses. The first tab is for listening without the picture, the second for checking with the picture (Ctrl + Tab switches tabs). Rate each question from 1 to 5 (or leave it "not rated") and add comments; measured values (descriptions over dialogue, words per second, uncertain descriptions, on-screen text) are shown next to the questions they inform. There is no overall score: the guide considers an average meaningless. OK keeps the answers with the project (save it with Ctrl+S), and Save Report (Alt + R) writes a text file.

Exporting Your Work

Once you're happy with your descriptions, press the Export... button in the player. Choose a format with the arrow keys, set the options below the list, press Continue (Enter) and choose where to save. The formats:

  • Video with a separate audio description track (MKV): the original tracks are kept, the description is an extra audio track.
  • Video with a separate audio description track (MP4): the same, for most players and phones.
  • MP3 Audio: voices your descriptions with the voice selected in Settings, mixes it with the original sound and lowers the background during descriptions, to create an MP3 you can listen to anywhere.
  • Audio description track only (M4A): only the voiced descriptions, placed at their times.
  • WebVTT descriptions (.vtt): for web players and platforms.
  • SRT Subtitle File: the descriptions as subtitles with their times, for players like VLC.
  • Plain Text File (.txt): one description per line, without times.
  • W3C TTML DAPT script (.ttml): for professional audio description tools.
  • Production script (Word .docx): timecodes, text, level, status and notes, for review.
  • Full script (.txt): the AI transcribes the dialogue and interleaves it with the descriptions, a text alternative for deafblind readers (WCAG 1.2.8). It uses Gemini and can take a few minutes.

Audio and video exports need FFmpeg (included with the app) and voice each description; a progress window lets you follow and cancel the export.

Options of the export window: Only the descriptions of the current density (Alt + D, on by default) exports what you hear in the player (key D); Extended description (Alt + X, MKV, MP4 and MP3 only; on by default when the player is in extended mode) pauses the picture when a description is longer than its pause, instead of cutting it (the video is re-encoded and the original subtitles are not kept); spoken credit (Alt + R, audio and video formats) adds at the end a sentence saying that the audio description was generated by AI. Without the extended option, the end message lists the descriptions that were cut. The audio description track is named in the description language, the subtitles of the source are kept when possible, and with 5.1 sound the descriptions are placed on the centre channel. In the player, Shift + I saves the audio introduction as an MP3 to publish before the programme.

Choosing the AI: Gemini, Ollama or an OpenAI-Compatible Service

In Settings, AI Settings tab, two lists choose which AI looks at your media:

  • Video descriptions: the AI that describes videos.
  • Images and screen described by: the AI used by Describe an Image or PDF, Describe My Screen and Live Screen Description.

Each list offers three choices:

  • Gemini (online), the default and the most accurate. It receives the whole video with its sound. Needs the Gemini API key.
  • Ollama (local, free, private): a vision model running on your own computer through Ollama (ollama.com). The video never leaves your computer and no quota is used, but it is slower and less accurate. Install Ollama, then a vision model, for example ollama pull gemma3, and type the model name in Ollama vision model (default gemma3; llava or qwen2.5vl also work).
  • OpenAI-compatible vision service: any service that speaks the OpenAI chat API with images, online or on your computer: OpenRouter, OpenAI, Mistral, Groq, Claude through OpenRouter, or a local server such as LM Studio, llama.cpp or vLLM. Fill in three fields:
    • Vision service address (OpenAI-compatible): the address of the API, for example https://openrouter.ai/api/v1 (the default), https://api.openai.com/v1, or http://localhost:1234/v1 for LM Studio. An online service must use https://; http:// is only accepted for this computer (localhost, 127.0.0.1).
    • Vision service model: the model name as the service writes it, for example openai/gpt-5-mini on OpenRouter. It must be a model that accepts images.
    • Vision service API key: the key of that service; leave it empty for a local server.

With Ollama or an OpenAI-compatible service, the video is not uploaded: still frames are taken from each part of the video, with their times, and sent to the model.

Features that need Gemini: PDF documents, Ask More (and the W key), Scene Explorer, the audio introduction (I key) and the full script export (dialogue transcription) always use Gemini. When "Video descriptions" is set to another AI, these features refuse to run and tell you so, so that nothing is sent to Google behind your back. Switch "Video descriptions" back to Gemini to use them.

Voices

The voice chosen in Settings, Audio Output tab, reads the descriptions in audio and video exports, in the editor's "Hear" button, and in the player when "Descriptions in the player" is set to the app voice. (With the default screen reader mode, your screen reader's own voice reads them during playback.) Choose the Text-to-Speech Engine with the arrow keys; the fields of that engine appear below it. Press Test in the "Test Voice" group to hear the text typed above it.

  • OpenAI TTS (High Quality): natural voices; needs a paid OpenAI account and the OpenAI API key (AI Settings tab). Choose a Voice Preset; Manage Voice Presets... lets you add, edit and delete presets, each with a name, a base OpenAI voice (alloy, echo, fable, onyx, nova, shimmer, coral, ash, ballad, sage), a speed and instructions for the tone ("Speak in a calm, warm tone").
  • SAPI5 (64-bit Voices) and SAPI5 (32-bit Voices): voices installed in Windows, no key needed. The 32-bit choice gives access to older voices from past systems.
  • Windows OneCore (Modern Voices): the modern voices of Windows (the ones Narrator uses), offline, no key needed.
  • For SAPI5 and OneCore, choose the Voice and the Speed (50 to 200 %).
  • Microsoft Azure Neural Voices (online, key required): fields Speech resource key (from an Azure Speech resource), Region (for example westeurope), Voice (for example fr-FR-DeniseNeural), and optionally a Woman's voice and a Man's voice for translated dialogue.
  • Google Cloud Text-to-Speech (online, key required): fields API key, Voice (for example fr-FR-Chirp3-HD-Aoede), and optionally a Woman's voice and a Man's voice for translated dialogue.

Translated dialogue read with a voice matching the speaker

When dialogue in another language is translated (audio subtitles) and Read translated dialogue with a voice matching the speaker (woman or man) is checked (the default), each translated line is read with a woman's or a man's voice. The app picks, in this order:

  1. with Azure or Google, the woman's or man's voice typed in that engine's fields;
  2. otherwise the Woman's voice or Man's voice chosen below the checkbox: either "Installed Windows voice (automatic)", which takes a Windows voice of that gender in the description language, or a local Piper voice. Piper voices are free, high-quality voices that run offline on your computer. Choose one in the list (its size is shown), then press Download and listen: it is downloaded once (about 20 MB, checksum verified) and a sample is played. The list shows the Piper voices of the description language;
  3. if none of these is available, the usual description voice.

Which voice a speaker gets can be fixed per character (see Characters and Their Voices) or per line in the editor with Ctrl + G.

Interface Language and Description Language

  • Interface language (Settings, General tab, "Application Language"): with "Auto-Detect on Startup" (the default), the app follows the Windows display language each time it starts, so changing the Windows language changes the app's language at the next start. Choose a language in the list to keep it fixed. A change applies after restarting the app. Available: Arabic, English, French, Italian, Portuguese, Russian, Spanish, Turkish, Ukrainian and Vietnamese.
  • Description language (Settings, AI Settings tab, "Description Language"): the language the AI writes in. "Same as interface" (the default) follows the interface language; you can choose any other listed language, for example a French interface with English descriptions for an English lecture. The command line option --lang overrides it for one run.

The prompt presets follow the interface language; the AI rules follow the description language (see Customising the AI Rules).

A Deep Dive into Settings

The Settings window (Ctrl + ,, or the Settings button of the main window or the player) has three tabs; press Ctrl + Tab to move between them and Tab to move between the fields of a tab. At the bottom: Apply saves without closing (available once something changed), OK saves and closes, Cancel closes without saving.

General Tab

  • YouTube Video Download Quality: Best Available, or 1080p down to 144p (default 360p). A lower quality downloads faster and is usually enough for the AI.
  • Application Language (Requires Restart): see Interface Language and Description Language.
  • Logging Level: Info (default), Debug (more detail, useful when reporting a problem) or Disabled. The log file is in %LOCALAPPDATA%\OmniDescriber\logs.
  • Allow descriptions to interrupt current speech: When checked, a new description will start speaking immediately, even if the previous one hasn't finished. Unchecked (the default), each description finishes completely before the next one starts.

AI Settings Tab

  • Gemini API Key and the Test key button: see Getting Started.
  • OpenAI API Key (for TTS): for the OpenAI voices only.
  • Frame Rate for AI Analysis: Determines how many video frames per second are sent to the AI: original, 10, 5, 2 or 1 FPS. A lower value can significantly reduce API costs and help avoid processing limits, but may cause the AI to miss very fast actions.
  • Description density when the player opens: essential descriptions only, standard (default), or all descriptions with details. The D key in the player changes it at any time without a new AI request.
  • Description Language: see Interface Language and Description Language.
  • Description Style: Objective (default), or Subjective, evocative.
  • Focus On: General (default), Characters, Actions and instructions, Settings and atmosphere, or On-screen text.
  • Maximum Words per Description: an upper limit on the length of each description (default 40); 0 means only the length of the pause limits it.
  • Explicitation: Describe only what is visible; Describe and name (default), for example the place or a well-known object; or Describe, name and briefly explain.
  • Images and screen described by, Video descriptions, Ollama vision model, Vision service address, Vision service model and Vision service API key: see Choosing the AI.
  • Translate dialogue spoken in another language (audio subtitles): off by default; see audio subtitles.
  • Check the descriptions with a second AI pass: on by default; a text-only check marks uncertain descriptions "Review" in the editor.
  • Mention colours: on by default; uncheck it if colours mean nothing to you.
  • Gemini Model: a read-only list of models (the default is shown in the label). Refresh model list (Alt + R) asks Google which models your key can use and fills the list.
  • Thinking Level (Gemini 3 and later): Low (faster, cheaper), Medium (default) or High (slower, for complex films).
  • Temperature: how free the AI is in its wording (default 0.3). Lower values give more literal, consistent descriptions. A value that is not a number is replaced by the default.
  • Send Video Only (No Audio) to AI: not recommended: without the sound, the AI can no longer avoid speaking over dialogue.
  • Disable Safety Filters (Use with caution): on by default. This lets the AI process content that it might otherwise flag as sensitive, but the output is still subject to the AI provider's core safety policies. You are responsible for how you use this feature.
  • Enable Video Chunking for Long Videos: splits the video into parts, analyses them one after the other and joins the results. Recommended for long videos. Chunk Duration (seconds) (30 to 2400, default 600) is available only when chunking is checked.
  • Detect pauses in the soundtrack before describing (recommended): on by default; finds the moments without speech so descriptions are placed there.

Audio Output Tab

  • Text-to-Speech Engine and its fields (OpenAI voice preset, SAPI5/OneCore voice and speed, Azure or Google key, region and voices), and the Test Voice group: see Voices.
  • Pronunciation dictionary: one rule per line, such as Hermione = her-my-oh-nee, used by the app voice, the exports and the editor's listen button (whole words, upper or lower case).
  • Audio description mode in the player: in the pauses (the video keeps playing, default), extended (the video pauses when a description does not fit), or on demand (Enter describes the current moment). M changes it in the player.
  • Original audio lowered during descriptions (-dB): how much the video sound is lowered while a description is spoken, in the player and the exports (default 9 dB; 6 to 12 recommended; 0 = not lowered). Shift+Up and Shift+Down change it from the player.
  • Audio description voice level in exports (dB): makes the description voice louder or quieter than the programme in exports (-20 to +20, 0 = unchanged).
  • In exports, read on-screen text in a second, lower voice: on by default, so you can tell a read sign or title from a description.
  • Read translated dialogue with a voice matching the speaker, Woman's voice, Man's voice and the Download and listen buttons: see Translated dialogue.
  • Descriptions in the player: Screen reader (speech and braille, default); App voice above, prepared in advance (exact timing); or Braille only, the video waits for Enter.
  • Also show descriptions in large text on the video, Text size on the video (16 to 120, default 40) and Text colour on the video (yellow, white or cyan): for low-vision viewers.

Customising the AI Rules

Everything the app sends to the AI besides your prompt preset is written in a text file you can read and change: the 12 professional audio description rules (place descriptions in pauses, word budget, present tense, objectivity, characters, on-screen text, scene changes, do not describe what is heard, no censorship, no spoilers, adapt to the content, levels), the list of output fields the AI must return, and the lines added by the Style, Focus On, Explicitation, colours and audio subtitles settings.

  • The built-in text is in prompts\rules\en.json inside the app folder (in the installed app, inside the _internal folder next to OmniDescriber.exe). Do not edit that file: it is replaced by updates.
  • To change the rules, create a file named ad_rules.json in your data folder, %APPDATA%\Describer (type this in the Windows Run dialog, Windows + R, to open it). Copy into it only the keys you want to change from en.json; a partial file is fine, the other keys keep their built-in value. Keep the placeholders in braces, such as {language} or {max_words}: the app fills them in. A key of the wrong type, or a file that is not valid JSON, is ignored (and noted in the log), so a typo cannot stop descriptions.
  • When the description language is not English, a translation prompts\rules\<language>.json (for example fr.json) is used if it exists; your ad_rules.json is applied on top of it.
  • The file is read again for each description: your edits apply to the next description without restarting the app.
  • File > Reset Settings and Data, "Prompt presets", removes your ad_rules.json (a backup copy is kept), so the built-in rules apply again.

Reset Settings and Data

File > Reset Settings and Data... restores a clean state. Check what you want to reset, then press Reset (Alt + R) and confirm:

  • Settings (back to defaults) (Alt + S): all settings return to their default values. Your API keys (Gemini, OpenAI, vision service, Azure, Google) are kept...
  • ...unless you also check Also forget my API keys (Alt + A), available only when Settings is checked.
  • Prompt presets (custom presets are removed) (Alt + P): the default presets of every language come back, and your ad_rules.json is removed.
  • OpenAI voice presets (Alt + V): back to the default presets.
  • Downloaded voices and models (Alt + D): deletes the Piper voices and the speech-detection model; they are downloaded again when needed.
  • Temporary files (Alt + T): deletes the app's own temporary folder (downloaded and processed videos), nothing else.

Before resetting settings or presets, a backup copy of the files is saved in the backups subfolder of your data folder, in a folder named with the date and time, so a mistaken reset can be undone by copying the files back. Projects (.omniad) and exported files are never touched. Some settings, such as the interface language, apply after restarting the app.

Where Your Data Is Stored

  • Data folder: %APPDATA%\Describer, that is C:\Users\<your name>\AppData\Roaming\Describer. It contains your encrypted settings and keys (settings.dat2), your prompt presets (prompts.json), your own AI rules (ad_rules.json, if you created it), and the backups folder.
  • Downloaded voices and models, and the log: %LOCALAPPDATA%\OmniDescriber (Piper voices, the speech-detection model, and the logs folder).
  • Temporary files: %TEMP%\OmniDescriber.
  • Projects and exports: wherever you save them.

Tips and Tricks for the Best Results

Creating great audio descriptions is an art. While AI is an effective assistant, you'll get the best results when you guide it correctly.

The Power of Prompts: Your Director's Notes

The application has a set of core rules it teaches the AI (like not talking over dialogue; see Customising the AI Rules). Think of the Prompt Preset area on the main screen as the place where you provide your director's notes for that specific video. A good note helps the AI focus on a particular style or detail.
Tip: The "Focus on Names" Prompt
In a video with many characters, you can create a custom prompt to prioritize name tracking: Your highest priority for this video is to identify and use the correct character names as soon as they are spoken.
Tip: The "Describe the Atmosphere" Prompt
For visually rich films, guide the AI to focus on the environment: Focus on describing the setting, atmosphere, and environmental details. Mention the lighting, colors, and the overall mood of the scene.

What to Avoid in Prompts

Avoid instructions that contradict the AI's core principles (describing only visuals, not speaking over dialogue). Giving it a flawed instruction can cause poor results.

  • Bad Prompt: "Tell me everything that happens." This is too vague and can cause the AI to describe unimportant details.
  • Bad Prompt: "Tell me what the characters are saying." This will cause it to violate the "visuals only" rule.

In short: Use prompts to guide the AI's focus, not to change the fundamental rules of good audio description. To change the rules themselves, use ad_rules.json.

Frequently Asked Questions (FAQ)

Q: My API keys are not working. What should I do?
A: First, double-check that you have copied the entire key correctly, and use the Test key button next to the Gemini key. For OpenAI, ensure you have set up a payment method in your account, as their TTS service is not free. For Gemini, ensure the API is enabled in your Google Cloud project.

Q: The process failed with a "MAX_TOKENS" error. What does this mean?
A: This means your video is too long or visually complex for the AI to process in a single pass. This is a capacity limit, not a content error. The best solution is to go to Settings > AI Settings and enable "Enable Video Chunking for Long Videos". This will automatically split the video into smaller, more manageable parts for the AI.

Q: The AI failed to generate descriptions because of "Safety Filters". What can I do?
A: This is a known issue where the AI's safety system can be overly cautious. You have a few options to try, in order: 1) Go to Settings > AI Settings and make sure "Disable Safety Filters" is checked. 2) If that fails, try reducing the "Frame Rate for AI Analysis" to send less data to the AI. 3) As a last resort, choose a more powerful model in the Gemini Model list, such as gemini-4-argon. It may handle sensitive content better, but it is slower and may be more expensive if you are on a paid API tier.

Q: Some of my old voices are missing from the SAPI5 list. Where did they go?
A: Modern Windows systems are 64-bit, but many classic, beloved text-to-speech voices were 32-bit. In Settings under the "Audio Output" tab, you will see separate engine choices for "SAPI5 (64-bit Voices)" and "SAPI5 (32-bit Voices)". To access your older voices, simply select the 32-bit engine.

Q: Why does generating descriptions take so long?
A: The time depends on your video's length, your internet speed (for the upload to the AI), the selected frame rate, and the current load on the AI services. Using "Video Chunking" is highly recommended for long videos. You can stop at any time with Escape.

Q: Ask More or Scene Explorer says "This feature uses Gemini".
A: "Video descriptions" is set to Ollama or an OpenAI-compatible service. These features only work with Gemini; switch back to Gemini in Settings > AI Settings to use them.

In the video player

These keys work whatever control has the focus, except that the description and token text boxes keep their own reading keys, and the arrow keys keep adjusting the volume slider when it has the focus. F1, Ctrl+S and Alt+Left / Alt+Right work everywhere.

  • Space: Play / pause
  • Left / Right: Back / forward 5 seconds
  • Ctrl + Left / Right: Back / forward 30 seconds

  • Up / Down: Video volume (by 5)

  • T: Announce the current time and total duration

  • Ctrl + S: Save the project (Ctrl + Shift + S: Save As)
  • F1: Speak this list of shortcuts
