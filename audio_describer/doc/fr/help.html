Guide de l'Utilisateur d'Omni Describer

Donner une Voix au Monde Visuel grâce à l'IA.

Tout a commencé avec ma passion pour le cinéma. Quand j'ai réalisé combien de détails dans mes scènes préférées se perdaient sans une bonne audiodescription, une idée a germé : "Et si l'IA pouvait nous faciliter la tâche ?" J'ai rêvé d'un outil qui ne se contenterait pas de générer des descriptions, mais qui donnerait aussi un contrôle total à l'utilisateur. Après des mois de travail acharné, d'innombrables essais et de nombreux obstacles techniques surmontés, j'ai développé Omni Describer comme le fruit de ce rêve.

D'où vient le nom ?

Le "Omni" dans le nom vient du latin, signifiant "tout" ou "chaque chose". J'ai choisi ce nom car je ne voulais pas que l'outil ait un seul but. Oui, Omni Describer vise principalement à rendre les médias accessibles aux personnes aveugles et malvoyantes en créant des audiodescriptions. Cependant, son utilité ne s'arrête pas là.

C'est aussi un outil d'exploration. Un critique de cinéma, un étudiant, un artiste, ou toute personne curieuse des détails visuels peut utiliser des fonctionnalités comme "Explorateur de Scène" ou "Poser des questions" pour sonder les couches d'une vidéo comme jamais auparavant. Omni Describer est une fenêtre pour voir le monde à travers les "yeux" de l'IA et le comprendre différemment. En bref, c'est "un descripteur pour tout, pour tout le monde".

Configuration Requise

Pour obtenir les meilleures performances d'Omni Describer, je recommande de respecter la configuration minimale suivante :

  • Système d'exploitation : Windows 10 ou plus récent (64-bit).
  • Mémoire vive (RAM) : Au moins 4 Go de RAM.
  • Espace de stockage : Au moins 500 Mo d'espace disque libre pour l'application et les fichiers temporaires.
  • Connexion Internet : Une connexion internet active est requise pour se connecter aux services d'IA (Google Gemini, OpenAI) et télécharger les vidéos.
  • Lecteur d'écran : Pour une accessibilité totale, un lecteur d'écran comme JAWS, NVDA ou le Narrateur Windows est recommandé.

Pour commencer : Configurer vos clés API

Omni Describer utilise des services d'IA basés sur le cloud pour analyser et vocaliser les descriptions. Par conséquent, vous devez saisir vos propres clés API avant de pouvoir commencer.

  1. Ouvrir les Paramètres : Allez dans le menu Fichier et sélectionnez Paramètres... (ou appuyez sur Ctrl + ,).
  2. Onglet Paramètres IA :
    • Clé API Gemini : Ceci est obligatoire pour l'analyse vidéo. Collez votre clé dans le champ "Clé API Gemini :". Vous pouvez obtenir une clé API gratuite depuis Google AI Studio.
    • Clé API OpenAI (pour TTS) : Ceci est requis pour la synthèse vocale de haute qualité. Collez votre clé dans ce champ. Vous pouvez toujours utiliser les voix intégrées de Windows sans cette clé, mais OpenAI est recommandé pour de meilleurs résultats. Vous pouvez obtenir une clé depuis la Plateforme OpenAI.
  3. Enregistrer : Cliquez sur Appliquer ou OK pour sauvegarder vos paramètres. Vous êtes maintenant prêt !
Veuillez noter : Vos clés API sont stockées en toute sécurité sur votre ordinateur dans le fichier de configuration de l'application et ne sont jamais envoyées ailleurs, sauf pour se connecter aux services d'IA respectifs.

Au premier démarrage, si aucune clé Gemini n'est définie, l'application propose d'ouvrir la page de Google AI Studio et les Paramètres. Collez la clé, puis appuyez sur Tester la clé à côté du champ : l'application vous indique si la clé fonctionne et combien de modèles elle peut utiliser.

Démarrage rapide : Générer votre première description

Commençons ! Suivez simplement ces étapes :

  1. Choisissez une vidéo : Cliquez sur un bouton comme "Fichier vidéo local" sur la fenêtre principale ou sélectionnez votre source vidéo depuis le menu Fichier.
  2. Sélectionnez une instruction (Optionnel) : Le menu déroulant liste des instructions prédéfinies qui guident l'IA. Pour votre premier essai, "Description standard" est un excellent point de départ.
  3. Lancez le traitement : L'application va maintenant commencer à analyser votre vidéo. Vous pouvez suivre la progression dans le "Journal d'état" en bas de la fenêtre. Cela peut prendre quelques minutes, selon la durée de la vidéo.

Lorsque le processus est terminé, le Lecteur Vidéo Audiodécrit s'ouvrira automatiquement, et vous pourrez commencer à profiter de votre vidéo nouvellement décrite !

Fonctionnalités Principales

Avant de décrire, l'application repère les moments sans parole, même sous la musique (détection de la parole Silero, téléchargée une seule fois, environ 2 Mo, et exécutée sur votre ordinateur), ainsi que les changements de plan, puis demande à l'IA d'y placer les descriptions. Elle annonce le nombre approximatif de jetons avant d'envoyer la vidéo (Échap annule) et donne des nouvelles au moins toutes les 25 secondes pendant le travail.

Le Lecteur Vidéo Audiodécrit

C'est votre salle de cinéma personnelle et audiodécrite. Pendant que la vidéo se joue normalement, votre lecteur d'écran installé (comme JAWS ou NVDA) lira les descriptions générées aux moments appropriés.

  • Contrôles de lecture : Utilisez les boutons Lecture/Pause, Retour/Avance rapide, ou le curseur de recherche pour naviguer dans la vidéo.
  • Zone de l'audiodescription actuelle : Vous pouvez suivre ici le texte de la description en cours.
  • Modifier les descriptions : Si une description est inexacte, mal synchronisée ou si vous souhaitez la supprimer, cliquez sur le bouton "Modifier les descriptions..." pour la corriger ou la supprimer facilement.
  • Utilisation des jetons IA : Cette zone vous indique combien de "jetons" IA ont été utilisés pendant le processus, vous aidant à suivre votre consommation API.

Paramètres > Sortie audio, « Descriptions dans le lecteur » : votre lecteur d'écran (parole et braille, par défaut) ; la voix de l'application choisie ci-dessus, préparée à l'avance pour que la vidéo soit baissée ou mise en pause exactement le temps nécessaire ; ou le braille seul, où la vidéo se met en pause après chaque description jusqu'à ce que vous appuyiez sur Enter. « Afficher aussi les descriptions en gros caractères sur la vidéo » affiche chaque description sur l'image, dans la taille et la couleur de votre choix, pour les personnes malvoyantes.

Pour la relecture professionnelle, chaque description a un statut (à vérifier ou validée) et des notes du relecteur, enregistrés avec le projet. Après la génération, une vérification par l'IA signale aussi les descriptions qui ne sont pas au présent, qui interprètent les sentiments au lieu de décrire ce qu'on voit, ou qui sortent de la fiction (noms des acteurs, jargon de caméra) ; elles apparaissent avec « À vérifier » dans l'éditeur, et V dans le lecteur les compte. Modifier le texte efface ces marques.

Modifier les descriptions

  • Choisir: Sélectionnez une description dans la liste en haut de l'éditeur (bouton « Modifier les descriptions... » du lecteur).
  • Horaires: Modifiez le début et la fin ; changer le début décale la fin pour garder la durée.
  • Texte, ajout, suppression: Réécrivez le texte, « Ajouter nouveau... » crée une description, « Supprimer » l'enlève.
  • Personnages: Le bouton « Personnages... » (Alt+H) ouvre le glossaire que l'IA utilise pour garder les noms cohérents : ajouter, modifier ou supprimer (Entrée modifie, Suppr enlève). Renommer un personnage le renomme dans toutes les descriptions.
  • Relecture: Chaque description a un statut (à relire ou validée) et des notes. Après la génération, une vérification par l'IA signale les descriptions qui ne sont pas au présent, qui interprètent au lieu de décrire, ou qui sortent de la fiction ; V dans le lecteur les compte. Modifier le texte efface ces marques.
  • Raccourcis: F8 / Maj+F8 : description à relire suivante / précédente. Ctrl+P : lecture ou pause de la vidéo. Alt+Gauche / Alt+Droite : déplacer la vidéo d'une seconde. Ctrl+Z / Ctrl+Y dans la liste : annuler / rétablir. Ctrl+[ / Ctrl+] : début / fin = position du lecteur. Ctrl+S : enregistrer. Les heures se tapent en HH:MM:SS.mmm (MM:SS ou secondes acceptés) ; passer à une autre description garde vos changements, et la fermeture demande s'il en reste de non enregistrés.

Gérer les Préréglages d'Instructions

Les instructions (prompts) sont de puissantes directives qui déterminent sur quoi l'IA se concentre. En changeant l'instruction, vous pouvez obtenir des descriptions dans des styles très différents.

  • Sélectionner un préréglage : Avant de traiter une vidéo, choisissez un préréglage dans le menu déroulant sur la fenêtre principale.
  • Gérer les préréglages : Allez dans Fichier -> Gérer les préréglages d'instructions.... Ici, vous pouvez Ajouter, Modifier ou Supprimer vos propres instructions personnalisées. C'est parfait pour sauvegarder les instructions que vous utilisez fréquemment.
  • Spécifique à la langue : Vos préréglages d'instructions sont sauvegardés séparément pour chaque langue que vous sélectionnez dans les Paramètres.

Les préréglages existent dans les dix langues de l'interface. Exporter... enregistre vos préréglages dans un fichier pour les partager avec d'autres audiodescripteurs ; Importer... ajoute les préréglages d'un tel fichier (un préréglage portant le même nom est remplacé).

Poser des questions sur la scène

Vous vous êtes déjà demandé ce qu'un personnage tient ou ce qu'un panneau en arrière-plan dit ? Cette fonction vous permet de demander tout ce qui vous vient à l'esprit sur la scène.

  1. Mettez la vidéo en pause au moment qui vous intrigue.
  2. Cliquez sur le bouton Poser une question....
  3. Tapez votre question dans le champ "Votre nouvelle question :" (par ex., "De quelle couleur est le chapeau de la femme ?" ou "Que dit l'inscription sur le mur ?").
  4. Sélectionnez combien de secondes de vidéo l'IA doit analyser, à partir de la position actuelle du curseur.
  5. Cliquez sur "Soumettre la question". La réponse de l'IA apparaîtra dans la zone "Historique de la conversation".

Explorateur de Scène

L'Explorateur de scène indique ce qu'il y a dans l'image et où. Chaque objet est situé comme sur un cadran d'horloge : 12 heures est le haut de l'image, 3 heures le bord droit, 6 heures le bas. C'est une fenêtre ordinaire, lue par votre lecteur d'écran et votre plage braille.

  1. Mettez la vidéo en pause sur une scène que vous voulez explorer en détail.
  2. Cliquez sur le bouton Explorer la scène..., puis sur "Analyser la scène".

La fenêtre de l'Explorateur de scène a trois parties ; passez de l'une à l'autre avec Tab :

  • Scène : un résumé de toute la scène.
  • Objets : les objets avec leur position horaire. En parcourant la liste, un son est placé à gauche ou à droite selon l'emplacement de l'objet (utilisez un casque stéréo).
  • Détails : l'apparence de l'objet sélectionné et ce qu'il fait.
  • Échap : ferme l'Explorateur de scène.

Images, PDF et votre écran

Fichier > Décrire une image ou un PDF (Ctrl+I) décrit une photo, une capture d'écran ou un document PDF : le sujet principal d'abord, les personnes, les couleurs et le texte visible, lu exactement. Pour un PDF : la mise en page, les images, graphiques et tableaux avec leurs valeurs clés, puis un résumé par section. Le résultat s'ouvre dans une fenêtre que vous pouvez lire ligne par ligne ou copier.

Décrire mon écran (Ctrl+Alt+Shift+D) fonctionne depuis n'importe quelle application : navigateur, appel vidéo, jeu. L'écran principal est capturé et décrit, et la réponse est lue par votre lecteur d'écran. La capture est supprimée ensuite.

Description de l'écran en continu (Ctrl+Alt+Shift+L, activer ou désactiver) vérifie l'écran toutes les 3 secondes et ne le décrit que s'il a nettement changé, en disant seulement ce qui est nouveau. Chaque description consomme votre quota d'API : désactivez-la quand vous n'en avez plus besoin.

Sous-titres audio : dans Paramètres > IA, « Traduire les dialogues dans une autre langue » ajoute la traduction des répliques en langue étrangère (anime en VO, films étrangers), précédée du nom de la personne qui parle. Comme le texte à l'écran, elles sont annoncées par un son court et lues avec la seconde voix dans les exports.

Mode privé : dans Paramètres > IA, « Images et écran décrits par » peut utiliser un modèle local via Ollama (ollama.com) au lieu de Gemini. Rien ne quitte votre ordinateur et aucun quota n'est consommé, mais les descriptions sont moins précises, et les documents PDF nécessitent toujours Gemini. Installez Ollama, puis exécutez ollama pull gemma3 (ou choisissez un autre modèle de vision dans les paramètres).

Avec plusieurs écrans, c'est l'écran qui affiche la fenêtre active qui est décrit. En mode continu, la nouvelle description attend une pause dans ce que l'ordinateur diffuse (jusqu'à 8 secondes) avant d'être lue.

Ligne de commande et traitement par lot

Pour décrire de nombreux fichiers sans l'interface, utilisez la ligne de commande. Les dossiers sont traités fichier par fichier ; les images et PDF reçoivent une description texte. Les réglages et la clé API de l'application sont utilisés.

python -m audio_describer.cli film.mp4 episodes --lang fr --export vtt,srt,txt,project --out out

Options : --density faible, moyenne ou élevée (low, medium or high) ne garde dans les exports que les descriptions essentielles ou les garde toutes (le projet conserve tout) ; --export accepte aussi dapt, docx, mkv, mp4, mp3 et m4a ; --watch reste actif et décrit chaque nouveau fichier copié dans les dossiers. L'application installée a la même ligne de commande : OmniDescriber.exe --cli suivi des mêmes options.

Évaluer une audiodescription

Appuyez sur E dans le lecteur pour ouvrir le questionnaire issu du guide de l'audiodescription 2020 du régulateur français de l'audiovisuel (CSA). Le premier onglet sert à l'écoute sans l'image, le second à la vérification avec l'image. Notez chaque question de 1 à 5 et ajoutez des commentaires ; les valeurs mesurées (descriptions sur les dialogues, mots par seconde, descriptions incertaines, texte à l'écran) sont affichées à côté des questions qu'elles éclairent. Il n'y a pas de note globale : le guide juge une moyenne dénuée de sens. Les réponses sont enregistrées avec le projet, et Enregistrer le rapport écrit un fichier texte.

Exporter votre travail

Une fois que vous êtes satisfait de vos descriptions, vous pouvez les exporter depuis la fenêtre du Lecteur dans différents formats :

  • Exporter en .TXT : Un simple fichier texte avec les horodatages.
  • Exporter en .SRT : Un fichier de sous-titres standard que vous pouvez utiliser dans des lecteurs vidéo comme VLC.
  • Exporter l'audio (MP3) : C'est peut-être la fonctionnalité la plus excitante. Elle vocalise vos descriptions avec la voix que vous avez sélectionnée dans les Paramètres (SAPI5 ou OpenAI), la mélange avec l'audio original de la vidéo, et baisse automatiquement le son de fond pendant les descriptions pour créer un fichier MP3 que vous pouvez écouter n'importe où.

Autres exports : la vidéo avec une piste d'audiodescription séparée en MP4, pour la plupart des lecteurs et téléphones ; le script en W3C TTML DAPT pour les outils professionnels d'audiodescription ; un script de production en Word (.docx) avec codes temporels, texte, niveau, statut et notes ; et le script complet, où l'IA transcrit les dialogues et les entremêle avec les descriptions, une alternative textuelle pour les lecteurs sourdaveugles (WCAG 1.2.8).

Options des exports vidéo et audio : Seulement les descriptions de la densité actuelle exporte ce que vous entendez dans le lecteur (touche D) ; Description étendue met l'image en pause quand une description est plus longue que sa pause, au lieu de la couper (la vidéo est réencodée et les sous-titres d'origine ne sont pas conservés) ; mention parlée ajoute à la fin une phrase indiquant que l'audiodescription a été générée par IA. Sans l'option étendue, le message de fin liste les descriptions coupées. La piste d'audiodescription porte le nom de la langue de description, les sous-titres de la source sont conservés si possible, et avec un son 5.1 les descriptions sont placées sur le canal central. Dans le lecteur, Shift + I enregistre l'introduction audio en MP3, à publier avant le programme.

Local et gratuit : dans Paramètres, onglet IA, Descriptions vidéo peut utiliser Ollama (local, gratuit, privé) : la vidéo ne quitte jamais votre ordinateur (installez Ollama, puis un modèle de vision, par exemple ollama pull gemma3) ; c'est plus lent et moins précis que Gemini. Les dialogues traduits sont lus avec une voix de femme ou d'homme selon le locuteur : dans l'onglet Audio, gardez la voix Windows automatique ou choisissez une voix Piper locale et appuyez sur Télécharger et écouter (environ 20 Mo, une seule fois). Dans l'éditeur, Ctrl+G change la voix du locuteur d'une ligne traduite.

Plongée dans les Paramètres Avancés

La fenêtre des Paramètres (Ctrl + ,) vous donne un contrôle précis sur le comportement d'Omni Describer.

Onglet Paramètres IA

  • Fréquence d'images pour l'analyse IA : Détermine le nombre d'images par seconde envoyées à l'IA. Une valeur plus basse (par ex., 5 FPS) peut réduire les coûts API mais augmente le risque de manquer des actions très rapides.
  • Envoyer uniquement la vidéo (sans l'audio) à l'IA : C'est une option utile pour empêcher que l'audio de la vidéo (dialogues, musique, effets sonores) ne perturbe l'IA. Au lieu d'essayer de décrire une explosion qu'elle entend, l'IA se concentrera uniquement sur ce qui se passe visuellement.
  • Désactiver les filtres de sécurité (À utiliser avec prudence) : Cette option peut permettre à l'IA de traiter du contenu et de générer des descriptions qu'elle pourrait normalement signaler comme sensibles. Cependant, ce n'est pas une dérogation absolue. Le résultat reste soumis aux politiques de sécurité fondamentales de Google, et il n'y a aucune garantie que tous les filtres seront contournés. Veuillez vous rappeler que vous êtes responsable de l'utilisation de cette fonctionnalité.

Onglet Sortie Audio

  • Moteur de synthèse vocale :
    • SAPI5 (intégré à Windows) : Utilise les voix compatibles SAPI5 fournies avec Windows ou que vous avez installées. Il ne nécessite pas de clé API supplémentaire. La qualité audio variera en fonction de la qualité des voix installées sur votre système.
    • TTS OpenAI (Haute qualité) : Produit généralement des voix plus naturelles et fluides. L'utilisation de cette option nécessite une clé API OpenAI et un moyen de paiement associé à votre compte.

Également dans l'onglet Sortie audio : le dictionnaire de prononciation, une règle par ligne, par exemple Hermione = her-my-oh-nee, utilisé par la voix de l'application, les exports et le bouton d'écoute de l'éditeur (mots entiers, majuscules ou minuscules) ; et le mode d'audiodescription dans lequel démarre le lecteur (dans les pauses, étendu ou à la demande ; M le change toujours). Dans l'onglet IA, le réglage de densité choisit la densité à l'ouverture du lecteur.

Conseils et Astuces pour les Meilleurs Résultats

Créer de bonnes audiodescriptions est un art. Bien que l'IA soit un assistant efficace dans cet art, vous obtiendrez les meilleurs résultats en la guidant correctement.

Le pouvoir des instructions : vos notes de réalisateur

L'application a un ensemble de règles fondamentales qu'elle enseigne à l'IA (comme ne pas parler par-dessus les dialogues). Considérez la zone Préréglage d'Instruction sur l'écran principal comme l'endroit où vous fournissez vos notes de réalisateur pour cette vidéo spécifique. Une bonne note aide l'IA à se concentrer sur un style ou un détail particulier, tandis qu'une note vague peut entraîner des résultats inattendus.

Quand (et comment) utiliser une instruction

La plupart du temps, l'IA peut produire d'excellents résultats sans instruction spéciale, en se basant uniquement sur ses règles de base. Je recommande de n'utiliser cette fonctionnalité que lorsque vous avez un objectif précis en tête.

Astuce n°1 : L'instruction "Se concentrer sur les noms"
Dans une vidéo avec de nombreux personnages où les noms sont importants, l'IA peut parfois être trop hésitante à utiliser un nom. Pour prioriser le suivi des noms, vous pouvez créer une instruction personnalisée : Pour cette vidéo, votre plus haute priorité est d'identifier et d'utiliser les noms corrects des personnages dès qu'ils sont prononcés dans le dialogue. C'est plus important que d'être trop concis. Tout en vous concentrant sur cela, essayez de respecter toutes les autres règles du système du mieux que vous pouvez.
Astuce n°2 : L'instruction "Décrire l'atmosphère"
Dans les films visuellement riches où l'atmosphère est essentielle, vous pouvez guider l'IA pour qu'elle se concentre sur l'environnement : Concentrez-vous sur la description du décor, de l'atmosphère et des détails environnementaux. Pour créer un monde visuel riche, mentionnez l'éclairage, les couleurs et l'ambiance générale de la scène. Accordez moins d'importance aux mouvements mineurs des personnages, sauf s'ils sont cruciaux.

Ce qu'il faut éviter dans les instructions

Pour de meilleurs résultats, il est important d'éviter les instructions qui contredisent les principes fondamentaux de l'IA. Comme l'IA essaie toujours de suivre les instructions, lui en donner une défectueuse peut lui faire mal interpréter la vidéo.

  • Mauvais exemple d'instruction : "Dis-moi tout ce qui se passe." Cela peut rendre l'IA trop peu sélective, l'amenant à se concentrer sur des détails sans importance comme "(le personnage parle)" au lieu d'actions significatives.
  • Mauvais exemple d'instruction : "Dis-moi ce que les personnages disent." Cela peut lui faire violer la règle "décrire uniquement le visuel" et décrire le dialogue, comme "le personnage a dit de prendre ceci".

En résumé : Utilisez les instructions non pas pour changer les règles fondamentales d'une bonne audiodescription, mais pour guider l'IA sur un point de mire spécifique.

Foire Aux Questions (FAQ)

Q : Mes clés API sont-elles sécurisées ?
R : Oui. Vos clés sont stockées uniquement sur votre ordinateur et ne sont jamais partagées avec quiconque, sauf pour se connecter aux services de Google/OpenAI.

Q : Pourquoi la génération des descriptions prend-elle autant de temps ?
R : Le temps dépend de la durée de votre vidéo, de votre vitesse internet (pour envoyer la vidéo à l'IA), de la fréquence d'images que vous avez sélectionnée, et de la charge actuelle sur les services d'IA. L'utilisation de la fonction "Activer la segmentation vidéo" est fortement recommandée pour les longues vidéos.

Q : Pourquoi l'IA n'a-t-elle pas décrit quelque chose que j'ai vu à l'écran ?
R : L'IA est entraînée à préférer le silence plutôt que de faire une erreur ou de parler par-dessus un dialogue. Vous pouvez utiliser la fonction "Poser une question..." pour vous renseigner sur des moments spécifiques ou sélectionner le niveau de verbosité "Détaillé" dans les Paramètres.

Dans le lecteur vidéo

Ces touches fonctionnent quel que soit le contrôle qui a le focus, sauf que les zones de texte de la description et des jetons gardent leurs propres touches de lecture, et que les flèches continuent de régler le curseur de volume quand il a le focus.

  • Espace : Lecture / pause
  • Gauche / Droite : Reculer / avancer de 5 secondes
  • Ctrl + Gauche / Droite : Reculer / avancer de 30 secondes
  • Alt + Gauche / Droite : Description précédente / suivante (s'y rend et la lit)
  • Haut / Bas : Volume de la vidéo
  • R : Répéter la dernière description
  • T : Annoncer le temps écoulé et la durée totale
  • A : Activer ou couper l'audiodescription
  • D : Changer la densité : faible (l'essentiel), moyenne, élevée (tous les détails). Effet immédiat, sans nouvelle requête à l'IA.
  • M : Mode d'audiodescription : dans les pauses (la vidéo continue), étendu (la vidéo se met en pause quand une description est trop longue pour sa pause, puis reprend), ou à la demande (rien n'est lu automatiquement)
  • Entrée (mode à la demande) : pause et brève description du moment présent ; Maj + Entrée : tout ce qui a été décrit dans les 15 dernières secondes
  • Q : Poser une question sur le moment présent
  • S : Explorer la scène
  • I : Introduction audio : personnages principaux, leur apparence et les lieux, sans divulgâcher, à écouter avant le programme. Rédigée par l'IA la première fois, puis enregistrée avec le projet.
  • V : Rapport de qualité : nombre de descriptions, part respectant le budget de mots, descriptions sur du son ou marquées incertaines par la vérification de l'IA, mots par seconde, plus long passage sans description.
  • W : Ce qu'il y a à l'écran maintenant, y compris le texte visible. La réponse s'affiche dans la fenêtre Poser une question, où vous pouvez enchaîner d'autres questions : l'IA se souvient de la conversation.
  • E : Évaluer cette audiodescription avec le questionnaire CSA 2020 ; les réponses sont enregistrées avec le projet et peuvent être exportées sous forme de rapport.
  • Shift+Haut / Shift+Bas : Baisser plus ou moins la vidéo pendant qu'une description est lue (0 à 24 dB).
  • ? : Comme F1 : énonce la liste des raccourcis du lecteur.
  • Ctrl + S : Enregistrer le projet (Ctrl + Maj + S : Enregistrer sous)
  • F1 : Énoncer cette liste de raccourcis

Pendant qu'une description est dite, le volume de la vidéo baisse de 9 dB (jamais coupé, réglable dans Paramètres > Sortie audio) puis remonte en douceur, comme le recommandent les guides professionnels d'audiodescription. Un son court précède une description qui lit un texte à l'écran. Pendant la lecture, les descriptions sont lues par votre lecteur d'écran, à son propre volume ; dans les exports, leur niveau se règle dans Paramètres > Sortie audio.

Dans l'éditeur de descriptions, chaque entrée indique son temps, son niveau et ses mots par seconde ; celles qui sont trop longues pour leur pause ou qui tombent sur un dialogue commencent par « À vérifier ».

Autres fonctions : Fichier > Projets récents rouvre l'un des derniers projets ; Fichier > Importer des descriptions depuis SRT ou WebVTT ouvre un script de description existant avec sa vidéo, pour l'écouter, le modifier ou l'exporter. Dans le lecteur, L choisit la piste audio suivante de la vidéo (par exemple une audiodescription existante) et C la piste de sous-titres suivante ou aucune ; en mode à la demande, un son discret signale qu'une description essentielle est disponible. Dans l'éditeur de descriptions, Ctrl + R lit le texte avec la voix d'export.
