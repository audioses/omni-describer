Guide de l'utilisateur d'Omni Describer

Donner une voix au monde visuel grâce à l'IA.

Avis important : Omni Describer est passé à une plateforme web. L'application de bureau est désormais en mode maintenance. Les nouvelles fonctionnalités et améliorations se concentrent sur la version web, à l'adresse studio.binclusive.io. La plateforme web ne demande aucune installation ni clé API, et fonctionne sur tous les appareils, y compris Mac et mobiles. L'application de bureau reste disponible pour ceux qui la préfèrent.

Tout a commencé par mon amour du cinéma. Quand j'ai réalisé combien de détails de mes scènes préférées se perdaient sans une bonne audiodescription, une idée a germé : « L'IA ne pourrait-elle pas nous faciliter la tâche ? » Je rêvais d'un outil qui ne se contenterait pas de générer des descriptions, mais qui donnerait aussi le contrôle total à l'utilisateur. Après des mois de travail intense, d'innombrables essais et bien des obstacles techniques surmontés, j'ai développé Omni Describer, fruit de ce rêve.

Que signifie ce nom ?

Le « Omni » du nom vient du latin et signifie « tout ». J'ai choisi ce nom parce que je ne voulais pas que l'outil serve un seul objectif. Oui, Omni Describer vise avant tout à rendre les médias accessibles aux personnes aveugles et malvoyantes en créant des audiodescriptions. Mais son rôle ne s'arrête pas là.

C'est aussi un outil d'exploration. Un critique de cinéma, un étudiant, un artiste ou toute personne curieuse des détails visuels peut utiliser des fonctions comme « Explorateur de scène » ou « En savoir plus » pour plonger dans les couches d'une vidéo comme jamais auparavant. Omni Describer est une fenêtre pour voir le monde à travers les « yeux » de l'IA et le comprendre autrement. Bref, c'est « un descripteur de tout, pour tous ».

Configuration requise

Pour tirer le meilleur d'Omni Describer, je recommande la configuration minimale suivante :

  • Système d'exploitation : Windows 10 ou plus récent (64 bits).
  • Mémoire (RAM) : au moins 4 Go de RAM.
  • Stockage : au moins 500 Mo d'espace disque libre pour l'application et les fichiers temporaires.
  • Connexion Internet : nécessaire pour les services d'IA en ligne (Google Gemini, un service compatible OpenAI en ligne), les voix en ligne (OpenAI, Azure, Google) et le téléchargement de vidéos. Avec une IA locale (Ollama, ou un serveur local compatible OpenAI) et des voix Windows ou Piper, les vidéos peuvent être décrites sans rien envoyer sur Internet.
  • Lecteur d'écran : pour une accessibilité complète, un lecteur d'écran comme JAWS, NVDA ou le Narrateur de Windows est recommandé.

Premiers pas : configurer vos clés API

Par défaut, Omni Describer utilise Google Gemini pour analyser les vidéos : il vous faut donc votre propre clé API Gemini avant de commencer. Les autres services d'IA et les voix ont leurs propres clés, décrites dans Choisir l'IA et Les voix.

  1. Ouvrir les paramètres : ouvrez le menu Fichier (Alt + F) et choisissez Paramètres..., ou appuyez sur Ctrl + ,.
  2. Onglet Paramètres IA : appuyez sur Ctrl + Tab pour passer de l'onglet Général à l'onglet Paramètres IA, puis sur Tab pour y entrer.
    • Clé API Gemini : nécessaire pour l'analyse vidéo avec Gemini. Collez votre clé dans ce champ. Vous pouvez obtenir une clé gratuite sur Google AI Studio. Appuyez ensuite sur Tab jusqu'au bouton Tester la clé (Alt + T) : l'application indique si la clé fonctionne et combien de modèles elle peut utiliser.
    • Clé API OpenAI (pour TTS) : nécessaire seulement si vous choisissez les voix OpenAI. Vous pouvez utiliser les voix intégrées de Windows sans elle. Vous pouvez obtenir une clé sur la plateforme OpenAI.
  3. Enregistrer : appuyez sur Appliquer ou OK pour enregistrer vos paramètres. Vous êtes prêt !
Stockage sécurisé : vos clés API sont chiffrées et stockées en sécurité sur votre ordinateur, dans le fichier de paramètres de l'application. Elles ne sont jamais envoyées ailleurs qu'aux services d'IA concernés, pour s'y connecter directement.

Au premier démarrage, si aucune clé Gemini n'est définie (et qu'aucune IA locale n'est choisie), l'application propose d'ouvrir la page Google AI Studio et les paramètres. Répondez Oui, collez la clé, puis appuyez sur Tester la clé. Au tout premier démarrage, il vous est aussi demandé d'accepter la licence (Accepter ou Refuser).

Démarrage rapide : générer votre première description

C'est parti ! Suivez simplement ces étapes :

  1. Choisir une invite (facultatif) : dans la fenêtre principale, allez avec Tab jusqu'à la liste « Optionnel : Sélectionnez un préréglage d'invite pour améliorer la génération » et choisissez un préréglage avec les flèches. La zone en lecture seule qui suit affiche le texte complet qui sera envoyé à l'IA. Pour un premier essai, laisser « (Aucun préréglage sélectionné) » est un excellent point de départ.
  2. Choisir une vidéo : appuyez sur Ctrl + O pour une vidéo de votre ordinateur, Ctrl + U pour un lien direct vers un fichier vidéo, ou Ctrl + Y pour un lien YouTube. Les mêmes actions sont les trois premiers boutons de la fenêtre principale (Alt + V, Alt + U, Alt + Y).
  3. Attendre la description : l'application télécharge la vidéo si nécessaire, la prépare et l'envoie à l'IA. Vous pouvez suivre la progression dans le « Journal d'état » (le lecteur d'écran annonce aussi les principales étapes). Cela peut prendre quelques minutes selon la durée de la vidéo. Ctrl + Maj + P répète le dernier message de progression.

Une fois le traitement terminé, le lecteur vidéo audiodécrit s'ouvre automatiquement et vous pouvez profiter de votre vidéo fraîchement décrite ! Pensez à enregistrer le projet avec Ctrl + S dans le lecteur : sinon les descriptions sont perdues à sa fermeture (le lecteur vous le demande avant de se fermer).

Annuler une description

Pendant la génération d'une description, appuyez sur Échap dans la fenêtre principale, ou sur le bouton Annuler la génération (Alt + A ; le focus s'y place au début d'une génération). L'annulation fonctionne à chaque étape : pendant la préparation de la vidéo, pendant son envoi (même long), pendant l'attente avant une nouvelle tentative après une erreur, et pendant que l'IA travaille. L'application annonce « Annulation... » puis « Génération annulée. » Fermer l'application arrête aussi une génération en cours. Pendant une génération, le menu Fichier et les boutons de source sont indisponibles.

La fenêtre principale et ses menus

La fenêtre principale contient, dans l'ordre de Tab :

  1. Les boutons Fichier vidéo local, URL de vidéo directe et URL de vidéo YouTube, pour choisir la vidéo à décrire.
  2. Ouvrir la plateforme web : ouvre la version web d'Omni Describer dans votre navigateur (aucune clé API n'y est nécessaire).
  3. La liste des préréglages d'invite et le texte en lecture seule du préréglage sélectionné (voir Gérer les préréglages d'invite).
  4. Le Journal d'état, un texte en lecture seule de tout ce que l'application a fait ; lisez-le avec les flèches.
  5. Les boutons Paramètres..., Annuler la génération (disponible seulement pendant la génération d'une description) et Quitter.

La barre d'état en bas affiche l'étape en cours et, pendant le traitement, le pourcentage.

Le menu Fichier

Ouvrez-le avec Alt + F.

  • Ouvrir une vidéo locale... (Ctrl + O) : choisissez un fichier vidéo sur votre ordinateur et décrivez-le.
  • Ouvrir une vidéo depuis une URL... (Ctrl + U) : tapez l'adresse directe d'un fichier vidéo (se terminant par .mp4, .webm...). Il est téléchargé, puis décrit.
  • Ouvrir depuis YouTube... (Ctrl + Y) : collez une adresse YouTube. La qualité téléchargée se règle dans Paramètres, onglet Général.
  • Ouvrir un projet... (Ctrl + P) : rouvre un projet enregistré (fichier .omniad) dans le lecteur, sans interroger à nouveau l'IA. Si la vidéo a été déplacée, l'application vous demande de la retrouver.
  • Projets récents : un sous-menu des derniers projets ouverts ou enregistrés ; appuyez sur le numéro devant un projet pour l'ouvrir.
  • Importer des descriptions depuis SRT ou WebVTT... : ouvre un script de description existant (.srt ou .vtt). L'application indique combien de descriptions elle a trouvées, puis demande la vidéo correspondante. Vous pouvez ensuite les écouter, les modifier ou les exporter.
  • Décrire une image ou un PDF... (Ctrl + I), Décrire mon écran (Ctrl + Alt + Maj + D) et Description de l'écran en continu (Ctrl + Alt + Maj + L) : voir Images, PDF et votre écran.
  • Réutiliser les personnages d'un projet... (Ctrl + G) : pour une série, choisissez le projet d'un épisode précédent ; les descriptions suivantes partent de ses personnages, pour que noms et descriptions restent identiques.
  • Gérer les préréglages d'invite... : voir Gérer les préréglages d'invite.
  • Ouvrir la plateforme web... (Ctrl + W) : ouvre la version web dans votre navigateur.
  • Paramètres... (Ctrl + ,) : voir Les paramètres en détail.
  • Réinitialiser les paramètres et les données... : voir Réinitialiser les paramètres et les données.
  • Quitter (Alt + F4).

Le menu Aide

  • Afficher l'aide (F1) : ouvre ce guide dans votre navigateur, dans la langue de l'interface lorsqu'une traduction existe.
  • Journal des modifications : ce qui a changé dans chaque version.
  • Contributeurs : les personnes qui ont aidé à créer et à traduire l'application.
  • Voir la licence : le contrat de licence.
  • À propos... : version, adresse de contact et bouton Visiter le site web.

Fonctionnalités principales

Avant de décrire, l'application repère les moments sans parole, même sous la musique (détection de la parole Silero, téléchargée une seule fois, environ 2 Mo, et exécutée sur votre ordinateur), ainsi que les changements de plan, puis demande à l'IA d'y placer les descriptions. Elle annonce le nombre approximatif de jetons avant d'envoyer la vidéo (Échap annule), et donne des nouvelles au moins toutes les 25 secondes pendant qu'elle travaille.

Le lecteur vidéo audiodécrit

C'est votre salle de cinéma personnelle et audiodécrite. Pendant la lecture, les descriptions sont lues au bon moment : par défaut par votre lecteur d'écran installé (comme JAWS ou NVDA), ou par la voix de l'application ou sur votre afficheur braille (voir « Descriptions dans le lecteur » dans Onglet Sortie audio). Le focus commence sur le bouton Lire. Dans l'ordre de Tab, le lecteur contient :

  • Le bouton Lire / Pause (il indique Rejouer à la fin de la vidéo) et le curseur de progression de la vidéo : les flèches sur le curseur déplacent dans la vidéo.
  • Les boutons Rembobiner de 5s (Alt + R) et Avancer de 5s (Alt + A), et le curseur Vol (le volume de la vidéo, mémorisé pour la prochaine fois).
  • Audiodescription actuelle : le texte de la description en cours de lecture ; vous pouvez le relire avec les touches de lecture de votre lecteur d'écran.
  • Utilisation des jetons IA : combien de « jetons » d'IA ont été utilisés, pour suivre votre consommation d'API.
  • Les boutons Explorer la scène..., En savoir plus..., Modifier les descriptions..., Paramètres... et Exporter..., décrits ci-dessous.

La plupart des actions ont aussi un raccourci d'une seule touche qui fonctionne où que soit le focus : voir Raccourcis clavier (ou appuyez sur F1 ou ? dans le lecteur pour les entendre). À la fermeture du lecteur, il vous demande s'il faut enregistrer le projet en cas de modification ; une vidéo téléchargée est supprimée à la fermeture, sauf si vous avez enregistré un projet (la vidéo est alors copiée à côté du projet).

Paramètres > Sortie audio, « Descriptions dans le lecteur » : votre lecteur d'écran (parole et braille, par défaut) ; la voix de l'application choisie plus haut, préparée à l'avance pour que la vidéo soit baissée ou mise en pause exactement le temps qu'il faut ; ou le braille seul, où la vidéo se met en pause après chaque description jusqu'à ce que vous appuyiez sur Entrée. « Afficher aussi les descriptions en gros caractères sur la vidéo » affiche chaque description sur l'image, avec la taille et la couleur de votre choix, pour les spectateurs malvoyants.

Modifier les descriptions : le pouvoir d'affiner

L'IA fournit un excellent point de départ, mais la vraie qualité vient du travail d'affinage. Le bouton « Modifier les descriptions... » du lecteur ouvre un éditeur puissant qui vous donne le contrôle total sur chaque aspect de votre projet. La vidéo doit d'abord être chargée.

  • Sélectionner et modifier : la liste du haut (Alt + L) contient une ligne par description : début, fin, texte, mots par seconde, statut de vérification et niveau. Sélectionner une ligne la charge en dessous et y déplace la vidéo. Entrée sur une ligne passe à son texte.
  • Ajuster les horodatages : modifiez les champs Start et End (HH:MM:SS.mmm), ou réglez-les sur la position du lecteur avec les boutons « Début = position du lecteur » (Alt + D ou Ctrl + [) et « Fin = position du lecteur » (Alt + F ou Ctrl + ]). Quand vous changez l'heure de début, l'heure de fin se décale automatiquement pour conserver la durée de la description. Toutes les heures sont vérifiées pour rester dans les limites de votre vidéo.
  • Réécrire le texte : modifiez librement le texte de la description pour le clarifier, ajouter des détails ou corriger des inexactitudes.
  • Statut de vérification et Notes du relecteur : marquez une description « À vérifier » ou « Validée » et ajoutez une note ; les deux sont enregistrés avec le projet et figurent dans le script de production Word.
  • Ajouter nouveau... (Alt + A) : ouvre une petite fenêtre où vous saisissez le début, la fin et le texte d'une nouvelle description ; le début est la position actuelle du lecteur.
  • Supprimer (Alt + S, ou Suppr dans la liste) : supprime la description sélectionnée après confirmation.
  • Personnages... (Alt + P) : ouvre le glossaire des personnages, voir Les personnages et leurs voix.
  • Écouter avec la voix d'export (Alt + C ou Ctrl + R) : lit le texte avec la voix utilisée dans les exports audio, dictionnaire de prononciation compris.
  • Enregistrer les modifications (Alt + E ou Ctrl + S) et Fermer (ou Échap).
  • Raccourcis : F8 / Maj+F8 : description suivante / précédente à vérifier. Ctrl+P : lire ou mettre en pause la vidéo. Alt+Gauche / Alt+Droite : déplacer la vidéo d'1 seconde. Ctrl+Z / Ctrl+Y dans la liste : annuler / rétablir. Ctrl+G sur une réplique traduite : changer la voix du locuteur (indéterminé, femme, homme). Les heures se tapent au format HH:MM:SS.mmm (MM:SS ou des secondes fonctionnent aussi) ; passer à une autre description conserve vos modifications, et la fermeture vous demande s'il en reste de non enregistrées.
Enregistrez votre travail : quand vous fermez l'éditeur, votre liste de descriptions mise à jour revient au lecteur et sert à la lecture et aux exports. Pour la conserver après la fermeture du lecteur, enregistrez le projet dans le lecteur avec Ctrl + S.

Pour une relecture professionnelle, chaque description a un statut (à vérifier ou validée) et des notes du relecteur, enregistrés avec le projet. Après la génération, une vérification par l'IA marque aussi les descriptions qui ne sont pas au présent, qui interprètent des sentiments au lieu de décrire ce qu'on voit, ou qui sortent de la fiction (noms d'acteurs, jargon technique) ; elles apparaissent avec « Vérifier » dans l'éditeur, et la touche V du lecteur les compte. Modifier le texte efface ces marques. Les entrées trop longues pour leur pause ou qui tombent sur un dialogue commencent aussi par « Vérifier ».

Les personnages et leurs voix

L'IA tient un glossaire des personnages pour que chaque personne soit décrite de la même façon tout au long de la vidéo et ne soit nommée qu'une fois son nom prononcé ou affiché. Ouvrez-le depuis l'éditeur avec Personnages... (Alt + P).

  • La liste affiche l'ID, le nom (« Non nommé » tant qu'il n'est pas révélé), la description et la voix de chaque personnage. Entrée modifie le personnage sélectionné, Suppr le supprime (après confirmation).
  • Ajouter... (Alt + A), Modifier... (Alt + M), Supprimer (Alt + S), puis OK pour garder vos modifications ou Annuler.
  • Dans la fiche du personnage : Identifiant (un identifiant unique, obligatoire), Nom (laissez-le vide s'il n'est pas encore révélé), Description (comment le reconnaître, obligatoire).
  • Voix pour les répliques traduites de ce personnage : quand des dialogues en langue étrangère sont traduits (voir sous-titres audio), choisissez quelle voix lit les répliques de ce personnage dans les exports audio et avec la voix de l'application :
    • Automatique (par défaut) : le genre apparent de la personne qui parle, réplique par réplique.
    • Voix de femme ou Voix d'homme : toujours cette voix pour ce personnage.
    • Voix des descriptions : la même voix que les descriptions.
    L'étiquette se termine par « genre selon l'IA : femme », « homme » ou « indéterminé » : le genre perçu par l'IA, que votre choix remplace sans l'effacer.
  • Donner un nouveau nom à un personnage le renomme aussi dans toutes les descriptions ; l'application indique combien de descriptions ont été mises à jour.

Pour réutiliser les personnages d'un épisode précédent, utilisez Fichier > Réutiliser les personnages d'un projet (Ctrl + G) avant de décrire le suivant.

Gérer les préréglages d'invite

Les invites sont des instructions supplémentaires qui indiquent à l'IA sur quoi se concentrer. En changeant d'invite, vous pouvez obtenir des descriptions de styles très différents.

  • Choisir un préréglage : avant de traiter une vidéo, choisissez un préréglage dans la liste des invites de la fenêtre principale.
  • Gérer les préréglages : allez dans Fichier > Gérer les préréglages d'invite.... La liste affiche le nom et le texte de chaque préréglage. Boutons : Ajouter... (Alt + A), Modifier... (Alt + M, ou Entrée sur un préréglage), Supprimer (Alt + S), Exporter... (Alt + X), Importer... (Alt + I) et Fermer. Un préréglage a un nom et un texte d'invite, tous deux obligatoires.
  • Une liste par langue d'interface : la fenêtre gère les préréglages de la langue d'interface actuelle (elle l'indique en haut). Passer l'interface dans une autre langue affiche la liste de cette langue.

Les préréglages existent dans les dix langues de l'interface. Les préréglages par défaut sont fournis avec l'application sous forme de fichiers JSON dans son dossier prompts, un fichier par langue (en.json, fr.json...) ; votre propre liste est enregistrée dans votre dossier de données (prompts.json). Exporter... enregistre vos préréglages dans un fichier JSON pour les partager avec d'autres audiodescripteurs ; Importer... ajoute les préréglages d'un tel fichier (un préréglage du même nom est remplacé). Fichier > Réinitialiser les paramètres et les données permet de retrouver les préréglages par défaut.

En savoir plus sur la scène

Vous vous demandez ce que tient un personnage ou ce que dit un panneau à l'arrière-plan ? Cette fonction vous permet de poser n'importe quelle question sur la scène. Elle utilise Gemini.

  1. Mettez la vidéo en pause au moment qui vous intrigue.
  2. Appuyez sur Q, ou sur le bouton En savoir plus....
  3. Tapez votre question dans le champ « Votre nouvelle question : » (par ex. « De quelle couleur est le chapeau de la femme ? » ou « Que dit l'inscription sur le mur ? »).
  4. Choisissez dans « Durée du contexte vidéo (secondes) » combien de secondes de vidéo autour du moment actuel l'IA doit analyser (1 à 60, 5 par défaut).
  5. Appuyez sur Soumettre la question (Alt + S). La réponse de l'IA apparaît dans la zone « Historique de la conversation », et vous pouvez poser des questions de suivi : l'IA se souvient de la conversation.
  6. Ajouter aux descriptions (Alt + A) ajoute la dernière réponse comme nouvelle description au moment actuel. Fermer revient au lecteur.

La touche W du lecteur demande directement « Qu'y a-t-il à l'écran en ce moment ? » et affiche la réponse dans cette fenêtre.

L'explorateur de scène

L'explorateur de scène vous dit ce qu'il y a dans l'image et où. Chaque objet est accompagné d'une position horaire : 12 heures est le haut de l'image, 3 heures le bord droit, 6 heures le bas. C'est une fenêtre ordinaire, lue par votre lecteur d'écran et votre afficheur braille. Elle utilise Gemini.

  1. Mettez la vidéo en pause sur une scène que vous voulez explorer en détail.
  2. Appuyez sur S, ou sur le bouton Explorer la scène....
  3. Dans les options, choisissez la « Durée de l'analyse (secondes) » (1 à 10, 3 par défaut) et tapez éventuellement sur quoi se concentrer, puis appuyez sur Analyser la scène (Entrée).

La fenêtre de l'explorateur de scène comporte trois parties ; passez de l'une à l'autre avec Tab :

  • Scène (Alt + S) : un résumé de toute la scène.
  • Objets (Alt + O) : les objets avec leur position horaire. Parcourir la liste joue un son placé à gauche ou à droite selon l'emplacement de l'objet (utilisez un casque stéréo).
  • Détails (Alt + D) : l'aspect de l'objet sélectionné et ce qu'il fait.
  • Échap : fermer l'explorateur de scène.

Images, PDF et votre écran

Fichier > Décrire une image ou un PDF (Ctrl+I) décrit une photo, une capture d'écran ou un document PDF : le sujet principal d'abord, les personnes, les couleurs et tout texte visible, lu exactement. Pour un PDF : la mise en page, les images, les graphiques et les tableaux avec leurs valeurs clés, puis un résumé par section. Le résultat s'ouvre dans une fenêtre que vous pouvez lire ligne par ligne, ou copier avec le bouton Copier (Alt + C). Images prises en charge : PNG, JPG, WEBP, GIF, BMP et HEIC.

Décrire mon écran (Ctrl+Alt+Maj+D) fonctionne depuis n'importe quelle application : un navigateur, un appel vidéo, un jeu. L'écran est capturé, décrit, et la réponse est lue par votre lecteur d'écran. La capture est ensuite supprimée.

Description de l'écran en continu (Ctrl+Alt+Maj+L, activer ou désactiver) vérifie l'écran toutes les 3 secondes et ne le décrit que lorsqu'il a sensiblement changé, en ne disant que ce qui est nouveau. Chaque description consomme votre quota d'API : désactivez-la quand vous n'en avez plus besoin.

Sous-titres audio : dans Paramètres > IA, « Traduire les dialogues dans une autre langue » ajoute la traduction des répliques en langue étrangère (anime en version originale, films étrangers), introduite par le nom de la personne qui parle. Comme le texte à l'écran, elles sont annoncées par un son bref et lues avec la seconde voix dans les exports ; avec « Lire les dialogues traduits avec une voix correspondant au locuteur », elles sont lues avec une voix de femme ou d'homme (voir Les voix).

Mode privé : dans Paramètres > IA, « Images et écran décrits par » peut utiliser un modèle local via Ollama (ollama.com) ou un service de vision compatible OpenAI au lieu de Gemini (voir Choisir l'IA). Avec Ollama, rien ne quitte votre ordinateur et aucun quota n'est consommé, mais les descriptions sont moins précises. Les documents PDF nécessitent toujours Gemini. Installez Ollama, puis lancez ollama pull gemma3 (ou choisissez un autre modèle de vision dans les paramètres).

Avec plusieurs écrans, c'est l'écran qui affiche la fenêtre active qui est décrit. En mode continu, la nouvelle description attend une pause dans ce que l'ordinateur fait entendre (jusqu'à 8 secondes) avant d'être prononcée.

Ligne de commande et traitement par lots

Pour décrire de nombreux fichiers sans l'interface, utilisez la ligne de commande. Les dossiers sont traités fichier par fichier ; les images et les PDF reçoivent une description texte (name_description.txt). Les mêmes paramètres et la même clé API que l'application sont utilisés.

python -m audio_describer.cli film.mp4 episodes --lang fr --export vtt,srt,txt,project --out out

L'application installée a la même ligne de commande : OmniDescriber.exe --cli suivi des mêmes options. Toutes les options :

  • inputs : une ou plusieurs vidéos, images, PDF ou dossiers.
  • --lang : code de la langue des descriptions (fr, en, es...), pour cette exécution seulement ; par défaut : le réglage de l'application.
  • --export : liste séparée par des virgules parmi vtt, srt, txt, dapt, docx, project, mkv, mp4, mp3 et m4a. Par défaut : vtt,project.
  • --density low|medium|high : ne garde dans les exports que les descriptions essentielles (low) ou toutes (high, par défaut) ; le projet garde tout.
  • --extended : dans les exports audio et vidéo, met l'image en pause quand une description est plus longue que sa pause.
  • --no-credit : pas de mention parlée de l'IA à la fin des exports audio et vidéo.
  • --watch : reste actif et décrit chaque nouveau fichier copié dans les dossiers (une fois sa copie terminée). Ctrl + C arrête.
  • --out : dossier de sortie (par défaut : le dossier courant).
  • --prompt : instructions supplémentaires pour l'IA, comme un préréglage d'invite.

Évaluer une audiodescription

Appuyez sur E dans le lecteur pour ouvrir le questionnaire du guide de l'audiodescription 2020 du régulateur français de l'audiovisuel (CSA). La vidéo se met en pause. Le premier onglet sert à l'écoute sans l'image, le second à la vérification avec l'image (Ctrl + Tab change d'onglet). Notez chaque question de 1 à 5 (ou laissez-la « non noté ») et ajoutez des commentaires ; les valeurs mesurées (descriptions sur les dialogues, mots par seconde, descriptions incertaines, texte à l'écran) sont affichées à côté des questions qu'elles éclairent. Il n'y a pas de note globale : le guide considère qu'une moyenne n'a pas de sens. OK conserve les réponses avec le projet (enregistrez-le avec Ctrl+S), et Enregistrer le rapport (Alt + R) écrit un fichier texte.

Exporter votre travail

Une fois satisfait de vos descriptions, appuyez sur le bouton Exporter... du lecteur. Choisissez un format avec les flèches, réglez les options sous la liste, appuyez sur Continuer (Entrée) et choisissez où enregistrer. Les formats :

  • Vidéo avec une piste d'audiodescription séparée (MKV) : les pistes d'origine sont conservées, l'audiodescription est une piste audio supplémentaire.
  • Vidéo avec une piste d'audiodescription séparée (MP4) : la même chose, pour la plupart des lecteurs et téléphones.
  • Audio MP3 : vocalise vos descriptions avec la voix choisie dans les paramètres, les mixe avec le son d'origine et baisse le fond pendant les descriptions, pour créer un MP3 à écouter n'importe où.
  • Piste d'audiodescription seule (M4A) : seulement les descriptions vocalisées, placées à leurs heures.
  • Descriptions WebVTT (.vtt) : pour les lecteurs web et les plateformes.
  • Fichier de sous-titres SRT : les descriptions sous forme de sous-titres avec leurs heures, pour des lecteurs comme VLC.
  • Fichier texte brut (.txt) : une description par ligne, sans les heures.
  • Script d'audiodescription, W3C TTML DAPT (.ttml) : pour les outils professionnels d'audiodescription.
  • Script de production (Word .docx) : codes temporels, texte, niveau, statut et notes, pour la relecture.
  • Script complet (.txt) : l'IA transcrit les dialogues et les entrelace avec les descriptions, une alternative textuelle pour les lecteurs sourdaveugles (WCAG 1.2.8). Il utilise Gemini et peut prendre quelques minutes.

Les exports audio et vidéo nécessitent FFmpeg (inclus avec l'application) et vocalisent chaque description ; une fenêtre de progression permet de suivre et d'annuler l'export.

Options de la fenêtre d'export : Seulement les descriptions de la densité actuelle (Alt + D, activée par défaut) exporte ce que vous entendez dans le lecteur (touche D) ; Audiodescription étendue (Alt + T, MKV, MP4 et MP3 seulement ; activée par défaut quand le lecteur est en mode étendu) met l'image en pause quand une description est plus longue que sa pause, au lieu de la couper (la vidéo est réencodée et les sous-titres d'origine ne sont pas conservés) ; la mention parlée (Alt + M, formats audio et vidéo) ajoute à la fin une phrase indiquant que l'audiodescription a été générée par IA. Sans l'option étendue, le message de fin liste les descriptions qui ont été coupées. La piste d'audiodescription est nommée dans la langue des descriptions, les sous-titres de la source sont conservés si possible, et avec un son 5.1 les descriptions sont placées sur le canal central. Dans le lecteur, Maj + I enregistre l'introduction audio en MP3, à publier avant le programme.

Choisir l'IA : Gemini, Ollama ou un service compatible OpenAI

Dans Paramètres, onglet Paramètres IA, deux listes choisissent quelle IA regarde vos médias :

  • Descriptions vidéo : l'IA qui décrit les vidéos.
  • Images et écran décrits par : l'IA utilisée par Décrire une image ou un PDF, Décrire mon écran et Description de l'écran en continu.

Chaque liste propose trois choix :

  • Gemini (en ligne), le choix par défaut et le plus précis. Il reçoit toute la vidéo avec son son. Nécessite la clé API Gemini.
  • Ollama (local, gratuit, privé) : un modèle de vision qui tourne sur votre propre ordinateur via Ollama (ollama.com). La vidéo ne quitte jamais votre ordinateur et aucun quota n'est consommé, mais c'est plus lent et moins précis. Installez Ollama, puis un modèle de vision, par exemple ollama pull gemma3, et tapez le nom du modèle dans Modèle de vision Ollama (gemma3 par défaut ; llava ou qwen2.5vl fonctionnent aussi).
  • Service de vision compatible OpenAI : tout service qui parle l'API de chat d'OpenAI avec des images, en ligne ou sur votre ordinateur : OpenRouter, OpenAI, Mistral, Groq, Claude via OpenRouter, ou un serveur local comme LM Studio, llama.cpp ou vLLM. Remplissez trois champs :
    • Adresse du service de vision (compatible OpenAI) : l'adresse de l'API, par exemple https://openrouter.ai/api/v1 (par défaut), https://api.openai.com/v1, ou http://localhost:1234/v1 pour LM Studio. Un service en ligne doit utiliser https:// ; http:// n'est accepté que pour cet ordinateur (localhost, 127.0.0.1).
    • Modèle du service de vision : le nom du modèle tel que le service l'écrit, par exemple openai/gpt-5-mini sur OpenRouter. Ce doit être un modèle qui accepte les images.
    • Clé API du service de vision : la clé de ce service ; laissez-la vide pour un serveur local.

Avec Ollama ou un service compatible OpenAI, la vidéo n'est pas envoyée : des images fixes sont extraites de chaque partie de la vidéo, avec leurs heures, et envoyées au modèle.

Fonctions qui nécessitent Gemini : les documents PDF, En savoir plus (et la touche W), l'explorateur de scène, l'introduction audio (touche I) et l'export du script complet (transcription des dialogues) utilisent toujours Gemini. Quand « Descriptions vidéo » est réglé sur une autre IA, ces fonctions refusent de s'exécuter et vous le disent, pour que rien ne soit envoyé à Google à votre insu. Remettez « Descriptions vidéo » sur Gemini pour les utiliser.

Les voix

La voix choisie dans Paramètres, onglet Sortie audio, lit les descriptions dans les exports audio et vidéo, avec le bouton « Écouter » de l'éditeur, et dans le lecteur quand « Descriptions dans le lecteur » est réglé sur la voix de l'application. (Avec le mode lecteur d'écran par défaut, c'est la voix de votre lecteur d'écran qui les lit pendant la lecture.) Choisissez le Moteur de synthèse vocale avec les flèches ; les champs de ce moteur apparaissent en dessous. Appuyez sur Test dans le groupe « Tester la voix » pour entendre le texte tapé au-dessus.

  • TTS OpenAI (Haute Qualité) : des voix naturelles ; nécessite un compte OpenAI payant et la clé API OpenAI (onglet Paramètres IA). Choisissez un Préréglage de voix ; Gérer les préréglages de voix... permet d'ajouter, modifier et supprimer des préréglages, chacun avec un nom, une voix OpenAI de base (alloy, echo, fable, onyx, nova, shimmer, coral, ash, ballad, sage), une vitesse et des instructions sur le ton (« Parle d'un ton calme et chaleureux »).
  • SAPI5 (Voix 64 bits) et SAPI5 (Voix 32 bits) : les voix installées dans Windows, sans clé. Le choix 32 bits donne accès à des voix plus anciennes issues de systèmes passés.
  • Windows OneCore (voix modernes) : les voix modernes de Windows (celles qu'utilise le Narrateur), hors ligne, sans clé.
  • Pour SAPI5 et OneCore, choisissez la Voix et la Vitesse (50 à 200 %).
  • Voix neuronales Microsoft Azure (en ligne, clé requise) : champs Clé de la ressource Speech (d'une ressource Azure Speech), Région (par exemple westeurope), Voix (par exemple fr-FR-DeniseNeural), et éventuellement une Voix de femme et une Voix d'homme pour les dialogues traduits.
  • Google Cloud Text-to-Speech (en ligne, clé requise) : champs Clé API, Voix (par exemple fr-FR-Chirp3-HD-Aoede), et éventuellement une Voix de femme et une Voix d'homme pour les dialogues traduits.

Dialogues traduits lus avec une voix correspondant au locuteur

Quand des dialogues dans une autre langue sont traduits (sous-titres audio) et que Lire les dialogues traduits avec une voix correspondant au locuteur (femme ou homme) est cochée (par défaut), chaque réplique traduite est lue avec une voix de femme ou d'homme. L'application choisit, dans cet ordre :

  1. avec Azure ou Google, la voix de femme ou d'homme tapée dans les champs de ce moteur ;
  2. sinon la Voix de femme ou la Voix d'homme choisie sous la case à cocher : soit « Voix installée dans Windows (automatique) », qui prend une voix Windows de ce genre dans la langue des descriptions, soit une voix Piper locale. Les voix Piper sont des voix gratuites de haute qualité qui fonctionnent hors ligne sur votre ordinateur. Choisissez-en une dans la liste (sa taille est indiquée), puis appuyez sur Télécharger et écouter : elle est téléchargée une seule fois (environ 20 Mo, somme de contrôle vérifiée) et un extrait est joué. La liste affiche les voix Piper de la langue des descriptions ;
  3. si aucune n'est disponible, la voix habituelle des descriptions.

La voix attribuée à un locuteur peut être fixée par personnage (voir Les personnages et leurs voix) ou par réplique dans l'éditeur avec Ctrl + G.

Langue de l'interface et langue des descriptions

  • Langue de l'interface (Paramètres, onglet Général, « Langue de l'application ») : avec « Détection auto. au démarrage » (par défaut), l'application suit la langue d'affichage de Windows à chaque démarrage : changer la langue de Windows change donc celle de l'application au démarrage suivant. Choisissez une langue dans la liste pour la fixer. Un changement s'applique après le redémarrage de l'application. Langues disponibles : anglais, arabe, espagnol, français, italien, portugais, russe, turc, ukrainien et vietnamien.
  • Langue des descriptions (Paramètres, onglet Paramètres IA, « Langue des descriptions ») : la langue dans laquelle l'IA écrit. « Comme l'interface » (par défaut) suit la langue de l'interface ; vous pouvez choisir toute autre langue de la liste, par exemple une interface en français avec des descriptions en anglais pour un cours en anglais. L'option de ligne de commande --lang la remplace pour une exécution.

Les préréglages d'invite suivent la langue de l'interface ; les règles de l'IA suivent la langue des descriptions (voir Personnaliser les règles de l'IA).

Les paramètres en détail

La fenêtre Paramètres (Ctrl + ,, ou le bouton Paramètres de la fenêtre principale ou du lecteur) a trois onglets ; appuyez sur Ctrl + Tab pour passer de l'un à l'autre et sur Tab pour passer d'un champ à l'autre dans un onglet. En bas : Appliquer enregistre sans fermer (disponible dès que quelque chose a changé), OK enregistre et ferme, Annuler ferme sans enregistrer.

Onglet Général

  • Qualité de téléchargement des vidéos YouTube : Meilleure Disponible, ou de 1080p à 144p (360p par défaut). Une qualité plus basse se télécharge plus vite et suffit généralement à l'IA.
  • Langue de l'application (Nécessite un redémarrage) : voir Langue de l'interface et langue des descriptions.
  • Niveau de journalisation : Info (par défaut), Débogage (plus de détails, utile pour signaler un problème) ou Désactivé. Le fichier journal se trouve dans %LOCALAPPDATA%\OmniDescriber\logs.
  • Autoriser les descriptions à interrompre la parole en cours : cochée, une nouvelle description commence à être lue immédiatement, même si la précédente n'est pas terminée. Décochée (par défaut), chaque description se termine entièrement avant que la suivante ne commence.

Onglet Paramètres IA

  • Clé API Gemini et le bouton Tester la clé : voir Premiers pas.
  • Clé API OpenAI (pour TTS) : pour les voix OpenAI uniquement.
  • Fréquence d'images pour l'analyse IA : détermine combien d'images par seconde de la vidéo sont envoyées à l'IA : d'origine, 10, 5, 2 ou 1 IPS. Une valeur plus basse peut réduire nettement les coûts d'API et aider à éviter les limites de traitement, mais l'IA risque de manquer des actions très rapides.
  • Densité des descriptions à l'ouverture du lecteur : descriptions essentielles seulement, standard (par défaut), ou toutes les descriptions avec les détails. La touche D du lecteur la change à tout moment, sans nouvelle requête à l'IA.
  • Langue des descriptions : voir Langue de l'interface et langue des descriptions.
  • Style de description : Objectif (par défaut), ou Subjectif, évocateur.
  • Mettre l'accent sur : Général (par défaut), Personnages, Actions et instructions, Décors et ambiance, ou Texte à l'écran.
  • Nombre maximal de mots par description : une limite haute à la longueur de chaque description (40 par défaut) ; 0 signifie que seule la durée de la pause la limite.
  • Explicitation : Décrire seulement ce qui est visible ; Décrire et nommer (par défaut), par exemple le lieu ou un objet connu ; ou Décrire, nommer et expliquer brièvement.
  • Images et écran décrits par, Descriptions vidéo, Modèle de vision Ollama, Adresse du service de vision, Modèle du service de vision et Clé API du service de vision : voir Choisir l'IA.
  • Traduire les dialogues dans une autre langue (sous-titres audio) : désactivé par défaut ; voir sous-titres audio.
  • Vérifier les descriptions par une seconde passe de l'IA : activé par défaut ; une vérification sur le texte seul marque les descriptions incertaines « Vérifier » dans l'éditeur.
  • Mentionner les couleurs : activé par défaut ; décochez-le si les couleurs ne vous disent rien.
  • Modèle Gemini : une liste de modèles en lecture seule (le modèle par défaut est indiqué dans l'étiquette). Actualiser la liste des modèles (Alt + A) demande à Google quels modèles votre clé peut utiliser et remplit la liste.
  • Niveau de réflexion (Gemini 3 et suivants) : Bas (plus rapide, moins cher), Moyen (par défaut) ou Élevé (plus lent, pour les films complexes).
  • Température : la liberté de formulation de l'IA (0.3 par défaut). Des valeurs plus basses donnent des descriptions plus littérales et plus cohérentes. Une valeur qui n'est pas un nombre est remplacée par la valeur par défaut.
  • Envoyer uniquement la vidéo (sans audio) à l'IA : déconseillé : sans le son, l'IA ne peut plus éviter de parler par-dessus les dialogues.
  • Désactiver les filtres de sécurité (Utiliser avec prudence) : activé par défaut. Cela permet à l'IA de traiter des contenus qu'elle pourrait sinon signaler comme sensibles, mais le résultat reste soumis aux règles de sécurité fondamentales du fournisseur d'IA. Vous êtes responsable de l'usage que vous faites de cette fonction.
  • Activer la segmentation vidéo pour les vidéos longues : découpe la vidéo en parties, les analyse l'une après l'autre et assemble les résultats. Recommandé pour les vidéos longues. Durée du segment (secondes) (30 à 2400, 600 par défaut) n'est disponible que si la segmentation est cochée.
  • Détecter les pauses de la bande son avant de décrire (recommandé) : activé par défaut ; repère les moments sans parole pour y placer les descriptions.

Onglet Sortie audio

  • Moteur de synthèse vocale et ses champs (préréglage de voix OpenAI, voix et vitesse SAPI5/OneCore, clé, région et voix Azure ou Google), et le groupe Tester la voix : voir Les voix.
  • Dictionnaire de prononciation : une règle par ligne, comme Hermione = her-my-oh-nee, utilisé par la voix de l'application, les exports et le bouton d'écoute de l'éditeur (mots entiers, majuscules ou minuscules).
  • Mode d'audiodescription dans le lecteur : dans les pauses (la vidéo continue, par défaut), étendu (la vidéo se met en pause quand une description ne tient pas), ou à la demande (Entrée décrit le moment présent). M le change dans le lecteur.
  • Son d'origine baissé pendant les descriptions (-dB) : de combien le son de la vidéo est baissé pendant qu'une description est prononcée, dans le lecteur et les exports (9 dB par défaut ; 6 à 12 recommandé ; 0 = pas baissé). Maj+Haut et Maj+Bas le changent depuis le lecteur.
  • Niveau de la voix d'audiodescription dans les exports (dB) : rend la voix des descriptions plus forte ou plus faible que le programme dans les exports (-20 à +20, 0 = inchangé).
  • Dans les exports, lire le texte à l'écran avec une seconde voix, plus grave : activé par défaut, pour distinguer un panneau ou un titre lu d'une description.
  • Lire les dialogues traduits avec une voix correspondant au locuteur, Voix de femme, Voix d'homme et les boutons Télécharger et écouter : voir Dialogues traduits.
  • Descriptions dans le lecteur : Lecteur d'écran (parole et braille, par défaut) ; Voix de l'application ci-dessus, préparée à l'avance (minutage exact) ; ou Braille seul, la vidéo attend Entrée.
  • Afficher aussi les descriptions en gros caractères sur la vidéo, Taille du texte sur la vidéo (16 à 120, 40 par défaut) et Couleur du texte sur la vidéo (jaune, blanc ou cyan) : pour les spectateurs malvoyants.

Personnaliser les règles de l'IA

Tout ce que l'application envoie à l'IA en plus de votre préréglage d'invite est écrit dans un fichier texte que vous pouvez lire et modifier : les 12 règles professionnelles d'audiodescription (placer les descriptions dans les pauses, budget de mots, présent, objectivité, personnages, texte à l'écran, changements de scène, ne pas décrire ce qui s'entend, pas de censure, pas de révélations, s'adapter au contenu, niveaux), la liste des champs de sortie que l'IA doit renvoyer, et les lignes ajoutées par les réglages Style, Mettre l'accent sur, Explicitation, couleurs et sous-titres audio.

  • Le texte intégré se trouve dans prompts\rules\en.json dans le dossier de l'application (dans l'application installée, dans le dossier _internal à côté de OmniDescriber.exe). Ne modifiez pas ce fichier : il est remplacé par les mises à jour.
  • Pour changer les règles, créez un fichier nommé ad_rules.json dans votre dossier de données, %APPDATA%\Describer (tapez ceci dans la boîte de dialogue Exécuter de Windows, Windows + R, pour l'ouvrir). Copiez-y seulement les clés de en.json que vous voulez changer ; un fichier partiel convient, les autres clés gardent leur valeur intégrée. Conservez les espaces réservés entre accolades, comme {language} ou {max_words} : l'application les remplit. Une clé du mauvais type, ou un fichier qui n'est pas du JSON valide, est ignoré (et noté dans le journal), pour qu'une faute de frappe ne puisse pas bloquer les descriptions.
  • Quand la langue des descriptions n'est pas l'anglais, une traduction prompts\rules\<language>.json (par exemple fr.json) est utilisée si elle existe ; votre ad_rules.json s'applique par-dessus.
  • Le fichier est relu à chaque description : vos modifications s'appliquent à la description suivante sans redémarrer l'application.
  • Fichier > Réinitialiser les paramètres et les données, « Préréglages d'invite », supprime votre ad_rules.json (une copie de sauvegarde est conservée), pour que les règles intégrées s'appliquent à nouveau.

Réinitialiser les paramètres et les données

Fichier > Réinitialiser les paramètres et les données... rétablit un état propre. Cochez ce que vous voulez réinitialiser, puis appuyez sur Réinitialiser (Alt + R) et confirmez :

  • Paramètres (retour aux valeurs par défaut) (Alt + P) : tous les paramètres reprennent leur valeur par défaut. Vos clés API (Gemini, OpenAI, service de vision, Azure, Google) sont conservées...
  • ...sauf si vous cochez aussi Oublier aussi mes clés API (Alt + C), disponible seulement quand Paramètres est coché.
  • Préréglages d'invite (les préréglages personnalisés sont supprimés) (Alt + I) : les préréglages par défaut de toutes les langues reviennent, et votre ad_rules.json est supprimé.
  • Préréglages de voix OpenAI (Alt + V) : retour aux préréglages par défaut.
  • Voix et modèles téléchargés (Alt + T) : supprime les voix Piper et le modèle de détection de la parole ; ils sont téléchargés à nouveau si nécessaire.
  • Fichiers temporaires (Alt + O) : supprime le dossier temporaire propre à l'application (vidéos téléchargées et traitées), rien d'autre.

Avant de réinitialiser les paramètres ou les préréglages, une copie de sauvegarde des fichiers est enregistrée dans le sous-dossier backups de votre dossier de données, dans un dossier nommé d'après la date et l'heure : une réinitialisation par erreur peut donc être annulée en recopiant les fichiers. Les projets (.omniad) et les fichiers exportés ne sont jamais modifiés. Certains paramètres, comme la langue de l'interface, s'appliquent après le redémarrage de l'application.

Où sont stockées vos données

  • Dossier de données : %APPDATA%\Describer, c'est-à-dire C:\Users\<votre nom>\AppData\Roaming\Describer. Il contient vos paramètres et clés chiffrés (settings.dat2), vos préréglages d'invite (prompts.json), vos propres règles de l'IA (ad_rules.json, si vous l'avez créé) et le dossier backups.
  • Voix et modèles téléchargés, et le journal : %LOCALAPPDATA%\OmniDescriber (voix Piper, modèle de détection de la parole et dossier logs).
  • Fichiers temporaires : %TEMP%\OmniDescriber.
  • Projets et exports : là où vous les enregistrez.

Trucs et astuces pour de meilleurs résultats

Créer de belles audiodescriptions est un art. L'IA est une assistante efficace, mais vous obtiendrez les meilleurs résultats en la guidant correctement.

Le pouvoir des invites : vos notes de réalisation

L'application enseigne à l'IA un ensemble de règles fondamentales (comme ne pas parler par-dessus les dialogues ; voir Personnaliser les règles de l'IA). Voyez la zone Préréglage d'invite de l'écran principal comme l'endroit où vous donnez vos notes de réalisation pour cette vidéo précise. Une bonne note aide l'IA à se concentrer sur un style ou un détail particulier.
Astuce : l'invite « Priorité aux noms »
Dans une vidéo avec beaucoup de personnages, vous pouvez créer une invite personnalisée pour privilégier le suivi des noms : Ta priorité absolue pour cette vidéo est d'identifier et d'utiliser les bons noms des personnages dès qu'ils sont prononcés.
Astuce : l'invite « Décrire l'atmosphère »
Pour les films visuellement riches, guidez l'IA vers l'environnement : Concentre-toi sur la description du décor, de l'atmosphère et des détails de l'environnement. Mentionne l'éclairage, les couleurs et l'ambiance générale de la scène.

Ce qu'il faut éviter dans les invites

Évitez les instructions qui contredisent les principes fondamentaux de l'IA (ne décrire que le visuel, ne pas parler par-dessus les dialogues). Lui donner une instruction mal conçue peut produire de mauvais résultats.

  • Mauvaise invite : « Raconte-moi tout ce qui se passe. » C'est trop vague et peut amener l'IA à décrire des détails sans importance.
  • Mauvaise invite : « Dis-moi ce que disent les personnages. » Cela l'amènera à enfreindre la règle « uniquement le visuel ».

En résumé : utilisez les invites pour orienter l'attention de l'IA, pas pour changer les règles fondamentales d'une bonne audiodescription. Pour changer les règles elles-mêmes, utilisez ad_rules.json.

Questions fréquentes (FAQ)

Q : Mes clés API ne fonctionnent pas. Que faire ?
R : Vérifiez d'abord que vous avez bien copié la clé entière, et utilisez le bouton Tester la clé à côté de la clé Gemini. Pour OpenAI, assurez-vous d'avoir configuré un moyen de paiement dans votre compte, car leur service TTS n'est pas gratuit. Pour Gemini, assurez-vous que l'API est activée dans votre projet Google Cloud.

Q : Le traitement a échoué avec une erreur « MAX_TOKENS ». Qu'est-ce que cela signifie ?
R : Cela signifie que votre vidéo est trop longue ou trop complexe visuellement pour que l'IA la traite en une seule passe. C'est une limite de capacité, pas une erreur de contenu. La meilleure solution est d'aller dans Paramètres > Paramètres IA et d'activer « Activer la segmentation vidéo pour les vidéos longues ». La vidéo sera alors automatiquement découpée en parties plus petites et plus faciles à traiter pour l'IA.

Q : L'IA n'a pas pu générer de descriptions à cause des « filtres de sécurité ». Que puis-je faire ?
R : C'est un problème connu : le système de sécurité de l'IA peut se montrer trop prudent. Vous pouvez essayer plusieurs choses, dans l'ordre : 1) Allez dans Paramètres > Paramètres IA et vérifiez que « Désactiver les filtres de sécurité » est cochée. 2) Si cela échoue, essayez de réduire la « Fréquence d'images pour l'analyse IA » pour envoyer moins de données à l'IA. 3) En dernier recours, choisissez un modèle plus puissant dans la liste Modèle Gemini, comme gemini-4-argon. Il peut mieux gérer les contenus sensibles, mais il est plus lent et peut coûter plus cher si vous êtes sur une offre d'API payante.

Q : Certaines de mes anciennes voix manquent dans la liste SAPI5. Où sont-elles passées ?
R : Les systèmes Windows modernes sont en 64 bits, mais beaucoup de voix de synthèse classiques et appréciées étaient en 32 bits. Dans les paramètres, onglet « Sortie audio », vous trouverez des moteurs distincts « SAPI5 (Voix 64 bits) » et « SAPI5 (Voix 32 bits) ». Pour accéder à vos anciennes voix, choisissez simplement le moteur 32 bits.

Q : Pourquoi la génération des descriptions prend-elle autant de temps ?
R : La durée dépend de la longueur de votre vidéo, de votre débit Internet (pour l'envoi à l'IA), de la fréquence d'images choisie et de la charge actuelle des services d'IA. La segmentation vidéo est vivement recommandée pour les vidéos longues. Vous pouvez arrêter à tout moment avec Échap.

Q : En savoir plus ou l'explorateur de scène indique « Cette fonction utilise Gemini ».
R : « Descriptions vidéo » est réglé sur Ollama ou sur un service compatible OpenAI. Ces fonctions ne marchent qu'avec Gemini ; remettez Gemini dans Paramètres > Paramètres IA pour les utiliser.

  • Ctrl + Alt + Maj + D : décrire mon écran, depuis n'importe quelle application
  • Ctrl + Alt + Maj + L : activer ou désactiver la description de l'écran en continu, depuis n'importe quelle application
  • Ctrl + W : ouvrir la plateforme web
  • Ctrl + , : ouvrir les paramètres

  • Ctrl + Maj + P : répéter le dernier message de progression
  • F1 : afficher l'aide
  • Alt + F4 : quitter

Dans le lecteur vidéo

Ces touches fonctionnent quel que soit le contrôle qui a le focus, sauf que les zones de texte de la description et des jetons gardent leurs propres touches de lecture, et que les flèches continuent de régler le curseur de volume quand il a le focus. F1, Ctrl+S et Alt+Gauche / Alt+Droite fonctionnent partout.

  • Espace : lecture / pause
  • Gauche / Droite : reculer / avancer de 5 secondes
  • Ctrl + Gauche / Droite : reculer / avancer de 30 secondes
  • Alt + Gauche / Droite : description précédente / suivante (s'y rend et la lit)
  • Haut / Bas : volume de la vidéo (par pas de 5)
  • R : répéter la dernière description
  • T : annoncer le temps actuel et la durée totale
  • A : activer ou désactiver l'audiodescription
  • D : changer la densité des descriptions : faible (l'essentiel seulement), moyenne, élevée (tous les détails). S'applique instantanément, sans nouvelle requête à l'IA.
  • M : mode d'audiodescription : dans les pauses (la vidéo continue), étendu (la vidéo se met en pause quand une description est trop longue pour sa pause, puis reprend), ou à la demande (rien n'est lu automatiquement)
  • Entrée (mode à la demande) : mettre en pause et décrire brièvement le moment présent ; Maj + Entrée : tout ce qui a été décrit dans les 15 dernières secondes
  • Entrée (mode braille seul) : reprendre la vidéo après une description
  • Q : en savoir plus sur le moment présent
  • S : explorer la scène actuelle
  • I : introduction audio : personnages principaux, leur apparence et les lieux, sans révélations, à écouter avant le programme. Rédigée par l'IA la première fois, puis enregistrée avec le projet.
  • Maj + I : enregistrer l'introduction audio en MP3
  • V : rapport de qualité : nombre de descriptions, part respectant leur budget de mots, descriptions sur du son ou marquées incertaines par la vérification de l'IA, mots par seconde, plus long passage sans description.
  • W : ce qu'il y a à l'écran maintenant, texte visible compris. La réponse apparaît dans la fenêtre En savoir plus, où vous pouvez continuer à poser des questions : l'IA se souvient de la conversation.
  • E : évaluer cette audiodescription avec le questionnaire CSA 2020 ; les réponses sont enregistrées avec le projet et peuvent être exportées en rapport.
  • L : piste audio suivante de la vidéo (par exemple une audiodescription existante)
  • C : piste de sous-titres suivante, ou aucune
  • Maj+Haut / Maj+Bas : baisser plus ou moins la vidéo pendant qu'une description est prononcée (0 à 24 dB, par pas de 3 dB).
  • ? : comme F1 : énonce la liste des raccourcis du lecteur.
  • Ctrl + S : enregistrer le projet (Ctrl + Maj + S : enregistrer sous)
  • F1 : énoncer cette liste de raccourcis

Pendant qu'une description est prononcée, le volume de la vidéo est baissé de 9 dB (jamais coupé, réglable dans Paramètres > Sortie audio) puis remonté en douceur, comme le recommandent les guides professionnels d'audiodescription. Un son bref précède une description qui lit un texte à l'écran. En mode à la demande, un son discret signale qu'une description essentielle est disponible. En mode lecteur d'écran, les descriptions sont lues au volume de votre lecteur d'écran ; dans les exports, leur niveau se règle dans Paramètres > Sortie audio.

Dans l'éditeur de descriptions

  • F8 / Maj + F8 : description suivante / précédente à vérifier
  • Ctrl + P : lire ou mettre en pause la vidéo
  • Alt + Gauche / Droite : déplacer la vidéo d'1 seconde
  • Ctrl + [ / Ctrl + ] : régler le début / la fin sur la position du lecteur
  • Ctrl + R : écouter le texte avec la voix d'export
  • Ctrl + G : changer la voix du locuteur d'une réplique traduite (indéterminé, femme, homme)
  • Ctrl + S : enregistrer les modifications
  • Ctrl + Z / Ctrl + Y (hors des champs de texte) : annuler / rétablir
  • Suppr dans la liste : supprimer la description
  • Échap : fermer (propose d'enregistrer les modifications non enregistrées)
