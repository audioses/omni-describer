После месяцев напряжённой работы, бесчисленных испытаний и преодоления многих технических препятствий я разработал Omni Describer как воплощение этой мечты.

Что означает название?

Слово «Omni» в названии происходит из латыни и означает «всё» или «целое». Я выбрал это название, потому что не хотел, чтобы инструмент служил только одной цели. Да, Omni Describer прежде всего стремится сделать медиа доступными для незрячих и слабовидящих людей путём создания аудиоописаний. Однако его предназначение этим не ограничивается.

Это также инструмент для исследования. Кинокритик, студент, художник или любой, кто интересуется визуальными деталями, может использовать такие функции, как «Исследователь сцен» или «Спросить ещё», чтобы погрузиться в слои видео как никогда раньше. Omni Describer — это окно, через которое можно увидеть мир «глазами» ИИ и понять его по-другому. Короче говоря, это «описатель для всего и для всех».

Системные требования

Для наилучшей работы Omni Describer я рекомендую соответствовать следующим минимальным системным требованиям:

  • Операционная система: Windows 10 или новее (64-разрядная).
  • Оперативная память (RAM): не менее 4 ГБ.
  • Накопитель: не менее 500 МБ свободного места на диске для приложения и временных файлов.
  • Подключение к Интернету: требуется для онлайн-сервисов ИИ (Google Gemini, онлайн-сервис, совместимый с OpenAI), онлайн-голосов (OpenAI, Azure, Google) и загрузки видео. С локальным ИИ (Ollama или локальный OpenAI-совместимый сервер) и голосами Windows или Piper видео можно описывать, ничего не отправляя через Интернет.
  • Программа чтения с экрана: для полной доступности рекомендуется программа чтения с экрана, например JAWS, NVDA или Экранный диктор Windows.

Начало работы: настройка API-ключей

По умолчанию Omni Describer использует Google Gemini для анализа видео, поэтому перед началом работы вам нужен собственный API-ключ Gemini. У других сервисов ИИ и голосов есть свои ключи; они описаны в разделах Выбор ИИ и Голоса.

  1. Откройте настройки: откройте меню Файл (Alt + F) и выберите Настройки... или нажмите Ctrl + ,.
  2. Вкладка «Настройки ИИ»: нажмите Ctrl + Tab, чтобы перейти с вкладки «Общие» на вкладку «Настройки ИИ», затем войдите в неё клавишей Tab.
    • API-ключ Gemini: нужен для анализа видео с помощью Gemini. Вставьте ключ в это поле. Бесплатный ключ можно получить в Google AI Studio. Затем перейдите клавишей Tab к кнопке Проверить ключ (Alt + T): приложение сообщит, работает ли ключ и сколько моделей ему доступно.
    • API-ключ OpenAI (для TTS): нужен, только если вы выбираете голоса OpenAI. Без него можно пользоваться встроенными голосами Windows. Ключ можно получить на платформе OpenAI.
  3. Сохранение: нажмите Применить или OK, чтобы сохранить настройки. Теперь всё готово к работе!
Надёжное хранение: ваши API-ключи шифруются и надёжно хранятся на вашем компьютере в файле настроек приложения. Они никуда не отправляются, кроме как для прямого подключения к соответствующим сервисам ИИ.

При первом запуске, если ключ Gemini не задан (и не выбран локальный ИИ), приложение предлагает открыть страницу Google AI Studio и настройки. Ответьте «Да», вставьте ключ и нажмите Проверить ключ. При самом первом запуске вас также попросят принять лицензию («Согласен» или «Не согласен»).

Быстрый старт: создание первого описания

Приступим! Просто выполните эти простые шаги:

  1. Выберите шаблон запроса (необязательно): в главном окне перейдите клавишей Tab к списку «Необязательно: выберите шаблон запроса для улучшения генерации» и выберите шаблон клавишами со стрелками. Поле только для чтения после него показывает полный текст, который будет отправлен ИИ. Для первой попытки отлично подойдёт вариант «(Шаблон не выбран)».
  2. Выберите видео: нажмите Ctrl + O для видео на вашем компьютере, Ctrl + U для прямой ссылки на видеофайл или Ctrl + Y для ссылки на YouTube. Те же действия выполняют первые три кнопки главного окна (Alt + L, Alt + U, Alt + Y).
  3. Дождитесь описания: приложение при необходимости загружает видео, подготавливает его и отправляет ИИ. Следить за ходом работы можно в «Журнале состояний» (программа чтения с экрана также озвучивает основные этапы). Это может занять несколько минут в зависимости от длины видео. Ctrl + Shift + P повторяет последнее сообщение о ходе работы.

Когда процесс завершится, автоматически откроется видеоплеер с описаниями, и вы сможете насладиться только что описанным видео! Не забудьте сохранить проект клавишами Ctrl + S в плеере: иначе описания будут потеряны при его закрытии (перед закрытием плеер спросит вас).

Отмена описания

Пока создаётся описание, нажмите Escape в главном окне или кнопку Отменить генерацию (Alt + C; фокус переходит на неё при запуске генерации). Отмена работает на любом этапе: во время подготовки видео, во время его отправки (даже длительной), пока приложение ждёт повторной попытки после ошибки и пока работает ИИ. Приложение сообщает «Отмена...», а затем «Генерация отменена.» Закрытие приложения также останавливает идущую генерацию. Во время генерации меню «Файл» и кнопки выбора источника недоступны.

Главное окно и его меню

Главное окно содержит, в порядке перехода клавишей Tab:

  1. Кнопки Локальный видеофайл, Прямой URL видео и URL видео с YouTube для выбора видео, которое нужно описать.
  2. Открыть веб-платформу: открывает веб-версию Omni Describer в браузере (там API-ключ не нужен).
  3. Список шаблонов запросов и текст выбранного шаблона только для чтения (см. Управление шаблонами запросов).
  4. Журнал состояний — текст только для чтения обо всём, что сделало приложение; читайте его клавишами со стрелками.
  5. Кнопки Настройки..., Отменить генерацию (доступна только во время создания описания) и Выход.

Строка состояния внизу показывает текущий этап и, во время обработки, процент выполнения.

Меню «Файл»

Открывается клавишами Alt + F.

  • Открыть локальное видео... (Ctrl + O): выберите видеофайл на компьютере и опишите его.
  • Открыть видео по URL... (Ctrl + U): введите прямой адрес видеофайла (оканчивающийся на .mp4, .webm...). Он загружается, а затем описывается.
  • Открыть с YouTube... (Ctrl + Y): вставьте адрес YouTube. Качество загрузки задаётся в настройках, на вкладке «Общие».
  • Открыть проект... (Ctrl + P): снова открыть сохранённый проект (файл .omniad) в плеере, не обращаясь повторно к ИИ. Если видео было перемещено, приложение попросит указать, где оно находится.
  • Недавние проекты: подменю последних открытых или сохранённых проектов; нажмите цифру перед проектом, чтобы открыть его.
  • Импорт описаний из SRT или WebVTT...: открыть существующий сценарий описаний (.srt или .vtt). Приложение сообщает, сколько описаний найдено, а затем запрашивает видео, к которому они относятся. После этого их можно прослушать, отредактировать или экспортировать.
  • Описать изображение или PDF... (Ctrl + I), Описать мой экран (Ctrl + Alt + Shift + D) и Непрерывное описание экрана (Ctrl + Alt + Shift + L): см. Изображения, PDF и ваш экран.
  • Использовать персонажей из проекта... (Ctrl + G): для сериала выберите проект предыдущей серии; следующие описания начнутся с его персонажей, поэтому имена и описания останутся прежними.
  • Управление шаблонами запросов...: см. Управление шаблонами запросов.
  • Открыть веб-платформу... (Ctrl + W): открывает веб-версию в браузере.
  • Настройки... (Ctrl + ,): см. Подробный обзор настроек.
  • Сброс настроек и данных...: см. Сброс настроек и данных.
  • Выход (Alt + F4).

Меню «Справка»

  • Справка (F1): открывает это руководство в веб-браузере на языке интерфейса, если существует перевод.
  • Журнал изменений: что изменилось в каждой версии.
  • Участники: люди, которые помогли создать и перевести приложение.
  • Просмотр лицензии: лицензионное соглашение.
  • О программе...: версия, контактный адрес и кнопка «Посетить веб-сайт».

Основные функции

Перед описанием приложение находит моменты без речи, даже под музыкой (распознавание речи Silero, загружается один раз, около 2 МБ, и работает на вашем компьютере), и смены планов, а затем просит ИИ разместить описания именно там. Перед отправкой видео оно сообщает примерное количество токенов (Escape отменяет) и во время работы сообщает о ходе не реже чем раз в 25 секунд.

Видеоплеер с описаниями

Это ваш личный кинотеатр с описаниями. Во время воспроизведения видео описания зачитываются в нужные моменты: по умолчанию вашей установленной программой чтения с экрана (например, JAWS или NVDA), либо голосом приложения, либо на брайлевском дисплее (см. «Описания в плеере» в разделе Вкладка «Аудиовывод»). Фокус сначала находится на кнопке «Воспроизвести». В порядке перехода клавишей Tab плеер содержит:

  • Кнопку Воспроизвести / Пауза (в конце видео она называется «Повторить») и ползунок прогресса видео: клавиши со стрелками на ползунке перемещают по видео.
  • Кнопки Перемотать на 5s назад (Alt + R) и Вперед на 5s (Alt + F), а также ползунок Громк (громкость видео, запоминается до следующего раза).
  • Текущее аудиоописание: текст зачитываемого описания; его можно просмотреть клавишами чтения вашей программы чтения с экрана.
  • Использование токенов ИИ: сколько «токенов» ИИ было использовано; помогает следить за расходом API.
  • Кнопки Исследовать сцену..., Спросить еще..., Редактировать описания..., Настройки... и Экспорт..., каждая из которых описана ниже.

У большинства действий также есть однобуквенное сочетание, которое работает независимо от положения фокуса: см. Сочетания клавиш (или нажмите F1 или ? в плеере, чтобы прослушать их). При закрытии плеер спрашивает, сохранить ли проект, если что-то изменилось; загруженное видео удаляется при закрытии, если вы не сохранили проект (в этом случае видео копируется рядом с проектом).

Настройки > Аудиовывод, «Описания в плеере»: ваша программа чтения с экрана (речь и Брайль, по умолчанию); голос приложения, выбранный выше, подготовленный заранее, чтобы видео приглушалось или ставилось на паузу ровно на нужное время; или только Брайль, когда видео останавливается после каждого описания, пока вы не нажмёте Enter. «Также показывать описания крупным текстом на видео» выводит каждое описание поверх изображения, с выбранными вами размером и цветом, для слабовидящих зрителей.

Редактирование описаний: возможность доработки

ИИ даёт отличную отправную точку, но настоящее качество достигается доработкой. Кнопка «Редактировать описания...» в плеере открывает мощный редактор, который даёт полный контроль над каждым аспектом проекта. Сначала должно быть загружено видео.

  • Выбор и изменение: список вверху (Alt + L) содержит по одной строке на описание: начало, конец, текст, слов в секунду, статус проверки и уровень. Выбор строки загружает её ниже и перемещает видео в это место. Enter на строке переводит к её тексту.
  • Коррекция временных меток: редактируйте поля Start и End (ЧЧ:ММ:СС.ммм) или задайте их по позиции плеера кнопками «Начало = позиция плеера» (Alt + T или Ctrl + [) и «Конец = позиция плеера» (Alt + N или Ctrl + ]). При изменении времени начала время окончания автоматически сдвигается, чтобы сохранить длительность описания. Все значения времени проверяются, чтобы они оставались в пределах видео.
  • Переписывание текста: свободно редактируйте текст описания, чтобы сделать его яснее, добавить детали или исправить неточности.
  • Статус проверки и примечания проверяющего: отметьте описание как «Требует проверки» или «Утверждено» и добавьте примечание; и то и другое сохраняется в проекте и попадает в производственный сценарий Word.
  • Добавить... (Alt + A): открывает небольшое окно, где задаются начало, конец и текст нового описания; началом служит текущая позиция плеера.
  • Удалить (Alt + D или Delete в списке): удаляет выбранное описание после подтверждения.
  • Персонажи (Alt + H): открывает глоссарий персонажей, см. Персонажи и их голоса.
  • Прослушать голосом экспорта (Alt + R или Ctrl + R): воспроизводит текст голосом, используемым в аудиоэкспорте, с учётом словаря произношения.
  • Сохранить изменения (Alt + S или Ctrl + S) и Закрыть (или Escape).
  • Сочетания клавиш: F8 / Shift+F8: следующее / предыдущее описание на проверку. Ctrl+P: воспроизвести или поставить видео на паузу. Alt+Влево / Alt+Вправо: сдвинуть видео на 1 секунду. Ctrl+Z / Ctrl+Y в списке: отменить / повторить. Ctrl+G на строке переведённой реплики: сменить голос говорящего (неизвестен, женщина, мужчина). Время вводится в формате ЧЧ:ММ:СС.ммм (также подходят ММ:СС или секунды); переход к другому описанию сохраняет ваши изменения, а при закрытии редактор спросит, если что-то не сохранено.
Сохраняйте работу: когда вы закрываете редактор, обновлённый список описаний возвращается в плеер и используется для воспроизведения и экспорта. Чтобы сохранить его после закрытия плеера, сохраните проект в плеере клавишами Ctrl + S.

Для профессиональной проверки у каждого описания есть статус («Требует проверки» или «Утверждено») и примечания проверяющего, сохраняемые в проекте. После генерации проверка ИИ также помечает описания, написанные не в настоящем времени, интерпретирующие чувства вместо описания видимого или выходящие за рамки вымысла (имена актёров, операторский жаргон); в редакторе они отображаются с пометкой «Проверить», а клавиша V в плеере подсчитывает их. Изменение текста снимает эти пометки. Записи, слишком длинные для своей паузы или попадающие на диалог, также начинаются с пометки «Проверить».

Персонажи и их голоса

ИИ ведёт глоссарий персонажей, чтобы каждый человек описывался одинаково на протяжении всего видео и назывался по имени только после того, как его имя произнесено или показано. Откройте его из редактора кнопкой Персонажи (Alt + H).

  • В списке показаны ID, имя («Без имени», пока оно не раскрыто), описание и голос каждого персонажа. Enter редактирует выбранного персонажа, Delete удаляет его (после подтверждения).
  • Добавить... (Alt + A), Редактировать... (Alt + E), Удалить (Alt + D), затем OK, чтобы сохранить изменения, или Отмена.
  • В форме персонажа: ID (уникальный идентификатор, обязательно), Имя (оставьте пустым, если оно ещё не раскрыто), Описание (как его узнать, обязательно).
  • Голос для переведённых реплик этого персонажа: когда иноязычный диалог переводится (см. аудиосубтитры), выберите, каким голосом читаются реплики этого персонажа в аудиоэкспорте и голосом приложения:
    • Автоматически (по умолчанию): видимый пол говорящего в каждой реплике.
    • Женский голос или Мужской голос: всегда этот голос для данного персонажа.
    • Голос аудиоописания: тот же голос, что и у описаний.
    Подпись заканчивается словами «ИИ определил: женщина», «мужчина» или «не определено»: это пол, воспринятый ИИ, который ваш выбор переопределяет, не стирая его.
  • Если дать персонажу новое имя, оно также заменяется во всех описаниях; приложение сообщает, сколько описаний обновлено.

Чтобы использовать персонажей предыдущей серии, перед описанием следующей выберите Файл > Использовать персонажей из проекта (Ctrl + G).

Управление шаблонами запросов

Запросы (промпты) — это дополнительные инструкции, которые говорят ИИ, на чём сосредоточиться. Меняя запрос, можно получать описания в совершенно разных стилях.

  • Выбор шаблона: перед обработкой видео выберите шаблон в списке запросов главного окна.
  • Управление шаблонами: откройте Файл > Управление шаблонами запросов.... В списке показаны имя и текст каждого шаблона. Кнопки: Добавить... (Alt + A), Редактировать... (Alt + E или Enter на шаблоне), Удалить (Alt + D), Экспорт... (Alt + X), Импорт (Alt + I) и Закрыть. У шаблона есть имя и текст запроса; оба обязательны.
  • Отдельный список для каждого языка интерфейса: окно управляет шаблонами текущего языка интерфейса (вверху указано, какого именно). Если переключить интерфейс на другой язык, отобразится список этого языка.

Шаблоны существуют на десяти языках интерфейса. Шаблоны по умолчанию поставляются с приложением в виде JSON-файлов в папке prompts, по одному файлу на язык (en.json, fr.json...); ваш собственный список сохраняется в папке данных (prompts.json). Экспорт... сохраняет ваши шаблоны в JSON-файл, чтобы поделиться ими с другими авторами описаний; Импорт добавляет шаблоны из такого файла (шаблон с тем же именем заменяется). Файл > Сброс настроек и данных позволяет вернуть шаблоны по умолчанию.

Узнать больше о сцене

Хотите узнать, что держит персонаж или что написано на вывеске на заднем плане? Эта функция позволяет задать любой вопрос о сцене. Она использует Gemini.

  1. Поставьте видео на паузу в интересующий вас момент.
  2. Нажмите Q или кнопку Спросить еще....
  3. Введите вопрос в поле «Ваш новый вопрос:» (например, «Какого цвета шляпа у женщины?» или «Что написано на стене?»).
  4. В поле «Длительность контекста видео (секунды)» выберите, сколько секунд видео вокруг текущего момента должен проанализировать ИИ (от 1 до 60, по умолчанию 5).
  5. Нажмите Отправить вопрос (Alt + S). Ответ ИИ появится в области «История диалога», и вы можете задавать уточняющие вопросы: ИИ помнит разговор.
  6. Добавить в описания (Alt + A) добавляет последний ответ как новое описание в текущий момент. Закрыть возвращает в плеер.

Клавиша W в плеере напрямую спрашивает «Что сейчас на экране?» и показывает ответ в этом окне.

Исследователь сцен

Исследователь сцен сообщает, что находится на изображении и где. Для каждого объекта указано положение по циферблату: 12 часов — верх изображения, 3 часа — правый край, 6 часов — низ. Это обычное окно, которое читается программой чтения с экрана и брайлевским дисплеем. Функция использует Gemini.

  1. Поставьте видео на паузу на сцене, которую хотите подробно исследовать.
  2. Нажмите S или кнопку Исследовать сцену....
  3. В параметрах выберите «Длительность анализа (секунды)» (от 1 до 10, по умолчанию 3) и при желании укажите, на чём сосредоточиться, затем нажмите Анализировать сцену (Enter).

Окно исследователя сцен состоит из трёх частей; переходите между ними клавишей Tab:

  • Сцена (Alt + S): краткое описание всей сцены.
  • Объекты (Alt + O): объекты с их положением по циферблату. При перемещении по списку воспроизводится звук слева или справа в зависимости от того, где находится объект (используйте стереонаушники).
  • Подробности (Alt + D): как выглядит выбранный объект и что он делает.
  • Escape: закрыть исследователь сцен.

Изображения, PDF и ваш экран

Файл > Описать изображение или PDF... (Ctrl+I) описывает фотографию, снимок экрана или PDF-документ: сначала главный объект, затем люди, цвета и весь видимый текст, зачитанный дословно. Для PDF: макет, изображения, диаграммы и таблицы с их ключевыми значениями, затем краткое содержание по разделам. Результат открывается в окне, которое можно читать построчно или скопировать кнопкой Копировать (Alt + C). Поддерживаемые изображения: PNG, JPG, WEBP, GIF, BMP и HEIC.

Описать мой экран (Ctrl+Alt+Shift+D) работает из любого приложения: браузера, видеозвонка, игры. Экран захватывается и описывается, а ответ зачитывает программа чтения с экрана. После этого снимок удаляется.

Непрерывное описание экрана (Ctrl+Alt+Shift+L, включение и выключение) проверяет экран каждые 3 секунды и описывает его, только если он заметно изменился, сообщая лишь о новом. Каждое описание расходует вашу квоту API: выключайте функцию, когда она больше не нужна.

Аудиосубтитры: в разделе Настройки > Настройки ИИ параметр «Переводить диалоги на другом языке (аудиосубтитры)» добавляет перевод иноязычных реплик (аниме в оригинале, зарубежные фильмы) с указанием говорящего. Как и текст на экране, они предваряются коротким звуком и в экспорте читаются вторым голосом; с параметром «Читать переведённые реплики голосом, соответствующим говорящему (женщина или мужчина)» они читаются женским или мужским голосом (см. Голоса).

Конфиденциальный режим: в разделе Настройки > Настройки ИИ параметр «Изображения и экран описывает» может использовать вместо Gemini локальную модель через Ollama (ollama.com) или OpenAI-совместимый сервис распознавания изображений (см. Выбор ИИ). С Ollama ничего не покидает ваш компьютер и квота не расходуется, но описания менее точны. Для PDF-документов всегда нужен Gemini. Установите Ollama, затем выполните ollama pull gemma3 (или выберите другую модель распознавания изображений в настройках).

Если экранов несколько, описывается экран с активным окном. В непрерывном режиме новое описание ждёт паузы в том, что воспроизводит компьютер (до 8 секунд), прежде чем прозвучать.

Командная строка и пакетный режим

Чтобы описать много файлов без интерфейса, используйте командную строку. Папки обрабатываются файл за файлом; изображения и PDF получают текстовое описание (name_description.txt). Используются те же настройки и API-ключ, что и в приложении.

python -m audio_describer.cli film.mp4 episodes --lang fr --export vtt,srt,txt,project --out out

У установленного приложения та же командная строка: OmniDescriber.exe --cli, за которым следуют те же параметры. Все параметры:

  • inputs: одно или несколько видео, изображений, PDF или папок.
  • --lang: код языка описания (fr, en, es...) только для этого запуска; по умолчанию — настройка приложения.
  • --export: список через запятую из vtt, srt, txt, dapt, docx, project, mkv, mp4, mp3 и m4a. По умолчанию: vtt,project.
  • --density low|medium|high: оставляет в экспорте только основные описания (low) или все (high, по умолчанию); проект сохраняет всё.
  • --extended: в аудио- и видеоэкспорте останавливать изображение, если описание длиннее своей паузы.
  • --no-credit: без озвученного упоминания ИИ в конце аудио- и видеоэкспорта.
  • --watch: продолжать работу и описывать каждый новый файл, скопированный в папки (после завершения его копирования). Ctrl + C останавливает.
  • --out: папка вывода (по умолчанию — текущая папка).
  • --prompt: дополнительные инструкции для ИИ, как в шаблоне запроса.

Оценка аудиоописания

Нажмите E в плеере, чтобы открыть анкету из руководства по аудиоописанию 2020 года французского аудиовизуального регулятора (CSA). Видео ставится на паузу. Первая вкладка предназначена для прослушивания без изображения, вторая — для проверки с изображением (Ctrl + Tab переключает вкладки). Оцените каждый вопрос от 1 до 5 (или оставьте «без оценки») и добавьте комментарии; измеренные значения (описания поверх диалога, слов в секунду, сомнительные описания, текст на экране) показаны рядом с вопросами, к которым они относятся. Общей оценки нет: руководство считает среднее значение бессмысленным. OK сохраняет ответы в проекте (сохраните его клавишами Ctrl+S), а «Сохранить отчёт...» (Alt + R) записывает текстовый файл.

Экспорт вашей работы

Когда описания вас устраивают, нажмите кнопку Экспорт... в плеере. Выберите формат клавишами со стрелками, задайте параметры под списком, нажмите Продолжить (Enter) и выберите место сохранения. Форматы:

  • Видео с отдельной дорожкой аудиоописания (MKV): исходные дорожки сохраняются, описание добавляется отдельной звуковой дорожкой.
  • Видео с отдельной дорожкой аудиоописания (MP4): то же самое, для большинства плееров и телефонов.
  • Аудио MP3: озвучивает описания голосом, выбранным в настройках, смешивает его с исходным звуком и приглушает фон во время описаний, создавая MP3, который можно слушать где угодно.
  • Только дорожка аудиоописания (M4A): только озвученные описания, размещённые в своё время.
  • Описания WebVTT (.vtt): для веб-плееров и платформ.
  • Файл субтитров SRT: описания в виде субтитров с временными метками, для плееров вроде VLC.
  • Текстовый файл (.txt): одно описание на строку, без времени.
  • Сценарий W3C TTML DAPT (.ttml): для профессиональных инструментов аудиоописания.
  • Производственный сценарий (Word .docx): таймкоды, текст, уровень, статус и примечания, для проверки.
  • Полный сценарий (.txt): ИИ расшифровывает диалоги и чередует их с описаниями — текстовая альтернатива для слепоглухих читателей (WCAG 1.2.8). Использует Gemini и может занять несколько минут.

Для аудио- и видеоэкспорта нужен FFmpeg (входит в состав приложения), и каждое описание озвучивается; окно хода выполнения позволяет следить за экспортом и отменить его.

Параметры окна экспорта: Только описания текущей плотности (Alt + D, по умолчанию включено) экспортирует то, что вы слышите в плеере (клавиша D); Расширенное описание (Alt + X, только MKV, MP4 и MP3; по умолчанию включено, если плеер находится в расширенном режиме) останавливает изображение, когда описание длиннее своей паузы, вместо того чтобы обрезать его (видео перекодируется, а исходные субтитры не сохраняются); озвученные титры (Alt + R, аудио- и видеоформаты) добавляют в конце фразу о том, что аудиоописание создано ИИ. Без расширенного режима итоговое сообщение перечисляет обрезанные описания. Дорожка аудиоописания получает название на языке описания, субтитры источника по возможности сохраняются, а при звуке 5.1 описания размещаются в центральном канале. В плеере Shift + I сохраняет звуковое вступление в MP3 для публикации перед программой.

Выбор ИИ: Gemini, Ollama или OpenAI-совместимый сервис

В настройках, на вкладке «Настройки ИИ», два списка определяют, какой ИИ анализирует ваши материалы:

  • Описание видео: ИИ, который описывает видео.
  • Изображения и экран описывает: ИИ, используемый функциями «Описать изображение или PDF», «Описать мой экран» и «Непрерывное описание экрана».

В каждом списке три варианта:

  • Gemini (онлайн) — вариант по умолчанию и самый точный. Он получает всё видео вместе со звуком. Нужен API-ключ Gemini.
  • Ollama (локально, бесплатно, конфиденциально): модель распознавания изображений, работающая на вашем компьютере через Ollama (ollama.com). Видео никогда не покидает ваш компьютер и квота не расходуется, но работа медленнее и менее точна. Установите Ollama, затем модель распознавания изображений, например ollama pull gemma3, и введите имя модели в поле Модель распознавания изображений Ollama (по умолчанию gemma3; подходят также llava или qwen2.5vl).
  • OpenAI-совместимый сервис распознавания изображений: любой сервис, поддерживающий чат-API OpenAI с изображениями, онлайн или на вашем компьютере: OpenRouter, OpenAI, Mistral, Groq, Claude через OpenRouter или локальный сервер, например LM Studio, llama.cpp или vLLM. Заполните три поля:
    • Адрес сервиса распознавания изображений (OpenAI-совместимого): адрес API, например https://openrouter.ai/api/v1 (по умолчанию), https://api.openai.com/v1 или http://localhost:1234/v1 для LM Studio. Онлайн-сервис должен использовать https://; http:// допускается только для этого компьютера (localhost, 127.0.0.1).
    • Модель сервиса распознавания изображений: имя модели в том виде, в каком его пишет сервис, например openai/gpt-5-mini на OpenRouter. Модель должна принимать изображения.
    • API-ключ сервиса распознавания изображений: ключ этого сервиса; для локального сервера оставьте поле пустым.

С Ollama или OpenAI-совместимым сервисом видео не загружается: из каждой части видео берутся неподвижные кадры с указанием времени и отправляются модели.

Функции, которым нужен Gemini: PDF-документы, «Спросить еще» (и клавиша W), исследователь сцен, звуковое вступление (клавиша I) и экспорт полного сценария (расшифровка диалогов) всегда используют Gemini. Если в списке «Описание видео» выбран другой ИИ, эти функции отказываются работать и сообщают об этом, чтобы ничего не отправлялось в Google без вашего ведома. Чтобы пользоваться ими, снова выберите Gemini в списке «Описание видео».

Голоса

Голос, выбранный в настройках на вкладке Аудиовывод, читает описания в аудио- и видеоэкспорте, по кнопке «Прослушать» в редакторе и в плеере, если в параметре «Описания в плеере» выбран голос приложения. (В режиме по умолчанию, с программой чтения с экрана, описания во время воспроизведения читает голос вашей программы чтения с экрана.) Выберите Движок преобразования текста в речь клавишами со стрелками; поля этого движка появятся под ним. Нажмите Тест в группе «Проверить голос», чтобы прослушать текст, введённый над кнопкой.

  • OpenAI TTS (Высокое качество): естественные голоса; нужен платный аккаунт OpenAI и API-ключ OpenAI (вкладка «Настройки ИИ»). Выберите Шаблон голоса; Управление шаблонами голосов позволяет добавлять, изменять и удалять шаблоны, у каждого из которых есть имя, базовый голос OpenAI (alloy, echo, fable, onyx, nova, shimmer, coral, ash, ballad, sage), скорость и инструкции для тона («Говори спокойным, тёплым тоном»).
  • SAPI5 (64-битные голоса) и SAPI5 (32-битные голоса): голоса, установленные в Windows, ключ не нужен. Вариант 32 бита даёт доступ к старым голосам из прежних систем.
  • Windows OneCore (современные голоса): современные голоса Windows (те, что использует Экранный диктор), работают офлайн, ключ не нужен.
  • Для SAPI5 и OneCore выберите Голос и Скорость (от 50 до 200 %).
  • Microsoft Azure Neural Voices (онлайн, нужен ключ): поля Ключ ресурса Speech (из ресурса Azure Speech), Регион (например, westeurope), Голос (например, fr-FR-DeniseNeural) и при желании Женский голос и Мужской голос для переведённых реплик.
  • Google Cloud Text-to-Speech (онлайн, нужен ключ): поля API-ключ, Голос (например, fr-FR-Chirp3-HD-Aoede) и при желании Женский голос и Мужской голос для переведённых реплик.

Переведённые реплики голосом, соответствующим говорящему

Когда диалог на другом языке переводится (аудиосубтитры) и включён параметр Читать переведённые реплики голосом, соответствующим говорящему (женщина или мужчина) (по умолчанию), каждая переведённая реплика читается женским или мужским голосом. Приложение выбирает в таком порядке:

  1. с Azure или Google — женский или мужской голос, указанный в полях этого движка;
  2. иначе — Женский голос или Мужской голос, выбранный под флажком: либо «Голос, установленный в Windows (автоматически)», который берёт голос Windows соответствующего пола на языке описания, либо локальный голос Piper. Голоса Piper — бесплатные качественные голоса, работающие офлайн на вашем компьютере. Выберите голос в списке (указан его размер), затем нажмите Скачать и прослушать: он загружается один раз (около 20 МБ, контрольная сумма проверяется), и воспроизводится образец. В списке показаны голоса Piper для языка описания;
  3. если ничего из этого недоступно — обычный голос описаний.

Голос говорящего можно закрепить для персонажа (см. Персонажи и их голоса) или для отдельной реплики в редакторе клавишами Ctrl + G.

Язык интерфейса и язык описаний

  • Язык интерфейса (Настройки, вкладка «Общие», «Язык приложения»): с вариантом «Автоопределение при запуске» (по умолчанию) приложение при каждом запуске следует языку отображения Windows, поэтому смена языка Windows меняет язык приложения при следующем запуске. Выберите язык в списке, чтобы закрепить его. Изменение вступает в силу после перезапуска приложения. Доступны: английский, арабский, вьетнамский, испанский, итальянский, португальский, русский, турецкий, украинский и французский.
  • Язык описаний (Настройки, вкладка «Настройки ИИ», «Язык описаний»): язык, на котором пишет ИИ. «Как в интерфейсе» (по умолчанию) следует языку интерфейса; можно выбрать любой другой язык из списка, например французский интерфейс с описаниями на английском для англоязычной лекции. Параметр командной строки --lang переопределяет его для одного запуска.

Шаблоны запросов следуют языку интерфейса; правила ИИ следуют языку описаний (см. Настройка правил ИИ).

Окно настроек (Ctrl + , или кнопка «Настройки...» в главном окне или плеере) имеет три вкладки; нажимайте Ctrl + Tab для перехода между ними и Tab для перехода между полями вкладки. Внизу: Применить сохраняет без закрытия (доступна, когда что-то изменено), OK сохраняет и закрывает, Отмена закрывает без сохранения.

Вкладка «Общие»

  • Качество загрузки видео с YouTube: «Наилучшее доступное» или от 1080p до 144p (по умолчанию 360p). Более низкое качество загружается быстрее и обычно достаточно для ИИ.
  • Язык приложения (требуется перезапуск): см. Язык интерфейса и язык описаний.
  • Уровень логирования: Info (по умолчанию), «Отладка» (больше подробностей, полезно при сообщении о проблеме) или «Отключено». Файл журнала находится в %LOCALAPPDATA%\OmniDescriber\logs.
  • Разрешить описаниям прерывать текущую речь: если флажок установлен, новое описание начинает звучать сразу, даже если предыдущее ещё не закончилось. Если снят (по умолчанию), каждое описание полностью договаривается до начала следующего.

Вкладка «Настройки ИИ»

  • API-ключ Gemini и кнопка Проверить ключ: см. Начало работы.
  • API-ключ OpenAI (для TTS): только для голосов OpenAI.
  • Частота кадров для анализа ИИ: определяет, сколько кадров видео в секунду отправляется ИИ: исходная частота, 10, 5, 2 или 1 FPS. Меньшее значение может значительно снизить расходы на API и помочь избежать ограничений обработки, но ИИ может пропустить очень быстрые действия.
  • Плотность описаний при открытии плеера: только важнейшие описания, стандартная (по умолчанию) или все описания с деталями. Клавиша D в плеере меняет её в любой момент без нового запроса к ИИ.
  • Язык описаний: см. Язык интерфейса и язык описаний.
  • Стиль описаний: «Объективный» (по умолчанию) или «Субъективный, образный».
  • Фокус: «Общее» (по умолчанию), «Персонажи», «Действия и инструкции», «Обстановка и атмосфера» или «Текст на экране».
  • Максимум слов в описании: верхний предел длины каждого описания (по умолчанию 40); 0 означает, что длину ограничивает только пауза.
  • Степень пояснения: «Описывать только видимое»; «Описывать и называть» (по умолчанию), например место или известный предмет; или «Описывать, называть и кратко пояснять».
  • Изображения и экран описывает, Описание видео, Модель распознавания изображений Ollama, Адрес сервиса распознавания изображений, Модель сервиса распознавания изображений и API-ключ сервиса распознавания изображений: см. Выбор ИИ.
  • Переводить диалоги на другом языке (аудиосубтитры): по умолчанию выключено; см. аудиосубтитры.
  • Проверять описания вторым проходом ИИ: по умолчанию включено; текстовая проверка помечает сомнительные описания в редакторе как «Проверить».
  • Упоминать цвета: по умолчанию включено; снимите флажок, если цвета для вас ничего не значат.
  • Модель Gemini: список моделей только для чтения (модель по умолчанию указана в подписи). Обновить список моделей (Alt + R) запрашивает у Google, какие модели доступны вашему ключу, и заполняет список.
  • Уровень рассуждений (Gemini 3 и новее): «Низкий» (быстрее, дешевле), «Средний» (по умолчанию) или «Высокий» (медленнее, для сложных фильмов).
  • Температура: насколько свободен ИИ в формулировках (по умолчанию 0.3). Меньшие значения дают более буквальные и единообразные описания. Значение, не являющееся числом, заменяется значением по умолчанию.
  • Отправлять ИИ только видео (без звука): не рекомендуется: без звука ИИ больше не может избегать наложения на диалог.
  • Отключить фильтры безопасности (использовать с осторожностью): по умолчанию включено. Это позволяет ИИ обрабатывать материалы, которые иначе он мог бы пометить как деликатные, но результат по-прежнему подчиняется основным правилам безопасности поставщика ИИ. Вы несёте ответственность за то, как используете эту функцию.
  • Включить разделение на фрагменты для длинных видео: разбивает видео на части, анализирует их одну за другой и объединяет результаты. Рекомендуется для длинных видео. Длительность фрагмента (секунды) (от 30 до 2400, по умолчанию 600) доступна, только когда разделение включено.
  • Искать паузы в звуковой дорожке перед описанием (рекомендуется): по умолчанию включено; находит моменты без речи, чтобы разместить там описания.

Вкладка «Аудиовывод»

  • Движок преобразования текста в речь и его поля (шаблон голоса OpenAI, голос и скорость SAPI5/OneCore, ключ, регион и голоса Azure или Google), а также группа Проверить голос: см. Голоса.
  • Словарь произношения: одно правило на строку, например Hermione = her-my-oh-nee; используется голосом приложения, при экспорте и кнопкой прослушивания в редакторе (целые слова, без учёта регистра).
  • Режим аудиоописания в плеере: в паузах (видео продолжает воспроизводиться, по умолчанию), расширенный (видео останавливается, если описание не помещается) или по запросу (Enter описывает текущий момент). Клавиша M меняет его в плеере.
  • Приглушение исходного звука во время описаний (-дБ): насколько приглушается звук видео во время описания в плеере и при экспорте (по умолчанию 9 дБ; рекомендуется от 6 до 12; 0 = без приглушения). Shift+Вверх и Shift+Вниз меняют его из плеера.
  • Уровень голоса аудиоописания при экспорте (дБ): делает голос описаний громче или тише программы при экспорте (от -20 до +20, 0 = без изменений).
  • При экспорте читать текст на экране вторым, более низким голосом: по умолчанию включено, чтобы можно было отличить зачитанную вывеску или заголовок от описания.
  • Читать переведённые реплики голосом, соответствующим говорящему, Женский голос, Мужской голос и кнопки Скачать и прослушать: см. Переведённые реплики.
  • Описания в плеере: «Программа экранного доступа (речь и Брайль)» (по умолчанию); «Голос приложения, выбранный выше, подготовленный заранее (точная синхронизация)»; или «Только Брайль, видео ждёт нажатия Enter».
  • Также показывать описания крупным текстом на видео, Размер текста на видео (от 16 до 120, по умолчанию 40) и Цвет текста на видео (жёлтый, белый или голубой): для слабовидящих зрителей.

Настройка правил ИИ

Всё, что приложение отправляет ИИ помимо вашего шаблона запроса, записано в текстовом файле, который можно прочитать и изменить: 12 профессиональных правил аудиоописания (размещать описания в паузах, лимит слов, настоящее время, объективность, персонажи, текст на экране, смена сцен, не описывать то, что слышно, без цензуры, без спойлеров, адаптация к содержанию, уровни), список полей вывода, которые должен вернуть ИИ, и строки, добавляемые настройками «Стиль описаний», «Фокус», «Степень пояснения», цветов и аудиосубтитров.

  • Встроенный текст находится в prompts\rules\en.json в папке приложения (в установленном приложении — внутри папки _internal рядом с OmniDescriber.exe). Не редактируйте этот файл: он заменяется при обновлениях.
  • Чтобы изменить правила, создайте файл с именем ad_rules.json в папке данных %APPDATA%\Describer (введите этот путь в окне «Выполнить» Windows, Windows + R, чтобы открыть её). Скопируйте в него из en.json только те ключи, которые хотите изменить; неполный файл допустим, остальные ключи сохраняют встроенное значение. Сохраняйте заполнители в фигурных скобках, например {language} или {max_words}: их подставляет приложение. Ключ неверного типа или файл с недопустимым JSON игнорируется (с записью в журнал), поэтому опечатка не может остановить создание описаний.
  • Если язык описаний не английский, используется перевод prompts\rules\<language>.json (например, fr.json), если он существует; ваш ad_rules.json применяется поверх него.
  • Файл перечитывается для каждого описания: ваши правки применяются к следующему описанию без перезапуска приложения.
  • Файл > Сброс настроек и данных, пункт «Шаблоны запросов», удаляет ваш ad_rules.json (резервная копия сохраняется), и снова действуют встроенные правила.

Сброс настроек и данных

Файл > Сброс настроек и данных... восстанавливает чистое состояние. Отметьте, что нужно сбросить, затем нажмите Сбросить (Alt + R) и подтвердите:

  • Настройки (вернуть значения по умолчанию) (Alt + S): все настройки возвращаются к значениям по умолчанию. Ваши API-ключи (Gemini, OpenAI, сервис распознавания изображений, Azure, Google) сохраняются...
  • ...если только вы не отметите также Также забыть мои API-ключи (Alt + A); этот пункт доступен, только когда отмечены «Настройки».
  • Шаблоны запросов (пользовательские шаблоны удаляются) (Alt + P): возвращаются шаблоны по умолчанию для всех языков, а ваш ad_rules.json удаляется.
  • Шаблоны голосов OpenAI (Alt + V): возврат к шаблонам по умолчанию.
  • Загруженные голоса и модели (Alt + D): удаляет голоса Piper и модель распознавания речи; при необходимости они загружаются снова.
  • Временные файлы (Alt + T): удаляет собственную временную папку приложения (загруженные и обработанные видео) и больше ничего.

Перед сбросом настроек или шаблонов резервная копия файлов сохраняется в подпапке backups папки данных, в папке с датой и временем в названии, поэтому ошибочный сброс можно отменить, скопировав файлы обратно. Проекты (.omniad) и экспортированные файлы никогда не затрагиваются. Некоторые настройки, например язык интерфейса, вступают в силу после перезапуска приложения.

Где хранятся ваши данные

  • Папка данных: %APPDATA%\Describer, то есть C:\Users\<ваше имя>\AppData\Roaming\Describer. Она содержит ваши зашифрованные настройки и ключи (settings.dat2), шаблоны запросов (prompts.json), ваши собственные правила ИИ (ad_rules.json, если вы его создали) и папку backups.
  • Загруженные голоса и модели, а также журнал: %LOCALAPPDATA%\OmniDescriber (голоса Piper, модель распознавания речи и папка logs).
  • Временные файлы: %TEMP%\OmniDescriber.
  • Проекты и экспорт: там, где вы их сохраняете.

Советы и приёмы для лучших результатов

Создание хороших аудиоописаний — это искусство. ИИ — эффективный помощник, но лучших результатов вы добьётесь, если будете правильно им руководить.

Сила запросов: ваши режиссёрские заметки

У приложения есть набор основных правил, которым оно обучает ИИ (например, не говорить поверх диалога; см. Настройка правил ИИ). Считайте область шаблона запроса в главном окне местом, где вы даёте свои режиссёрские заметки для конкретного видео. Хорошая заметка помогает ИИ сосредоточиться на определённом стиле или детали.
Совет: запрос «Сосредоточься на именах»
В видео с множеством персонажей можно создать собственный запрос, чтобы приоритетом было отслеживание имён: Твой главный приоритет в этом видео — определять и использовать правильные имена персонажей, как только они прозвучат.
Совет: запрос «Опиши атмосферу»
Для визуально насыщенных фильмов направьте ИИ на описание окружения: Сосредоточься на описании обстановки, атмосферы и деталей окружения. Упоминай освещение, цвета и общее настроение сцены.

Чего избегать в запросах

Избегайте инструкций, противоречащих основным принципам ИИ (описывать только визуальное, не говорить поверх диалога). Ошибочная инструкция может привести к плохим результатам.

  • Плохой запрос: «Расскажи мне всё, что происходит». Это слишком расплывчато и может заставить ИИ описывать неважные детали.
  • Плохой запрос: «Расскажи, что говорят персонажи». Это заставит его нарушить правило «только визуальное».

Короче говоря: используйте запросы, чтобы направлять внимание ИИ, а не чтобы менять основные правила хорошего аудиоописания. Чтобы изменить сами правила, используйте ad_rules.json.

Часто задаваемые вопросы (FAQ)

В: Мои API-ключи не работают. Что делать?
О: Сначала убедитесь, что вы правильно скопировали весь ключ, и воспользуйтесь кнопкой Проверить ключ рядом с ключом Gemini. Для OpenAI убедитесь, что в вашем аккаунте настроен способ оплаты, так как их сервис TTS не бесплатный. Для Gemini убедитесь, что API включён в вашем проекте Google Cloud.

В: Процесс завершился ошибкой «MAX_TOKENS». Что это значит?
О: Это значит, что ваше видео слишком длинное или визуально сложное, чтобы ИИ обработал его за один проход. Это ограничение ёмкости, а не ошибка содержимого. Лучшее решение — открыть Настройки > Настройки ИИ и включить «Включить разделение на фрагменты для длинных видео». Видео будет автоматически разделено на более мелкие и удобные для ИИ части.

В: ИИ не смог создать описания из-за «фильтров безопасности». Что можно сделать?
О: Это известная проблема: система безопасности ИИ бывает излишне осторожной. Попробуйте по порядку: 1) Откройте Настройки > Настройки ИИ и убедитесь, что флажок «Отключить фильтры безопасности» установлен. 2) Если это не помогло, уменьшите «Частоту кадров для анализа ИИ», чтобы отправлять ИИ меньше данных. 3) В крайнем случае выберите более мощную модель в списке Модель Gemini, например gemini-4-argon. Она может лучше справляться с деликатным содержимым, но работает медленнее и может стоить дороже, если вы используете платный тариф API.

В: Некоторых моих старых голосов нет в списке SAPI5. Куда они делись?
О: Современные системы Windows 64-разрядные, но многие классические любимые голоса синтеза речи были 32-разрядными. В настройках на вкладке «Аудиовывод» есть отдельные варианты движка: «SAPI5 (64-битные голоса)» и «SAPI5 (32-битные голоса)». Чтобы получить доступ к старым голосам, просто выберите 32-битный движок.

В: Почему создание описаний занимает так много времени?
О: Время зависит от длины видео, скорости Интернета (для отправки ИИ), выбранной частоты кадров и текущей нагрузки на сервисы ИИ. Для длинных видео настоятельно рекомендуется разделение на фрагменты. Остановить процесс можно в любой момент клавишей Escape.

В: «Спросить еще» или исследователь сцен сообщает: «Эта функция использует Gemini».
О: В списке «Описание видео» выбран Ollama или OpenAI-совместимый сервис. Эти функции работают только с Gemini; чтобы пользоваться ими, снова выберите Gemini в разделе Настройки > Настройки ИИ.

  • Ctrl + Alt + Shift + L: Включить или выключить непрерывное описание экрана, из любого приложения
  • Ctrl + W: Открыть веб-платформу
  • Ctrl + ,: Открыть настройки
  • Escape: Отменить текущую генерацию
  • Ctrl + Shift + P: Повторить последнее сообщение о ходе работы
  • F1: Справка
  • Alt + F4: Выход

В видеоплеере

Эти клавиши работают независимо от того, какой элемент в фокусе, за исключением того, что текстовые поля описания и токенов сохраняют собственные клавиши чтения, а стрелки продолжают регулировать ползунок громкости, когда он в фокусе. F1, Ctrl+S и Alt+Влево / Alt+Вправо работают везде.

  • Пробел: Воспроизведение / пауза
  • Стрелка влево / Стрелка вправо: Назад / вперёд на 5 секунд
  • Ctrl + Стрелка влево / Стрелка вправо: Назад / вперёд на 30 секунд
  • Alt + Стрелка влево / Стрелка вправо: Предыдущее / следующее описание (переход к нему и его чтение)
  • Стрелка вверх / Стрелка вниз: Громкость видео (с шагом 5)
  • R: Повторить последнее описание
  • T: Сообщить текущее время и общую длительность
  • A: Включить или выключить аудиоописание
  • D: Изменить плотность описаний: низкая (только самое важное), средняя, высокая (все детали). Применяется сразу, без нового запроса к ИИ.
  • M: Режим аудиоописания: в паузах (видео продолжает воспроизводиться), расширенный (видео приостанавливается, если описание слишком длинное для своей паузы, затем продолжается) или по запросу (ничего не читается автоматически)
  • Enter (режим по запросу): приостановить и кратко описать текущий момент; Shift + Enter: всё, что было описано за последние 15 секунд
  • Enter (режим «только Брайль»): продолжить видео после описания
  • Q: Спросить еще о текущем моменте
  • S: Исследовать текущую сцену
  • I: Звуковое вступление: главные персонажи, их внешность и места действия, без спойлеров, для прослушивания перед программой. ИИ составляет его при первом нажатии, затем оно сохраняется в проекте.
  • Shift + I: Сохранить звуковое вступление в MP3
  • V: Отчёт о качестве: число описаний, доля в пределах лимита слов, описания поверх звука или отмеченные проверкой ИИ как сомнительные, слов в секунду, самый длинный участок без описаний.
  • W: Что сейчас на экране, включая видимый текст. Ответ появляется в окне «Спросить еще», где можно задавать уточняющие вопросы: ИИ помнит разговор.
  • E: Оценить это аудиоописание по анкете CSA 2020; ответы сохраняются вместе с проектом и могут быть экспортированы в виде отчёта.
  • L: Следующая звуковая дорожка видео (например, существующее аудиоописание)
  • C: Следующая дорожка субтитров или их отключение
  • Shift+Вверх / Shift+Вниз: Сильнее или слабее приглушать видео, пока звучит описание (от 0 до 24 дБ, с шагом 3 дБ).
  • ?: То же, что F1: произносит список клавиш плеера.
  • Ctrl + S: Сохранить проект (Ctrl + Shift + S: Сохранить как)
  • F1: Прочитать этот список клавиш

Пока звучит описание, громкость видео снижается на 9 дБ (звук никогда не отключается полностью, настраивается в Настройки > Аудиовывод), а затем плавно возвращается, как рекомендуют профессиональные руководства по аудиоописанию. Перед описанием, которое читает текст на экране, звучит короткий сигнал. В режиме по запросу тихий звук сообщает, что доступно важное описание. В режиме программы чтения с экрана описания читаются с громкостью вашей программы чтения с экрана; при экспорте их уровень задаётся в Настройки > Аудиовывод.

В редакторе описаний

  • F8 / Shift + F8: Следующее / предыдущее описание на проверку
  • Ctrl + P: Воспроизвести видео или поставить на паузу
  • Alt + Стрелка влево / Стрелка вправо: Сдвинуть видео на 1 секунду
  • Ctrl + [ / Ctrl + ]: Установить начало / конец по позиции плеера
  • Ctrl + R: Прослушать текст голосом экспорта
  • Ctrl + G: Сменить голос говорящего для переведённой реплики (неизвестен, женщина, мужчина)
  • Ctrl + S: Сохранить изменения
  • Ctrl + Z / Ctrl + Y (вне текстовых полей): Отменить / повторить
  • Delete в списке: Удалить описание
  • Escape: Закрыть (предлагает сохранить несохранённые изменения)

В других окнах

  • «Персонажи» и «Управление шаблонами запросов»: Enter на элементе открывает его для редактирования; в окне «Персонажи» Delete удаляет выбранного персонажа.
  • Настройки и оценка: Ctrl + Tab / Ctrl + Shift + Tab переключают вкладки.
  • Любое окно: Escape закрывает или отменяет; подчёркнутые буквы вызываются клавишей Alt вместе с буквой, как указано в этом руководстве.
