Guia do Utilizador do Omni Describer

Dar voz ao mundo visual com IA.

Aviso importante: O Omni Describer passou para uma plataforma web. A aplicação para computador está agora em modo de manutenção. As novas funcionalidades e melhorias concentram-se na versão web em studio.binclusive.io. A plataforma web não requer instalação nem chaves API e funciona em todos os dispositivos, incluindo Mac e telemóveis. A aplicação para computador continuará disponível para quem a preferir.

Tudo começou com o meu amor pelo cinema. Quando percebi quantos pormenores das minhas cenas favoritas se perdiam sem uma boa audiodescrição, surgiu uma ideia: "Bem, não poderia a IA facilitar-nos isto?" Sonhei com uma ferramenta que não só gerasse descrições, mas que também desse controlo total ao utilizador. Após meses de trabalho intenso, inúmeros testes e a superação de muitos obstáculos técnicos, desenvolvi o Omni Describer como o produto desse sonho.

O que significa o nome?

O "Omni" do nome vem do latim e significa "tudo" ou "todas as coisas". Escolhi este nome porque não queria que a ferramenta servisse apenas um propósito. Sim, o Omni Describer pretende sobretudo tornar os media acessíveis a pessoas cegas e com baixa visão, criando audiodescrições. Contudo, o seu propósito não se limita a isso.

É também uma ferramenta de exploração. Um crítico de cinema, um estudante, um artista ou qualquer pessoa curiosa sobre pormenores visuais pode usar funcionalidades como o "Explorador de cenas" ou o "Perguntar mais" para mergulhar nas camadas de um vídeo como nunca antes. O Omni Describer é uma janela para ver o mundo através dos "olhos" da IA e compreendê-lo de forma diferente. Em suma, é "um descritor para tudo, para todos".

Requisitos do sistema

Para obter o melhor desempenho do Omni Describer, recomendo cumprir os seguintes requisitos mínimos de sistema:

  • Sistema operativo: Windows 10 ou superior (64 bits).
  • Memória (RAM): pelo menos 4 GB de RAM.
  • Armazenamento: pelo menos 500 MB de espaço livre em disco para a aplicação e os ficheiros temporários.
  • Ligação à Internet: indispensável: a IA, Google Gemini, funciona online. Também é necessária para as vozes online (OpenAI, Azure, Google) e a transferência de vídeos.
  • Leitor de ecrã: para uma acessibilidade total, recomenda-se um leitor de ecrã como o JAWS, o NVDA ou o Narrador do Windows.

Primeiros passos: configurar as chaves API

O Omni Describer usa o Google Gemini para analisar vídeos, imagens e documentos, por isso precisa da sua própria chave API Gemini antes de começar. As vozes online têm as suas próprias chaves, descritas em Vozes; a escolha do modelo Gemini é explicada em A IA: modelos e definições do Gemini.

  1. Abrir as Configurações: abra o menu Ficheiro (Alt + F) e escolha Configurações..., ou prima Ctrl + ,.
  2. Separador Definições de IA: prima Ctrl + Tab para passar do separador Geral para o separador Definições de IA e depois Tab para entrar nele.
    • Chave API Gemini: necessária para a análise de vídeo com o Gemini. Cole a sua chave neste campo. Pode obter uma chave gratuita no Google AI Studio. Depois prima Tab até ao botão Testar chave (Alt + T): a aplicação indica se a chave funciona e quantos modelos pode usar.
    • Chave da API OpenAI (para TTS): só é necessária se escolher as vozes OpenAI. Sem ela, pode continuar a usar as vozes integradas do Windows. Pode obter uma chave na OpenAI Platform.
  3. Guardar: prima Aplicar ou OK para guardar as configurações. Está pronto a começar!
Armazenamento seguro: as suas chaves API são cifradas e guardadas em segurança no seu computador, no ficheiro de configurações da aplicação. Nunca são enviadas para outro lado, exceto para ligar diretamente aos respetivos serviços de IA.

No primeiro arranque, se não estiver definida nenhuma chave Gemini, a aplicação propõe abrir a página do Google AI Studio e as Configurações. Responda Sim, cole a chave e prima Testar chave. No primeiríssimo arranque também lhe é pedido que aceite a licença (Concordo ou Discordo).

Início rápido: gerar a primeira descrição

Vamos começar! Basta seguir estes passos simples:

  1. Selecionar um prompt (opcional): na janela principal, prima Tab até à lista "Opcional: Selecionar uma predefinição de aviso para melhorar a geração" e escolha uma predefinição com as setas. A caixa só de leitura a seguir mostra o texto completo que será enviado à IA. Para a primeira experiência, deixar em "(Sem predefinição selecionada)" é um excelente ponto de partida.
  2. Escolher um vídeo: prima Ctrl + O para um vídeo no seu computador, Ctrl + U para uma ligação direta para um ficheiro de vídeo, ou Ctrl + Y para uma ligação do YouTube. As mesmas ações são os três primeiros botões da janela principal (Alt + L, Alt + U, Alt + Y).
  3. Aguardar a descrição: a aplicação transfere o vídeo se necessário, prepara-o e envia-o à IA. Pode acompanhar o progresso no "Registo de estado" (o leitor de ecrã também anuncia os passos principais). Isto pode demorar alguns minutos, consoante a duração do vídeo. Ctrl + Shift + P repete a última mensagem de progresso.

Quando o processo terminar, o Leitor de vídeo descrito abre-se automaticamente e pode começar a desfrutar do seu vídeo acabado de descrever! Lembre-se de guardar o projeto com Ctrl + S no leitor: caso contrário, as descrições perdem-se ao fechá-lo (o leitor pergunta-lhe antes de fechar).

Cancelar uma descrição

Enquanto uma descrição está a ser gerada, prima Escape na janela principal, ou o botão Cancelar geração (Alt + C; o foco passa para ele quando uma geração começa). O cancelamento funciona em todas as fases: enquanto o vídeo é preparado, enquanto é enviado (mesmo um envio longo), enquanto a aplicação espera para tentar de novo após um erro e enquanto a IA trabalha. A aplicação diz "A cancelar..." e depois "Geração cancelada." Fechar a aplicação também interrompe uma geração em curso. Enquanto uma geração decorre, o menu Ficheiro e os botões de origem ficam indisponíveis.

A janela principal e os seus menus

A janela principal contém, pela ordem de Tab:

  1. Os botões ficheiro de vídeo Local, Vídeo direto URL e URL do vídeo do YouTube, para escolher o vídeo a descrever.
  2. Abrir plataforma web: abre a versão web do Omni Describer no seu navegador (aí não é necessária nenhuma chave API).
  3. A lista de predefinições de prompt e o texto só de leitura da predefinição selecionada (consulte Gerir predefinições de prompts).
  4. O Registo de estado, um texto só de leitura com tudo o que a aplicação fez; leia-o com as setas.
  5. Os botões Configurações..., Cancelar geração (disponível apenas enquanto uma descrição está a ser gerada) e Sair.

A barra de estado, em baixo, mostra o passo atual e, durante o processamento, a percentagem.

O menu Ficheiro

Abra-o com Alt + F.

  • Abrir vídeo local... (Ctrl + O): escolha um ficheiro de vídeo no seu computador e descreva-o.
  • Abrir vídeo a partir de URL... (Ctrl + U): escreva o endereço direto de um ficheiro de vídeo (terminado em .mp4, .webm...). É transferido e depois descrito.
  • Abrir a partir de YouTube... (Ctrl + Y): cole um endereço do YouTube. A qualidade transferida define-se nas Configurações, separador Geral.
  • Abrir projeto... (Ctrl + P): reabre um projeto guardado (ficheiro .omniad) no leitor, sem voltar a consultar a IA. Se o vídeo tiver mudado de sítio, a aplicação pede-lhe que o localize.
  • Projetos recentes: um submenu com os últimos projetos que abriu ou guardou; prima o número à frente de um projeto para o abrir.
  • Importar descrições de SRT ou WebVTT...: abre um guião de descrições existente (.srt ou .vtt). A aplicação diz quantas descrições encontrou e depois pede o vídeo a que pertencem. Pode então ouvi-las, editá-las ou exportá-las.
  • Descrever uma imagem ou um PDF... (Ctrl + I), Descrever o meu ecrã (Ctrl + Alt + Shift + D) e Descrição contínua do ecrã (Ctrl + Alt + Shift + L): consulte Imagens, PDF e o seu ecrã.
  • Reutilizar personagens de um projeto... (Ctrl + G): para uma série, escolha o projeto de um episódio anterior; as descrições seguintes partem das suas personagens, para que os nomes e as descrições se mantenham iguais.
  • Gerir predefinições de prompts...: consulte Gerir predefinições de prompts.
  • Abrir plataforma web... (Ctrl + W): abre a versão web no seu navegador.
  • Configurações... (Ctrl + ,): consulte Um mergulho profundo nas Configurações.
  • Repor configurações e dados...: consulte Repor configurações e dados.
  • Sair (Alt + F4).

O menu Ajuda

  • Ver Ajuda (F1): abre este guia no seu navegador, na língua da interface quando existe uma tradução.
  • Changelog: o que mudou em cada versão.
  • Contribuidores: as pessoas que ajudaram a criar e a traduzir a aplicação.
  • Ver Licença: o contrato de licença.
  • Sobre...: versão, endereço de contacto e um botão Visitar sítio web.

Funcionalidades principais

Antes de descrever, a aplicação encontra os momentos sem fala, mesmo por baixo da música (deteção de fala Silero, transferida uma vez, cerca de 2 MB, e executada no seu computador), e as mudanças de plano, e depois pede à IA que coloque aí as descrições. Anuncia o número aproximado de tokens antes de enviar o vídeo (Escape cancela) e dá notícias pelo menos a cada 25 segundos enquanto trabalha.

O leitor de vídeo descrito

Esta é a sua sala de cinema pessoal com audiodescrição. Enquanto o vídeo é reproduzido, as descrições são lidas nos momentos certos: por predefinição pelo seu leitor de ecrã instalado (como o JAWS ou o NVDA), ou pela voz da aplicação, ou na sua linha braille (consulte "Descrições no leitor" em Separador Saída de áudio). O foco começa no botão Reproduzir. Pela ordem de Tab, o leitor contém:

  • O botão Reproduzir / Pausa (no fim do vídeo diz Repetição) e o controlo deslizante de progresso do vídeo: as setas no controlo deslizante movem-se no vídeo.
  • Os botões Rewind 5s (Alt + R) e Forward 5s (Alt + F), e o controlo deslizante Vol (o volume do vídeo, memorizado para a próxima vez).
  • Descrição áudio atual: o texto da descrição que está a ser lida; pode revê-lo com as teclas de leitura do seu leitor de ecrã.
  • Utilização do token de IA: quantos "tokens" de IA foram usados, para o ajudar a acompanhar a utilização da API.
  • Os botões Explorar a cena..., Perguntar mais..., Editar descrições..., Configurações... e Exportar..., cada um descrito abaixo.

A maioria das ações tem também um atalho de uma só tecla que funciona onde quer que esteja o foco: consulte Atalhos de teclado (ou prima F1 ou ? no leitor para os ouvir). Quando fecha o leitor, este pergunta se quer guardar o projeto caso algo tenha mudado; um vídeo transferido é eliminado ao fechar, a menos que tenha guardado um projeto (o vídeo é então copiado para junto do projeto).

Configurações > Saída de áudio, "Descrições no leitor": o seu leitor de ecrã (fala e braille, a opção predefinida); a voz da aplicação escolhida acima, preparada antecipadamente para que o vídeo seja baixado ou pausado exatamente durante o tempo certo; ou apenas braille, em que o vídeo pausa após cada descrição até premir Enter. "Mostrar também as descrições em letra grande no vídeo" apresenta cada descrição sobre a imagem, com o tamanho e a cor que escolher, para espectadores com baixa visão.

Editar descrições: o poder de refinar

A IA oferece um ponto de partida fantástico, mas a verdadeira qualidade vem do refinamento. O botão "Editar descrições..." no leitor abre um editor poderoso que lhe dá controlo total sobre todos os aspetos do seu projeto. O vídeo tem de estar carregado primeiro.

  • Selecionar e modificar: a lista no topo (Alt + L) tem uma linha por descrição: início, fim, texto, palavras por segundo, estado de revisão e nível. Selecionar uma linha carrega-a abaixo e leva o vídeo até lá. Enter numa linha passa para o seu texto.
  • Ajustar os tempos: edite os campos Início e Fim (HH:MM:SS.mmm), ou defina-os a partir da posição do leitor com os botões "Início = posição do leitor" (Alt + T ou Ctrl + [) e "Fim = posição do leitor" (Alt + N ou Ctrl + ]). Quando altera o tempo de início, o tempo de fim desloca-se automaticamente para preservar a duração da descrição. Todos os tempos são validados para garantir que ficam dentro dos limites do vídeo.
  • Reescrever o texto: edite livremente o texto da descrição para melhorar a clareza, acrescentar pormenores ou corrigir imprecisões.
  • Estado de revisão e Notas do revisor: marque uma descrição como "a rever" ou "validada" e acrescente uma nota; ambos são guardados com o projeto e aparecem no guião de produção Word.
  • Adicionar novo... (Alt + A): abre uma pequena caixa de diálogo onde define o início, o fim e o texto de uma nova descrição; o início é a posição atual do leitor.
  • Apagar (Alt + D, ou Delete na lista): remove a descrição selecionada após confirmação.
  • Personagens (Alt + H): abre o glossário de personagens; consulte As personagens e as suas vozes.
  • Ouvir com a voz de exportação (Alt + R ou Ctrl + R): lê o texto com a voz usada nas exportações de áudio, incluindo o dicionário de pronúncia.
  • Salvar alterações (Alt + S ou Ctrl + S) e Fechar (ou Escape).
  • Atalhos: F8 / Shift+F8: descrição seguinte / anterior a rever. Ctrl+P: reproduzir ou pausar o vídeo. Alt+Seta esquerda / Alt+Seta direita: mover o vídeo 1 segundo. Ctrl+Z / Ctrl+Y na lista: anular / refazer. Ctrl+G numa fala de diálogo traduzido: mudar a voz do interlocutor (desconhecida, mulher, homem). Os tempos escrevem-se como HH:MM:SS.mmm (MM:SS ou segundos também funcionam); passar para outra descrição mantém as suas alterações e, ao fechar, é-lhe perguntado se há alterações por guardar.
Guarde o seu trabalho: quando fecha o editor, a lista atualizada de descrições volta para o leitor e é usada na reprodução e nas exportações. Para a manter depois de fechar o leitor, guarde o projeto no leitor com Ctrl + S.

Para uma revisão profissional, cada descrição tem um estado (a rever ou validada) e notas do revisor, guardados com o projeto. Após a geração, uma verificação pela IA também marca as descrições que não estão no presente, que interpretam sentimentos em vez de descreverem o que se vê, ou que saem da ficção (nomes de atores, jargão de câmara); aparecem como "a rever" no editor, e a tecla V no leitor conta-as. Alterar o texto apaga estas marcas. As entradas demasiado longas para a sua pausa ou que caem sobre o diálogo também começam como "a rever".

As personagens e as suas vozes

A IA mantém um glossário de personagens para que cada pessoa seja descrita da mesma forma ao longo de todo o vídeo e só seja nomeada depois de o seu nome ter sido dito ou mostrado. Abra-o a partir do editor com Personagens (Alt + H).

  • A lista mostra o ID, o nome ("Não indicado" até ser revelado), a descrição e a voz de cada personagem. Enter edita a personagem selecionada, Delete remove-a (após confirmação).
  • Adicionar... (Alt + A), Editar... (Alt + E), Apagar (Alt + D), e depois OK para manter as alterações ou Cancelar.
  • No formulário da personagem: ID (um identificador único, obrigatório), Nome (deixe-o vazio se ainda não tiver sido revelado), Descrição (como a reconhecer, obrigatória).
  • Voz para as falas traduzidas desta personagem: quando o diálogo em língua estrangeira é traduzido (consulte legendas áudio), escolha que voz lê as falas desta personagem nas exportações de áudio e com a voz da aplicação:
    • Automática (predefinição): o género aparente do interlocutor em cada fala.
    • Voz feminina ou Voz masculina: sempre essa voz para esta personagem.
    • Voz da audiodescrição: a mesma voz que as descrições.
    O rótulo termina com "a IA viu: mulher", "homem" ou "indeterminado": o género que a IA percebeu, que a sua escolha substitui sem o apagar.
  • Dar um novo nome a uma personagem também a renomeia em todas as descrições; a aplicação diz quantas descrições foram atualizadas.

Para reutilizar as personagens de um episódio anterior, use Ficheiro > Reutilizar personagens de um projeto (Ctrl + G) antes de descrever o seguinte.

Gerir predefinições de prompts

Os prompts são instruções adicionais que dizem à IA em que se deve concentrar. Mudando o prompt, pode obter descrições em estilos muito diferentes.

  • Selecionar uma predefinição: antes de processar um vídeo, escolha uma predefinição na lista de prompts da janela principal.
  • Gerir as predefinições: vá a Ficheiro > Gerir predefinições de prompts.... A lista mostra o nome e o texto de cada predefinição. Botões: Adicionar... (Alt + A), Editar... (Alt + E, ou Enter numa predefinição), Apagar (Alt + D), Exportar... (Alt + X), Importar (Alt + I) e Fechar. Uma predefinição tem um nome e um texto de prompt, ambos obrigatórios.
  • Uma lista por língua da interface: a caixa de diálogo gere as predefinições da língua atual da interface (indica qual no topo). Mudar a interface para outra língua mostra a lista dessa língua.

As predefinições existem nas dez línguas da interface. As predefinições de origem são fornecidas com a aplicação como ficheiros JSON na sua pasta prompts, um ficheiro por língua (en.json, fr.json...); a sua própria lista é guardada na sua pasta de dados (prompts.json). Exportar... guarda as suas predefinições num ficheiro JSON para as partilhar com outros audiodescritores; Importar acrescenta as predefinições de um desses ficheiros (uma predefinição com o mesmo nome é substituída). Ficheiro > Repor configurações e dados pode restaurar as predefinições de origem.

Perguntar mais sobre a cena

Já se perguntou o que uma personagem tem na mão ou o que diz uma placa ao fundo? Esta funcionalidade permite-lhe perguntar tudo o que lhe vier à cabeça sobre a cena. Usa o Gemini.

  1. Pause o vídeo no momento que lhe desperta curiosidade.
  2. Prima Q, ou o botão Perguntar mais....
  3. Escreva a sua pergunta no campo "A sua nova pergunta:" (por exemplo, "De que cor é o chapéu da mulher?" ou "O que diz o texto na parede?").
  4. Escolha em "Duração do contexto do vídeo (segundos)" quantos segundos de vídeo em torno do momento atual a IA deve analisar (1 a 60, por predefinição 5).
  5. Prima Submeter pergunta (Alt + S). A resposta da IA aparece na área "História da conversa", e pode fazer perguntas de seguimento: a IA lembra-se da conversa.
  6. Adicionar às descrições (Alt + A) acrescenta a última resposta como nova descrição no momento atual. Fechar volta ao leitor.

A tecla W no leitor pergunta diretamente "O que está no ecrã neste momento?" e mostra a resposta nesta janela.

Explorador de cenas

O Explorador de cenas diz-lhe o que está na imagem e onde. Cada objeto vem com uma posição horária: as 12 horas são o topo da imagem, as 3 horas o lado direito, as 6 horas a parte de baixo. É uma janela normal, lida pelo seu leitor de ecrã e pela sua linha braille. Usa o Gemini.

  1. Pause o vídeo numa cena que queira explorar em pormenor.
  2. Prima S, ou o botão Explorar a cena....
  3. Nas opções, escolha a "Duração da análise (segundos)" (1 a 10, por predefinição 3) e, opcionalmente, escreva em que se deve concentrar; depois prima Analisar a cena (Enter).

A janela do Explorador de cenas tem três partes; passe de uma para outra com Tab:

  • Cena (Alt + S): um resumo da cena inteira.
  • Objetos (Alt + O): os objetos com a sua posição horária. Ao percorrer a lista, ouve-se um som colocado à esquerda ou à direita conforme a posição do objeto (use auscultadores estéreo).
  • Detalhes (Alt + D): o aspeto do objeto selecionado e o que está a fazer.
  • Escape: fecha o Explorador de cenas.

Imagens, PDF e o seu ecrã

Ficheiro > Descrever uma imagem ou um PDF (Ctrl+I) descreve uma fotografia, uma captura de ecrã ou um documento PDF: primeiro o tema principal, depois as pessoas, as cores e qualquer texto visível, lido exatamente. Para um PDF: a paginação, as imagens, os gráficos e as tabelas com os seus valores principais, e depois um resumo por secção. O resultado abre-se numa janela que pode ler linha a linha, ou copiar com o botão Copiar (Alt + C). Imagens suportadas: PNG, JPG, WEBP, GIF, BMP e HEIC.

Descrever o meu ecrã (Ctrl+Alt+Shift+D) funciona a partir de qualquer aplicação: um navegador, uma videochamada, um jogo. O ecrã é capturado e descrito, e a resposta é lida pelo seu leitor de ecrã. A captura é eliminada a seguir.

Descrição contínua do ecrã (Ctrl+Alt+Shift+L, ativar ou desativar) verifica o ecrã a cada 3 segundos e só o descreve quando mudou de forma visível, dizendo apenas o que é novo. Cada descrição consome a sua quota da API: desative-a quando já não precisar dela.

Legendas áudio: em Configurações > Definições de IA, "Traduzir diálogos noutra língua (legendas áudio)" acrescenta a tradução das falas em língua estrangeira (anime em versão original, filmes estrangeiros), introduzida pelo interlocutor. Tal como o texto no ecrã, são anunciadas por um som curto e lidas com a segunda voz nas exportações; com "Ler o diálogo traduzido com uma voz correspondente ao interlocutor (mulher ou homem)" são lidas com uma voz feminina ou masculina (consulte Vozes).

Com vários ecrãs, é descrito o ecrã que mostra a janela ativa. No modo contínuo, a nova descrição espera por uma pausa no que o computador está a reproduzir (até 8 segundos) antes de ser lida.

Linha de comandos e processamento em lote

Para descrever muitos ficheiros sem a interface, use a linha de comandos. As pastas são processadas ficheiro a ficheiro; as imagens e os PDF recebem uma descrição em texto (name_description.txt). São usadas as mesmas configurações e a mesma chave API que na aplicação.

python -m audio_describer.cli film.mp4 episodes --lang fr --export vtt,srt,txt,project --out out

A aplicação instalada tem a mesma linha de comandos: OmniDescriber.exe --cli seguido das mesmas opções. Todas as opções:

  • inputs: um ou mais vídeos, imagens, PDF ou pastas.
  • --lang: código da língua das descrições (fr, en, es...), apenas para esta execução; por predefinição: a configuração da aplicação.
  • --export: lista separada por vírgulas entre vtt, srt, txt, dapt, docx, project, mkv, mp4, mp3 e m4a. Por predefinição: vtt,project.
  • --density low|medium|high: mantém nas exportações apenas as descrições essenciais (low) ou todas (high, predefinição); o projeto guarda tudo.
  • --extended: nas exportações de áudio e vídeo, pausa a imagem quando uma descrição é mais longa do que a sua pausa.
  • --no-credit: sem menção falada da IA no fim das exportações de áudio e vídeo.
  • --watch: continua em execução e descreve cada novo ficheiro copiado para as pastas (quando a cópia termina). Ctrl + C interrompe.
  • --out: pasta de saída (por predefinição: a pasta atual).
  • --prompt: instruções adicionais para a IA, como uma predefinição de prompt.

Avaliar uma audiodescrição

Prima E no leitor para abrir o questionário do guia de audiodescrição de 2020 do regulador audiovisual francês (CSA). O vídeo pausa. O primeiro separador serve para ouvir sem a imagem, o segundo para verificar com a imagem (Ctrl + Tab muda de separador). Classifique cada pergunta de 1 a 5 (ou deixe-a "sem classificação") e acrescente comentários; os valores medidos (descrições sobre o diálogo, palavras por segundo, descrições incertas, texto no ecrã) são mostrados junto das perguntas a que dizem respeito. Não há nota global: o guia considera que uma média não tem significado. OK guarda as respostas com o projeto (guarde-o com Ctrl+S) e Guardar relatório... (Alt + R) escreve um ficheiro de texto.

Exportar o seu trabalho

Quando estiver satisfeito com as suas descrições, prima o botão Exportar... no leitor. Escolha um formato com as setas, defina as opções por baixo da lista, prima Continuar (Enter) e escolha onde guardar. Os formatos:

  • Vídeo com faixa de audiodescrição separada (MKV): as faixas originais são mantidas, a descrição é uma faixa de áudio adicional.
  • Vídeo com faixa de audiodescrição separada (MP4): o mesmo, para a maioria dos leitores e telemóveis.
  • Áudio MP3: dá voz às suas descrições com a voz selecionada nas Configurações, mistura-a com o som original e baixa o fundo durante as descrições, para criar um MP3 que pode ouvir em qualquer lado.
  • Apenas a faixa de audiodescrição (M4A): só as descrições faladas, colocadas nos seus tempos.
  • Descrições WebVTT (.vtt): para leitores e plataformas web.
  • Ficheiro de legendas SRT: as descrições como legendas com os seus tempos, para leitores como o VLC.
  • Ficheiro de texto simples (.txt): uma descrição por linha, sem tempos.
  • Guião W3C TTML DAPT (.ttml): para ferramentas profissionais de audiodescrição.
  • Guião de produção (Word .docx): códigos de tempo, texto, nível, estado e notas, para revisão.
  • Guião completo (.txt): a IA transcreve os diálogos e intercala-os com as descrições, uma alternativa em texto para leitores surdocegos (WCAG 1.2.8). Usa o Gemini e pode demorar alguns minutos.

As exportações de áudio e vídeo precisam do FFmpeg (incluído na aplicação) e dão voz a cada descrição; uma janela de progresso permite-lhe acompanhar e cancelar a exportação.

Opções da janela de exportação: Apenas as descrições da densidade atual (Alt + D, ativada por predefinição) exporta o que ouve no leitor (tecla D); Descrição alargada (Alt + X, apenas MKV, MP4 e MP3; ativada por predefinição quando o leitor está em modo alargado) pausa a imagem quando uma descrição é mais longa do que a sua pausa, em vez de a cortar (o vídeo é recodificado e as legendas originais não são mantidas); menção falada (Alt + R, formatos de áudio e vídeo) acrescenta no fim uma frase a dizer que a audiodescrição foi gerada por IA. Sem a opção alargada, a mensagem final enumera as descrições que foram cortadas. A faixa de audiodescrição recebe o nome na língua das descrições, as legendas da origem são mantidas sempre que possível e, com som 5.1, as descrições são colocadas no canal central. No leitor, Shift + I guarda a introdução áudio como MP3 para publicar antes do programa.

A IA: modelos e definições do Gemini

O Omni Describer usa o Google Gemini para tudo: as descrições de vídeo, as imagens, os documentos PDF e o seu ecrã, Perguntar mais, o Explorador de cenas, a introdução áudio e a transcrição dos diálogos do guião completo. O Gemini recebe o vídeo inteiro com a sua banda sonora: ouve os diálogos e coloca as descrições nas pausas reais em vez de falar por cima das pessoas. Basta uma chave API Gemini, que pode obter gratuitamente em aistudio.google.com/apikey (consulte Primeiros passos).

Escolher um modelo: nas Configurações, separador Definições de IA, Modelo Gemini. Atualizar lista de modelos pede à Google a lista atual de modelos que a sua chave pode usar. O predefinido, gemini-3.8-flash, oferece um bom equilíbrio entre qualidade, velocidade e custo para a maioria dos vídeos.

  • Nível gratuito (sem faturação, dentro dos limites diários da Google): gemini-4-hydrogen, o modelo geral mais recente, mais lento quando o nível de raciocínio é Alto; gemini-3.8-flash (predefinido) e gemini-3.6-flash; gemini-3.5-flash-lite e gemini-3.1-flash-lite, os mais baratos e rápidos, com qualidade inferior.
  • Só pagos (faturação ativada na sua conta Google): gemini-4-neon, gemini-4-carbon e gemini-4-argon.
  • Os modelos gemini-2.5 e gemini-2.0 estão descontinuados ou desativados: se ainda tiver um selecionado, escolha um modelo mais recente.

Escolha um modelo Flash-Lite para rascunhos rápidos, vídeos muito longos ou quando a quota diária está a acabar. Escolha gemini-4-hydrogen para um filme em que a qualidade das descrições conta mais do que o tempo de espera.

As restantes definições da IA são descritas em Separador Configurações de IA; em resumo:

  • Nível de raciocínio (Gemini 3 e posteriores): quanto o modelo raciocina antes de responder. Baixo é mais rápido e barato; Alto ajuda nos filmes complexos, mas é mais lento.
  • Detalhe das imagens enviadas à IA: quanto detalhe de cada fotograma do vídeo o Gemini recebe. Baixo ou Médio chega para a maioria dos vídeos e permite que os vídeos longos caibam e custem menos; Alto ajuda a ler textos pequenos no ecrã, créditos ou letreiros, mas custa cerca de 3 a 4 vezes mais por fotograma. Automático (predefinido) deixa a escolha ao Gemini.
  • Desativar os filtros de segurança: ativado por predefinição, para que os filmes com cenas violentas ou sensíveis sejam descritos na mesma.
  • Ativar a fragmentação de vídeo para vídeos longos: analisa um vídeo longo por partes, uma após a outra; use-a quando um vídeo longo falha ou para antes do fim.

Vozes

A voz escolhida nas Configurações, separador Saída de áudio, lê as descrições nas exportações de áudio e vídeo, no botão "Ouvir" do editor e no leitor quando "Descrições no leitor" está definido para a voz da aplicação. (No modo predefinido do leitor de ecrã, é a própria voz do seu leitor de ecrã que as lê durante a reprodução.) Escolha o Motor de conversão de texto em voz com as setas; os campos desse motor aparecem por baixo. Prima Testar no grupo "Voz de teste" para ouvir o texto escrito acima.

  • OpenAI TTS (alta qualidade): vozes naturais; precisa de uma conta OpenAI paga e da chave da API OpenAI (separador Definições de IA). Escolha uma Predefinição de voz; Gerir predefinições de voz permite adicionar, editar e apagar predefinições, cada uma com um nome, uma voz OpenAI de base (alloy, echo, fable, onyx, nova, shimmer, coral, ash, ballad, sage), uma velocidade e instruções para o tom ("Fala num tom calmo e caloroso").
  • SAPI5 (Vozes de 64 bits) e SAPI5 (vozes de 32 bits): vozes instaladas no Windows, sem necessidade de chave. A opção de 32 bits dá acesso a vozes mais antigas de sistemas anteriores.
  • Windows OneCore (vozes modernas): as vozes modernas do Windows (as que o Narrador usa), offline, sem necessidade de chave.
  • Para SAPI5 e OneCore, escolha a Voz e a Velocidade (50 a 200 %).
  • Microsoft Azure Neural Voices (online, requer chave): campos Chave do recurso de voz (de um recurso Azure Speech), Região (por exemplo westeurope), Voz (por exemplo fr-FR-DeniseNeural) e, opcionalmente, uma Voz feminina e uma Voz masculina para o diálogo traduzido.
  • Google Cloud Text-to-Speech (online, requer chave): campos Chave API, Voz (por exemplo fr-FR-Chirp3-HD-Aoede) e, opcionalmente, uma Voz feminina e uma Voz masculina para o diálogo traduzido.

Diálogo traduzido lido com uma voz correspondente ao interlocutor

Quando o diálogo noutra língua é traduzido (legendas áudio) e a opção Ler o diálogo traduzido com uma voz correspondente ao interlocutor (mulher ou homem) está marcada (predefinição), cada fala traduzida é lida com uma voz feminina ou masculina. A aplicação escolhe, por esta ordem:

  1. com Azure ou Google, a voz feminina ou masculina escrita nos campos desse motor;
  2. caso contrário, a Voz feminina ou a Voz masculina escolhida por baixo da caixa de verificação: ou "Voz instalada no Windows (automática)", que usa uma voz do Windows desse género na língua das descrições, ou uma voz Piper local. As vozes Piper são vozes gratuitas e de alta qualidade que funcionam offline no seu computador. Escolha uma na lista (o tamanho é indicado) e prima Transferir e ouvir: é transferida uma única vez (cerca de 20 MB, com verificação da soma de controlo) e é reproduzido um exemplo. A lista mostra as vozes Piper da língua das descrições;
  3. se nenhuma destas estiver disponível, a voz habitual das descrições.

A voz atribuída a um interlocutor pode ser fixada por personagem (consulte As personagens e as suas vozes) ou por fala no editor com Ctrl + G.

Língua da interface e língua das descrições

  • Língua da interface (Configurações, separador Geral, "Linguagem de aplicação"): com "Deteção automática no arranque" (predefinição), a aplicação segue a língua de apresentação do Windows sempre que arranca, por isso mudar a língua do Windows muda a língua da aplicação no arranque seguinte. Escolha uma língua na lista para a manter fixa. Uma alteração aplica-se depois de reiniciar a aplicação. Disponíveis: árabe, inglês, francês, italiano, português, russo, espanhol, turco, ucraniano e vietnamita.
  • Língua das descrições (Configurações, separador Definições de IA, "Idioma da descrição"): a língua em que a IA escreve. "Igual à interface" (predefinição) segue a língua da interface; pode escolher qualquer outra língua da lista, por exemplo uma interface em francês com descrições em inglês para uma aula em inglês. A opção de linha de comandos --lang substitui-a numa execução.

As predefinições de prompt seguem a língua da interface; as regras da IA seguem a língua das descrições (consulte Personalizar as regras da IA).

Um mergulho profundo nas Configurações

A janela Configurações (Ctrl + ,, ou o botão Configurações da janela principal ou do leitor) tem três separadores; prima Ctrl + Tab para passar de um para outro e Tab para passar entre os campos de um separador. Em baixo: Aplicar guarda sem fechar (disponível quando algo mudou), OK guarda e fecha, Cancelar fecha sem guardar.

Separador Geral

  • Qualidade de transferência de vídeo do YouTube: Melhor disponível, ou de 1080p até 144p (por predefinição 360p). Uma qualidade mais baixa transfere mais depressa e costuma ser suficiente para a IA.
  • Linguagem de aplicação (requer reinício): consulte Língua da interface e língua das descrições.
  • Nível de registo: Informação (predefinição), Depuração (mais pormenor, útil para comunicar um problema) ou Desativado. O ficheiro de registo está em %LOCALAPPDATA%\OmniDescriber\logs.
  • Permitir que as descrições interrompam o discurso atual: quando marcada, uma nova descrição começa a ser lida imediatamente, mesmo que a anterior não tenha terminado. Desmarcada (predefinição), cada descrição termina por completo antes de a seguinte começar.

Separador Definições de IA

  • Chave API Gemini e o botão Testar chave: consulte Primeiros passos.
  • Chave da API OpenAI (para TTS): apenas para as vozes OpenAI.
  • Taxa de quadros para análise de IA: determina quantos fotogramas de vídeo por segundo são enviados à IA: original, 10, 5, 2 ou 1 FPS. Um valor mais baixo pode reduzir bastante os custos da API e ajudar a evitar limites de processamento, mas pode fazer com que a IA perca ações muito rápidas.
  • Densidade das descrições ao abrir o leitor: Apenas descrições essenciais, Padrão (predefinição), ou Todas as descrições, com pormenores. A tecla D no leitor altera-a a qualquer momento sem novo pedido à IA.
  • Idioma da descrição: consulte Língua da interface e língua das descrições.
  • Estilo da descrição: Objetivo (predefinido), ou Subjetivo, evocativo.
  • Foco em: Geral (predefinido), Personagens, Ações e instruções, Cenários e atmosfera, ou Texto no ecrã.
  • Máximo de palavras por descrição: um limite superior para a extensão de cada descrição (por predefinição 40); 0 significa que só a duração da pausa a limita.
  • Explicitação: Descrever apenas o que é visível; Descrever e nomear (predefinição), por exemplo o local ou um objeto conhecido; ou Descrever, nomear e explicar brevemente.
  • Traduzir diálogos noutra língua (legendas áudio): desativada por predefinição; consulte legendas áudio.
  • Verificar as descrições com uma segunda passagem da IA: ativada por predefinição; uma verificação apenas do texto marca as descrições incertas como "a rever" no editor.
  • Mencionar cores: ativada por predefinição; desmarque-a se as cores não significarem nada para si.
  • Modelo Gemini: uma lista só de leitura de modelos (a predefinição é indicada no rótulo). Atualizar lista de modelos (Alt + R) pergunta à Google que modelos a sua chave pode usar e preenche a lista.
  • Nível de raciocínio (Gemini 3 e posteriores): Baixo (mais rápido, mais barato), Médio (predefinido) ou Alto (mais lento, para filmes complexos).
  • Detalhe das imagens enviadas à IA: Automático (predefinido), Baixo (mais barato, para vídeos longos), Médio ou Alto (lê textos pequenos no ecrã, custa mais). Define quanto detalhe de cada fotograma do vídeo a IA recebe (a "media resolution" do Gemini). Baixo ou Médio chega para a maioria dos vídeos; Alto custa cerca de 3 a 4 vezes mais tokens por fotograma. Consulte A IA.
  • Enviar apenas vídeo (sem áudio) para a IA: não recomendado: sem o som, a IA deixa de conseguir evitar falar por cima do diálogo.
  • Desativar os filtros de segurança (Utilizar com precaução): ativada por predefinição. Permite à IA processar conteúdos que, de outro modo, poderia assinalar como sensíveis, mas o resultado continua sujeito às políticas de segurança fundamentais do fornecedor da IA. É responsável pela forma como usa esta funcionalidade.
  • Ativar a fragmentação de vídeo para vídeos longos: divide o vídeo em partes, analisa-as uma após a outra e junta os resultados. Recomendado para vídeos longos. Duração do pedaço (segundos) (30 a 2400, por predefinição 600) só está disponível quando a fragmentação está marcada.
  • Detetar pausas na banda sonora antes de descrever (recomendado): ativada por predefinição; encontra os momentos sem fala para aí colocar as descrições.

Separador Saída de áudio

  • Motor de conversão de texto em voz e os seus campos (predefinição de voz OpenAI, voz e velocidade SAPI5/OneCore, chave Azure ou Google, região e vozes), e o grupo Voz de teste: consulte Vozes.
  • Dicionário de pronúncia: uma regra por linha, como Hermione = er-mai-o-ni, usado pela voz da aplicação, pelas exportações e pelo botão de audição do editor (palavras inteiras, maiúsculas ou minúsculas).
  • Modo de audiodescrição no leitor: Nas pausas (o vídeo continua a reproduzir, predefinição), alargado (o vídeo pausa quando uma descrição não cabe), ou A pedido (Enter descreve o momento atual). A tecla M altera-o no leitor.
  • Redução do áudio original durante as descrições (-dB): quanto o som do vídeo é baixado enquanto uma descrição é lida, no leitor e nas exportações (por predefinição 9 dB; 6 a 12 recomendado; 0 = sem redução). Shift+Seta acima e Shift+Seta abaixo alteram-na a partir do leitor.
  • Nível da voz de audiodescrição nas exportações (dB): torna a voz das descrições mais alta ou mais baixa do que o programa nas exportações (-20 a +20, 0 = sem alteração).
  • Nas exportações, ler o texto no ecrã com uma segunda voz, mais grave: ativada por predefinição, para distinguir uma placa ou um título lido de uma descrição.
  • Ler o diálogo traduzido com uma voz correspondente ao interlocutor, Voz feminina, Voz masculina e os botões Transferir e ouvir: consulte Diálogo traduzido.
  • Descrições no leitor: Leitor de ecrã (voz e braille, predefinição); Voz da aplicação acima, preparada antecipadamente (sincronização exata); ou Só braille, o vídeo espera por Enter.
  • Mostrar também as descrições em letra grande no vídeo, Tamanho do texto no vídeo (16 a 120, por predefinição 40) e Cor do texto no vídeo (amarelo, branco ou ciano): para espectadores com baixa visão.

Personalizar as regras da IA

Tudo o que a aplicação envia à IA além da sua predefinição de prompt está escrito num ficheiro de texto que pode ler e alterar: as 12 regras profissionais de audiodescrição (colocar as descrições nas pausas, orçamento de palavras, presente do indicativo, objetividade, personagens, texto no ecrã, mudanças de cena, não descrever o que se ouve, sem censura, sem spoilers, adaptar-se ao conteúdo, níveis), a lista de campos de saída que a IA tem de devolver e as linhas acrescentadas pelas configurações Estilo, Foco em, Explicitação, cores e legendas áudio.

  • O texto de origem está em prompts\rules\en.json dentro da pasta da aplicação (na aplicação instalada, dentro da pasta _internal junto de OmniDescriber.exe). Não edite esse ficheiro: é substituído pelas atualizações.
  • Para alterar as regras, crie um ficheiro chamado ad_rules.json na sua pasta de dados, %APPDATA%\Describer (escreva isto na caixa Executar do Windows, Windows + R, para a abrir). Copie para ele apenas as chaves de en.json que quer alterar; um ficheiro parcial serve, as outras chaves mantêm o valor de origem. Mantenha os marcadores entre chavetas, como {language} ou {max_words}: a aplicação preenche-os. Uma chave do tipo errado, ou um ficheiro que não seja JSON válido, é ignorado (e registado no log), por isso um erro de escrita não pode impedir as descrições.
  • Quando a língua das descrições não é o inglês, é usada uma tradução prompts\rules\<language>.json (por exemplo pt.json), se existir; o seu ad_rules.json é aplicado por cima dela.
  • O ficheiro é lido de novo a cada descrição: as suas alterações aplicam-se à descrição seguinte sem reiniciar a aplicação.
  • Ficheiro > Repor configurações e dados, "Predefinições de prompt", remove o seu ad_rules.json (é mantida uma cópia de segurança), para que as regras de origem voltem a aplicar-se.

Repor configurações e dados

Ficheiro > Repor configurações e dados... restaura um estado limpo. Marque o que pretende repor, prima Repor (Alt + R) e confirme:

  • Configurações (voltar aos valores predefinidos) (Alt + C): todas as configurações voltam aos valores predefinidos. As suas chaves API (Gemini, OpenAI, Azure, Google) são mantidas...
  • ...a menos que marque também Esquecer também as minhas chaves API (Alt + E), disponível apenas quando Configurações está marcada.
  • Predefinições de prompt (as predefinições personalizadas são removidas) (Alt + P): as predefinições de origem de todas as línguas voltam, e o seu ad_rules.json é removido.
  • Predefinições de voz OpenAI (Alt + V): voltam as predefinições de origem.
  • Vozes e modelos transferidos (Alt + T): elimina as vozes Piper e o modelo de deteção de fala; voltam a ser transferidos quando necessário.
  • Ficheiros temporários (Alt + F): elimina a pasta temporária da própria aplicação (vídeos transferidos e processados), e nada mais.

Antes de repor as configurações ou as predefinições, é guardada uma cópia de segurança dos ficheiros na subpasta backups da sua pasta de dados, numa pasta com a data e a hora no nome, para que uma reposição por engano possa ser desfeita copiando os ficheiros de volta. Os projetos (.omniad) e os ficheiros exportados nunca são alterados. Algumas configurações, como a língua da interface, aplicam-se depois de reiniciar a aplicação.

Onde os seus dados são guardados

  • Pasta de dados: %APPDATA%\Describer, ou seja C:\Users\<o seu nome>\AppData\Roaming\Describer. Contém as suas configurações e chaves cifradas (settings.dat2), as suas predefinições de prompt (prompts.json), as suas próprias regras da IA (ad_rules.json, se o tiver criado) e a pasta backups.
  • Vozes e modelos transferidos, e o registo: %LOCALAPPDATA%\OmniDescriber (vozes Piper, o modelo de deteção de fala e a pasta logs).
  • Ficheiros temporários: %TEMP%\OmniDescriber.
  • Projetos e exportações: onde quer que os guarde.

Dicas e truques para os melhores resultados

Criar boas audiodescrições é uma arte. Embora a IA seja uma assistente eficaz, obterá os melhores resultados quando a orientar corretamente.

O poder dos prompts: as suas notas de realizador

A aplicação tem um conjunto de regras fundamentais que ensina à IA (como não falar por cima dos diálogos; consulte Personalizar as regras da IA). Pense na área de predefinição de prompt no ecrã principal como o local onde dá as suas notas de realizador para esse vídeo específico. Uma boa nota ajuda a IA a concentrar-se num estilo ou num pormenor particular.
Dica: o prompt "Concentrar-se nos nomes"
Num vídeo com muitas personagens, pode criar um prompt personalizado para dar prioridade ao acompanhamento dos nomes: A tua prioridade máxima neste vídeo é identificar e usar os nomes corretos das personagens assim que forem ditos.
Dica: o prompt "Descrever a atmosfera"
Para filmes visualmente ricos, oriente a IA para se concentrar no ambiente: Concentra-te em descrever o cenário, a atmosfera e os pormenores do ambiente. Menciona a iluminação, as cores e o ambiente geral da cena.

O que evitar nos prompts

Evite instruções que contradigam os princípios fundamentais da IA (descrever apenas o que se vê, não falar por cima dos diálogos). Dar-lhe uma instrução errada pode levar a maus resultados.

  • Mau prompt: "Diz-me tudo o que acontece." É demasiado vago e pode levar a IA a descrever pormenores sem importância.
  • Mau prompt: "Diz-me o que as personagens estão a dizer." Isto levá-la-á a violar a regra "apenas o visual".

Em suma: use os prompts para orientar o foco da IA, não para alterar as regras fundamentais de uma boa audiodescrição. Para alterar as próprias regras, use ad_rules.json.

Perguntas frequentes (FAQ)

P: As minhas chaves API não funcionam. O que devo fazer?
R: Primeiro, verifique se copiou a chave inteira corretamente e use o botão Testar chave junto da chave Gemini. Para a OpenAI, certifique-se de que configurou um método de pagamento na sua conta, pois o serviço TTS não é gratuito. Para o Gemini, certifique-se de que a API está ativada no seu projeto Google Cloud.

P: O processo falhou com um erro "MAX_TOKENS". O que significa?
R: Significa que o seu vídeo é demasiado longo ou visualmente complexo para a IA o processar de uma só vez. É um limite de capacidade, não um erro de conteúdo. A melhor solução é ir a Configurações > Definições de IA e ativar "Ativar a fragmentação de vídeo para vídeos longos". Isto divide automaticamente o vídeo em partes mais pequenas e mais fáceis de processar pela IA.

P: A IA não gerou descrições por causa dos "filtros de segurança". O que posso fazer?
R: É um problema conhecido em que o sistema de segurança da IA pode ser demasiado cauteloso. Tem algumas opções a experimentar, por esta ordem: 1) Vá a Configurações > Definições de IA e certifique-se de que "Desativar os filtros de segurança" está marcada. 2) Se isso falhar, experimente reduzir a "Taxa de quadros para análise de IA" para enviar menos dados à IA. 3) Como último recurso, escolha um modelo mais potente na lista Modelo Gemini, como gemini-4-hydrogen (nível gratuito) ou gemini-4-argon (só pago, com faturação ativada). Podem lidar melhor com conteúdos sensíveis, mas são mais lentos.

P: Algumas das minhas vozes antigas desapareceram da lista SAPI5. Para onde foram?
R: Os sistemas Windows modernos são de 64 bits, mas muitas vozes de síntese clássicas e muito apreciadas eram de 32 bits. Nas Configurações, no separador "Saída de áudio", verá opções de motor separadas para "SAPI5 (Vozes de 64 bits)" e "SAPI5 (vozes de 32 bits)". Para aceder às vozes mais antigas, basta selecionar o motor de 32 bits.

P: Porque é que gerar as descrições demora tanto?
R: O tempo depende da duração do vídeo, da velocidade da sua Internet (para o envio à IA), da taxa de fotogramas selecionada e da carga atual dos serviços de IA. Para vídeos longos recomenda-se vivamente a "fragmentação de vídeo". Pode parar a qualquer momento com Escape.

Atalhos de teclado

Na janela principal

  • Ctrl + O: Abrir vídeo local
  • Ctrl + U: Abrir a partir de um URL direto
  • Ctrl + Y: Abrir a partir do YouTube
  • Ctrl + P: Abrir projeto (.omniad)
  • Ctrl + G: Reutilizar as personagens de um episódio anterior (séries)
  • Ctrl + I: Descrever uma imagem ou um PDF
  • Ctrl + Alt + Shift + D: Descrever o meu ecrã, a partir de qualquer aplicação
  • Ctrl + Alt + Shift + L: Ativar ou desativar a descrição contínua do ecrã, a partir de qualquer aplicação
  • Ctrl + W: Abrir a plataforma web
  • Ctrl + ,: Abrir as Configurações
  • Escape: Cancelar a geração em curso
  • Ctrl + Shift + P: Repetir a última mensagem de progresso
  • F1: Ver Ajuda
  • Alt + F4: Sair

No leitor de vídeo

Estas teclas funcionam seja qual for o controlo com o foco, exceto que as caixas de texto da descrição e dos tokens mantêm as suas próprias teclas de leitura, e as setas continuam a ajustar o controlo deslizante do volume quando este tem o foco. F1, Ctrl+S e Alt+Seta Esquerda / Alt+Seta Direita funcionam em todo o lado.

  • Espaço: Reproduzir / pausar
  • Seta Esquerda / Seta Direita: Recuar / avançar 5 segundos
  • Ctrl + Seta Esquerda / Seta Direita: Recuar / avançar 30 segundos
  • Alt + Seta Esquerda / Seta Direita: Descrição anterior / seguinte (salta para ela e lê-a)
  • Seta Acima / Seta Abaixo: Volume do vídeo (de 5 em 5)
  • R: Repetir a última descrição
  • T: Anunciar o tempo atual e a duração total
  • A: Ativar ou desativar a audiodescrição
  • D: Mudar a densidade das descrições: baixa (apenas o essencial), média, alta (todos os pormenores). Aplica-se de imediato, sem novo pedido à IA.
  • M: Modo de audiodescrição: nas pausas (o vídeo continua a reproduzir), alargado (o vídeo pausa quando uma descrição é demasiado longa para a sua pausa e depois retoma), ou a pedido (nada é lido automaticamente)
  • Enter (modo a pedido): pausar e descrever brevemente o momento atual; Shift + Enter: tudo o que foi descrito nos últimos 15 segundos
  • Enter (modo só braille): retomar o vídeo após uma descrição
  • Q: Perguntar mais sobre o momento atual
  • S: Explorar a cena atual
  • I: Introdução áudio: personagens principais, o seu aspeto e os locais, sem spoilers, para ouvir antes do programa. Escrita pela IA da primeira vez e depois guardada com o projeto.
  • Shift + I: Guardar a introdução áudio como MP3
  • V: Relatório de qualidade: número de descrições, proporção dentro do orçamento de palavras, descrições sobre o som ou marcadas como incertas pela verificação da IA, palavras por segundo, maior intervalo sem descrição.
  • W: O que está no ecrã agora, incluindo o texto visível. A resposta aparece na janela Perguntar mais, onde pode continuar a fazer perguntas de seguimento: a IA lembra-se da conversa.
  • E: Avaliar esta audiodescrição com o questionário CSA 2020; as respostas são guardadas com o projeto e podem ser exportadas como relatório.
  • L: Faixa de áudio seguinte do vídeo (por exemplo, uma audiodescrição existente)
  • C: Faixa de legendas seguinte, ou nenhuma
  • Shift+Seta acima / Shift+Seta abaixo: Baixar mais ou menos o vídeo enquanto uma descrição é lida (0 a 24 dB, de 3 em 3 dB).
  • ?: O mesmo que F1: lê a lista de atalhos do leitor.
  • Ctrl + S: Guardar o projeto (Ctrl + Shift + S: Guardar como)
  • F1: Ler esta lista de atalhos

Enquanto uma descrição é lida, o volume do vídeo baixa 9 dB (nunca fica sem som; ajustável em Configurações > Saída de áudio) e volta a subir suavemente, como recomendam os guias profissionais de audiodescrição. Um som curto toca antes de uma descrição que lê texto no ecrã. No modo a pedido, um som suave indica que está disponível uma descrição essencial. No modo leitor de ecrã, as descrições são lidas ao volume do seu próprio leitor de ecrã; nas exportações, o seu nível define-se em Configurações > Saída de áudio.

No editor de descrições

  • F8 / Shift + F8: Descrição seguinte / anterior a rever
  • Ctrl + P: Reproduzir ou pausar o vídeo
  • Alt + Seta Esquerda / Seta Direita: Mover o vídeo 1 segundo
  • Ctrl + [ / Ctrl + ]: Definir o início / fim na posição do leitor
  • Ctrl + R: Ouvir o texto com a voz de exportação
  • Ctrl + G: Mudar a voz do interlocutor de uma fala traduzida (desconhecida, mulher, homem)
  • Ctrl + S: Salvar alterações
  • Ctrl + Z / Ctrl + Y (fora dos campos de texto): Anular / refazer
  • Delete na lista: Apagar a descrição
  • Escape: Fechar (pergunta se quer guardar as alterações não guardadas)

Nas outras caixas de diálogo

  • Personagens e Gerir predefinições de prompts: Enter num item edita-o; em Personagens, Delete remove a personagem selecionada.
  • Configurações e Avaliação: Ctrl + Tab / Ctrl + Shift + Tab mudam de separador.
  • Todas as caixas de diálogo: Escape fecha ou cancela; as letras sublinhadas alcançam-se com Alt mais a letra, como indicado neste guia.
